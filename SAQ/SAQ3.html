Question 1

Squaring function on ℝ

Setup
Consider \(f:\mathbb{R}\to\mathbb{R}\) defined by \(f(x)=x^2\). Identify the following:
Part 1
The domain of \(f\).
In \(f:X\to Y\), the domain is the set \(X\) the function is declared to act on — read it straight off the notation, no computation needed.
The domain of \(f\) is \(\mathbb{R}\).
Part 2
The codomain of \(f\).
In \(f:X\to Y\), the codomain is \(Y\) — the declared target set. It's not the same as the range/image, and you don't need to check what's actually reached to answer this part.
The codomain of \(f\) is \(\mathbb{R}\).
Part 3
The image of \(1\).
"The image of \(1\)" means \(f(1)\) — just substitute \(x=1\) into the formula.
\(f(1)=1^2=1\). The image of \(1\) is \(1\).
Part 4
The image of \(-1\).
Substitute \(x=-1\) into \(f(x)=x^2\). Remember squaring removes the sign.
\(f(-1)=(-1)^2=1\). The image of \(-1\) is \(1\).
Part 5
The preimage(s) of \(0\).
The preimage of a value \(y\) is the set of all \(x\) with \(f(x)=y\). Here, solve \(x^2=0\).
\(x^2=0\iff x=0\). The preimage of \(0\) is \(\{0\}\) — a single element.
Part 6
The preimage(s) of \(1\).
Solve \(x^2=1\). How many real solutions does this equation have?
\(x^2=1\iff x=1 \text{ or } x=-1\). The preimage of \(1\) is \(\{-1,1\}\) — two elements, confirming \(f\) is not one-one.
Part 7
The preimage(s) of \(-1\).
Solve \(x^2=-1\) over the reals. Can a real number squared ever be negative?
No real \(x\) satisfies \(x^2=-1\), since a real square is always \(\ge0\). The preimage of \(-1\) is \(\emptyset\) — confirming \(-1\) is not in the range of \(f\).
Part 8
The image of \(f\) (i.e. \(f(\mathbb{R})\), the range).
This asks for the full set of values \(f\) actually hits as \(x\) ranges over all of \(\mathbb{R}\) — not the codomain, the achieved outputs. Parts 5–7 already gave you three data points; what pattern do they suggest?
\(f(\mathbb{R})=[0,\infty)\). Every square is \(\ge0\) (so nothing negative, like \(-1\), is ever hit — matching Part 7), and every nonnegative real \(y\) is achieved by \(x=\sqrt y\) (or \(x=-\sqrt y\)). Note the image is a proper subset of the codomain \(\mathbb{R}\) from Part 2 — so \(f\) is not onto.
Question 2

Square-root function on [0, ∞)

Setup
Consider \(g:[0,\infty)\to\mathbb{R}\) defined by \(g(x)=\sqrt{x}\). Identify the following:
Part 1
The domain of \(g\).
Read the set \(X\) straight off the notation \(g:X\to Y\) — no computation needed. Note this domain is not all of \(\mathbb{R}\).
The domain of \(g\) is \([0,\infty)\).
Part 2
The codomain of \(g\).
In \(g:X\to Y\), the codomain is the declared target set \(Y\) — it doesn't need to be fully reached to count as the codomain.
The codomain of \(g\) is \(\mathbb{R}\).
Part 3
The image of \(4\).
"The image of \(4\)" means \(g(4)\) — substitute \(x=4\) into the formula.
\(g(4)=\sqrt4=2\). The image of \(4\) is \(2\).
Part 4
The image of \(0\).
Substitute \(x=0\) into \(g(x)=\sqrt x\). Note \(0\) is a legal input here, unlike negative numbers.
\(g(0)=\sqrt0=0\). The image of \(0\) is \(0\).
Part 5
The preimage(s) of \(2\).
Solve \(\sqrt x=2\) for \(x\ge0\) — square both sides.
\(\sqrt x=2\iff x=4\). The preimage of \(2\) is \(\{4\}\).
Part 6
The preimage(s) of \(-1\).
The (principal) square root symbol \(\sqrt{\phantom{x}}\) never outputs a negative number. Is there any \(x\ge0\) with \(\sqrt x=-1\)?
No such \(x\) exists, since \(\sqrt x\ge0\) for every \(x\) in the domain. The preimage of \(-1\) is \(\emptyset\).
Part 7
The preimage(s) of \(0\).
Solve \(\sqrt x=0\) for \(x\ge0\).
\(\sqrt x=0\iff x=0\). The preimage of \(0\) is \(\{0\}\) — a single element.
Part 8
The image of \(g\) (i.e. \(g([0,\infty))\), the range).
This asks for every value \(g\) actually hits as \(x\) ranges over \([0,\infty)\) — not the codomain. Parts 5–7 already gave you three data points; what pattern do they suggest?
\(g([0,\infty))=[0,\infty)\). The square root of a nonnegative number is always \(\ge0\) (so \(-1\) is never hit — matching Part 6), and every \(y\ge0\) is achieved by \(x=y^2\). As with Question 1, the image is a proper subset of the codomain \(\mathbb{R}\) — so \(g\) is not onto either, though here it is one-one (each output has exactly one preimage, unlike \(f(x)=x^2\) in Question 1).

Question 4

Matching the largest codomain (the range)

Setup
A codomain can technically be chosen as anything containing the function's outputs — but the tightest possible codomain, the one that makes the function onto by construction, is exactly its range. Each function below has domain all of \(\mathbb R\):
  • A \(f(x)=x^2\)
  • B \(f(x)=\sin x\)
  • C \(f(x)=e^x\)
  • D \(f(x)=\dfrac{1}{1+x^2}\)
Part 1
Which function above has range (largest codomain) \([0,\infty)\)?
Which of the four can never be negative, but does hit \(0\) exactly?
Function A. \(x^2\ge0\) always, with \(0\) achieved at \(x=0\), and every nonnegative value achieved by some \(x\) — range \([0,\infty)\).
Part 2
Which function above has range \([-1,1]\)?
Which of the four oscillates, bounded above and below by the same magnitude?
Function B. \(\sin x\) sweeps through every value in \([-1,1]\) and never leaves that band.
Part 3
Which function above has range \((0,\infty)\)?
Which of the four is always strictly positive but gets arbitrarily close to \(0\) without ever reaching it?
Function C. \(e^x>0\) for every real \(x\), \(e^x\to0\) as \(x\to-\infty\) (never reaching it), and \(e^x\) grows without bound — range \((0,\infty)\).
Part 4
Which function above has range \((0,1]\)?
This is the only remaining option — but check it directly: what's the largest value this function can take, and at which \(x\)?
Function D. \(\dfrac{1}{1+x^2}\) is maximized at \(x=0\), giving the value \(1\) (attained), and \(\to0^+\) as \(|x|\to\infty\) (never attained) — range \((0,1]\).
Question 5

One-one functions

Setup
For each function and stated domain, decide whether it is one-one (injective).
Part 1
\(f:\mathbb R\to\mathbb R\), \(f(x)=2x+5\).
Suppose \(f(x_1)=f(x_2)\). Does that force \(x_1=x_2\)?
One-one. If \(2x_1+5=2x_2+5\), then \(x_1=x_2\). Every straight line with nonzero slope is one-one.
Part 2
\(f:\mathbb R\to\mathbb R\), \(f(x)=x^2\).
Can you find two different real numbers with the same square?
Not one-one. \(f(-2)=f(2)=4\), but \(-2\ne2\) — a single counterexample is enough to kill injectivity.
Part 3
\(f:[0,\infty)\to\mathbb R\), \(f(x)=x^2\) (same formula, restricted domain).
Part 2's counterexample used \(-2\). Is \(-2\) available here?
One-one. Restricting the domain to \([0,\infty)\) removes every negative "twin" — on this domain, \(x_1^2=x_2^2\) with \(x_1,x_2\ge0\) forces \(x_1=x_2\). Restricting the domain is exactly how a non-injective formula is turned into an injective function.
Part 4
\(f:\mathbb R\to\mathbb R\), \(f(x)=x^3-x\).
Factor \(f(x)=x(x-1)(x+1)\) and evaluate at a few small integers.
Not one-one. \(f(-1)=f(0)=f(1)=0\) — three different inputs sharing one output. A cubic with a local max and a local min is never one-one on all of \(\mathbb R\).

Setup
For each function, domain, and stated codomain, decide whether it is onto (surjective) — i.e. whether the range equals the codomain exactly.
Part 1
\(f:\mathbb R\to\mathbb R\), \(f(x)=2x+5\).
Given any target \(y\in\mathbb R\), can you always solve \(2x+5=y\) for a real \(x\)?
Onto. For any \(y\in\mathbb R\), \(x=\dfrac{y-5}{2}\) is a real number with \(f(x)=y\). Every line with nonzero slope is onto \(\mathbb R\).
Part 2
\(f:\mathbb R\to\mathbb R\), \(f(x)=x^2\).
Is there any real \(x\) with \(x^2=-1\)?
Not onto. No real \(x\) gives \(f(x)=-1\) (or any negative value) — the range \([0,\infty)\) is a proper subset of the codomain \(\mathbb R\).
Part 3
\(f:\mathbb R\to[0,\infty)\), \(f(x)=x^2\) (same formula, tightened codomain).
Every value in the new, smaller codomain — is each one actually hit by some \(x\)?
Onto. Every \(y\ge0\) is hit, e.g. by \(x=\sqrt y\). Shrinking the codomain down to exactly the range (Question 4's idea) is precisely how a non-surjective function is turned into a surjective one — the mirror image of what restricting the domain did for injectivity in Question 5.
Part 4
\(f:\mathbb R\to\mathbb R\), \(f(x)=x^3\).

Onto. Every \(y\in\mathbb R\) has a real cube root \(x=\sqrt[3]y\), with \(f(x)=y\) — unlike \(x^2\), odd-power functions don't lose the negative half of the codomain.

Question 7

The Horizontal Line Test

Setup
The horizontal line test reads one-one-ness and onto-ness directly off a graph, without any algebra.
Part 1
State the horizontal line test for one-one functions, in your own words.
Think about what it would mean, graphically, for two different \(x\)-values to share the same \(y\)-value.
A function is one-one if and only if every horizontal line \(y=k\) intersects its graph at most once. Two intersection points on the same horizontal line would mean two different inputs sharing one output — exactly what one-one-ness forbids.
Part 2
State the horizontal line test for onto functions (with codomain \(Y\)), in your own words.
Onto means every element of the codomain gets hit by something.
A function \(f:X\to Y\) is onto if and only if every horizontal line \(y=k\), for \(k\in Y\), intersects the graph at least once. Combine both tests: a bijection is exactly a function where every horizontal line (at a codomain height) meets the graph exactly once.

Apply the test to \(f:\mathbb R\to\mathbb R\), \(f(x)=e^x\). Is it one-one? Is it onto?
\(e^x\) is strictly increasing everywhere, but stays strictly positive everywhere too.
