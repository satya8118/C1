Setup — read this first

Every function below is written as \(f:A\to\mathbb R\), where \(A\subseteq\mathbb R\) is whatever the formula for \(f\) allows — finding that largest possible \(A\) is itself part of the exercise.

Preimage. For \(y\in\mathbb R\), the preimage of \(y\) is \(f^{-1}(y)=\{x\in A \mid f(x)=y\}\) — the collection of every input that produces \(y\). This is always a set, a subset of \(A\) — and its size varies genuinely from function to function: it can be empty (if \(y\) is never produced by any \(x\in A\)), a singleton (one input), a finite set with several inputs, or an infinite set. Don't assume it's always a single point — check each case on its own merits.

Image of a set. For \(B\subseteq A\), the image of \(B\) is \(f(B)=\{f(x) \mid x\in B\}\) — the collection of every output produced by some input in \(B\).

Greatest Integer Function. The greatest integer function, denoted by \([x]\), outputs the largest integer that is less than or equal to \(x\). For example:

  • \([3.7] = 3\)
  • \([5] = 5\)
  • \([0.999] = 0\)
  • \([-2.3] = -3\) (Note: \([-2.3]\) is \(-3\), not \(-2\), because \(-3\) is the largest integer less than or equal to \(-2.3\))
  • \([-4] = -4\)

Example Walkthrough: \(f(x) = e^x \sin x\)

1. Domain & Range: Exponential and sine functions are defined for all real numbers, so the domain is \(A = \mathbb{R}\). Because \(\sin x\) oscillates between \(-1\) and \(1\) while \(e^x\) grows infinitely large as \(x \to \infty\) and approaches \(0\) as \(x \to -\infty\), the outputs span all real numbers, making the range \(f(A) = \mathbb{R}\).

2. One-one & Onto:

  • One-one? No. The function equals zero at multiple points, e.g., \(f(0) = 0\) and \(f(\pi) = 0\). Since multiple inputs give the same output, it is not one-one.
  • Onto \(\mathbb{R}\)? Yes. The range matches the entire codomain \(\mathbb{R}\).

3. Finding Preimage \(f^{-1}(0)\) for \(y = 0\):
Set \(e^x \sin x = 0\). Since \(e^x > 0\) for all \(x\), we must have \(\sin x = 0\). This gives an infinite set of inputs: \(f^{-1}(0) = \{k\pi \mid k \in \mathbb{Z}\}\).

4. Finding Image \(f(B)\) for \(B = [0, \pi]\):
On the interval \([0, \pi]\), \(\sin x \ge 0\), reaching its maximum at \(x = \frac{\pi}{2}\). Evaluating the endpoints and critical points gives a minimum output of \(0\) and a maximum output of \(e^{\pi/2}\). Thus, the image set is \(f(B) = \left[0, e^{\pi/2}\right]\).
