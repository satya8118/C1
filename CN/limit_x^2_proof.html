Understanding the Limit of f(x) = x² at x = a

A Step-by-Step Rigorous & Intuitive Guide to the ε-δ Proof

1. Intuition & The Goal of the "Game"

We want to rigorously prove that limx → a x² = a² without assuming continuity.

The Intuition: As x gets arbitrarily close to a, its square x² gets arbitrarily close to a².

The ε-δ Game Rules:
  1. Challenge (ε > 0): An opponent gives us a challenge tolerance ε. They demand that |f(x) - f(a)| = |x² - a²| < ε.
  2. Response (δ > 0): We must respond with a distance radius δ such that whenever 0 < |x - a| < δ, the opponent's challenge is strictly guaranteed to hold!

2. Breaking Down the Difference |x² - a²|

To control |x² - a²|, we factor it algebraically:

|x² - a²| = |x - a| · |x + a|

Notice two components here:

  • |x - a| : This is direct control given by our choice of δ (since |x - a| < δ).
  • |x + a| : This factor is troublesome because it changes with x! It can grow large if x moves far away. We need to bound (cap) this term.

3. The Core Mystery: Why Choose δ = min{1, ...}?

Students often ask: "Where did 1 come from? Why do we take the minimum with 1?"

The Problem:

We want |x + a| to be bounded by a fixed constant. But x could theoretically be anywhere in the universe!

The Solution (First Preliminary Step):

Before picking our final δ, we make an initial agreement that δ will never be larger than 1. (Note: 1 is completely arbitrary! We could have picked 0.5, 2, or 0.1. 1 is just nice and clean.)

If we assume |x - a| < 1, what does that say about |x + a|? Let's bound it:

|x + a| = |(x - a) + 2a|
≤ |x - a| + |2a|      (by Triangle Inequality)
< 1 + 2|a|            (since |x - a| < 1)

Now |x + a| is safely capped by the constant (1 + 2|a|)!

4. Putting It All Together: Finding δ

Under our initial assumption that |x - a| < 1, we have:

|x² - a²| = |x - a| · |x + a| < |x - a| · (1 + 2|a|)

We want this expression to be less than ε:

|x - a| · (1 + 2|a|) < ε  &implies;  |x - a| < ε / (1 + 2|a|)

Therefore, to satisfy BOTH conditions (our initial cap of 1 AND the required bound for ε), we set:

δ = min { 1, ε / (1 + 2|a|) }

5. The Final Formal Step-by-Step Proof

  1. Given any ε > 0, choose δ = min{ 1, ε / (1 + 2|a|) }.
  2. Assume 0 < |x - a| < δ.
  3. Since δ ≤ 1, we know |x - a| < 1, which implies |x + a| < 1 + 2|a|.
  4. Since δ ≤ ε / (1 + 2|a|), we know |x - a| < ε / (1 + 2|a|).
  5. Therefore:
    |f(x) - f(a)| = |x² - a²| = |x - a| · |x + a|
                      < [ε / (1 + 2|a|)] · (1 + 2|a|) = ε

Q.E.D. ■
