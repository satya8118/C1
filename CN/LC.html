Lipschitz Continuous Functions

From a Natural Question to the Lipschitz Constant · Examples · Non-Examples · Geometry

1. Motivation: How the Lipschitz Condition Arises

We want to measure how fast a function is allowed to change. A natural first question is:

The Question

Is there a number K > 0 such that

| f(x) − f(y) | < K | x − y |    for all x, y in the interval [a, b]?

At first glance this looks like a condition on every pair x, y. But notice what happens when x = y: both sides become 0, and the inequality reads 0 < 0, which is false. So we must exclude the trivial pair. More importantly, when x = y the quantity

| f(x) − f(y) | = 0 = K · 0 = K | x − y |

holds with equality for every K. The pair x = y therefore carries no information at all. All the content of the question lies in the pairs with x ≠ y.

Dividing by the positive quantity |x − y|

For x ≠ y, the number |x − y| is strictly positive, so we may divide both sides of |f(x) − f(y)| < K|x − y| by it without changing the direction of the inequality:

| f(x) − f(y) | ⁄ | x − y |  <  K.

The left-hand side is the absolute value of the slope of the secant line through the points (x, f(x)) and (y, f(y)). So the question becomes:

Reformulated

Is the collection of all secant slopes bounded above by some number K?

The set of secant slopes

This suggests that we collect all the secant slopes into one set and study it directly. For a function f on an interval [a, b], define

S(a, b) = { | f(x) − f(y) | ⁄ | x − y |  :  x, y ∈ [a, b],   x ≠ y }.

Now the original question has a clean, set-theoretic answer:

  • If S(a, b) is bounded above, then we may choose K to be any upper bound, and the condition holds.
  • If S(a, b) is unbounded above, then no such K exists, and the condition fails.

The most economical choice of K is the smallest upper bound. So we are led to the least upper bound of S(a, b), which we shall denote by Lip(f, a, b):

Lip(f, a, b) = LUB S(a, b) = LUB { | f(x) − f(y) | ⁄ | x − y |  :  x, y ∈ [a, b],   x ≠ y }.

Here LUB stands for least upper bound. The notation Lip(f, a, b) records that the constant depends on the function and on the interval under consideration.

A small technical point about < and ≤

If we insist on the strict inequality |f(x) − f(y)| < K|x − y| for all x ≠ y, then K must be strictly larger than Lip(f, a, b): no smallest such K exists. To avoid this nuisance, one usually writes the non-strict inequality |f(x) − f(y)| ≤ K|x − y|. With ≤, the smallest admissible K is exactly Lip(f, a, b). We adopt this convention from now on.

Test case: f(x) = x³ on [1, 5]

Let us put this to work. Take f(x) = x³ and the interval [1, 5]. Suppose somebody proposes K = 10. Does it work? We must check whether every secant slope is at most 10 in absolute value.

Test the pair x = 5 and y = 4:

| 5³ − 4³ | ⁄ | 5 − 4 | = | 125 − 64 | ⁄ 1 = 61  >  10.

So K = 10 is not an upper bound for S(1, 5). The proposed constant fails. K = 10 does not work.

Which K is best?

To answer this, simplify the quotient using the algebraic identity x³ − y³ = (x − y)(x² + xy + y²). For x ≠ y,

| x³ − y³ | ⁄ | x − y |  =  x² + xy + y².

So S(1, 5) = { x² + xy + y² : x, y ∈ [1, 5], x ≠ y }, and the problem reduces to finding the LUB of this set. The expression x² + xy + y² is increasing in each variable when both are positive, so on the square [1, 5] × [1, 5] its largest value occurs at the corner x = y = 5:

5² + 5·5 + 5² = 25 + 25 + 25 = 75.

Strictly speaking, the corner x = y = 5 is excluded from S(1, 5), because the quotient requires x ≠ y. But we can approach it: take x = 5 and y = 5 − ε. Then

x² + xy + y² = 75 − 15ε + ε²  ⟶  75   as   ε → 0⁺.

So 75 is the least upper bound, even though it is never attained. Therefore

Lip(f, 1, 5) = LUB S(1, 5) = 75.

Check both directions:

  • K = 75 works: for all x, y ∈ [1, 5], x² + xy + y² ≤ 75, hence |x³ − y³| ≤ 75|x − y|.
  • Any K < 75 fails: with x = 5, y = 5 − ε, the quotient is 75 − 15ε + ε², which exceeds K for ε small enough.

Sanity check via the derivative

Here f′(x) = 3x², and on [1, 5] the largest value is 3 · 5² = 75. Same answer. This is not a coincidence — it is the content of Section 6.

The general interval [a, b], 0 < a < b

Exactly the same computation gives, for x, y ∈ [a, b] with x ≠ y,

| x³ − y³ | ⁄ | x − y | = x² + xy + y² ≤ b² + b·b + b² = 3b²,

and this bound is sharp because we may take x, y → b from below. Therefore

Lip(x³, a, b) = 3b²    for   0 < a < b.

A pleasant surprise: the constant depends only on the right endpoint b, not on a. For [1, 5] we recover 3 · 25 = 75; for [2, 3] we get 27; for [1, 5] with K = 10 we fail, as we already saw.

What we have just done — forming the set of all secant slopes and asking whether it is bounded above — is precisely the idea behind Lipschitz continuity. Let us now state it properly.

2. Definition

Let A ⊆ ℝ and let f : A → ℝ. Consider the set of all secant slopes of f over A:

S = { | f(x) − f(y) | ⁄ | x − y |  :  x, y ∈ A,   x ≠ y }.

Definition (Lipschitz continuity)

The function f is Lipschitz continuous (or simply Lipschitz) on A if the set S is bounded above. In that case, the least upper bound of S is called the Lipschitz constant of f on A and is denoted by Lip(f, A):

Lip(f, A) = LUB S = LUB { | f(x) − f(y) | ⁄ | x − y |  :  x, y ∈ A,   x ≠ y }.

When A = [a, b] we write Lip(f, a, b) for Lip(f, [a, b]).

Equivalently, f is Lipschitz on A if and only if there exists a constant K ≥ 0 such that for all x, y ∈ A,

| f(x) − f(y) | ≤ K | x − y |.

The smallest such K is Lip(f, A). The two formulations are equivalent because dividing by |x − y| > 0 is reversible, and because K is an upper bound for S exactly when the inequality holds for all x ≠ y (the case x = y being trivial).

Three equivalent ways to say it

  • Set form. The set S of secant slopes is bounded above, and Lip(f, A) = LUB S.
  • Inequality form. There is a K ≥ 0 with |f(x) − f(y)| ≤ K|x − y| for all x, y ∈ A.
  • Amplification form. A change of δ in the input can change the output by at most Kδ: the function cannot amplify errors by more than the factor K.

Geometric interpretation

Fix any point x₀ ∈ A. The Lipschitz condition says that for every x ∈ A,

| f(x) − f(x₀) | ≤ K | x − x₀ |,

that is, the graph of f lies entirely inside the double cone with vertex (x₀, f(x₀)) and slopes +K and −K. This must hold at every point of the graph simultaneously, with the same K. The function is therefore not allowed to be arbitrarily steep anywhere, nor to oscillate with arbitrarily large amplitude over arbitrarily short intervals.

3. Examples

Example 1 — Linear functions

For f(x) = mx + b on ℝ,

| f(x) − f(y) | = | m | | x − y |,

so S = { |m| } and Lip(f) = |m|. Linear functions are the simplest Lipschitz functions, and they are the only ones for which the Lipschitz bound is attained at every pair of points.

Example 2 — The absolute value

For f(x) = |x| on ℝ, the reverse triangle inequality gives

| |x| − |y| | ≤ | x − y |,

so Lip(f) = 1. Note that f is not differentiable at 0. Thus Lipschitz continuity does not require differentiability.

Example 3 — The sine function

For f(x) = sin x on ℝ, the Mean Value Theorem gives, for some c between x and y,

| sin x − sin y | = | cos c | | x − y | ≤ | x − y |,

so Lip(f) = 1. The same argument works for cos.

Example 4 — A cubic on a bounded interval

This is our motivating example. For f(x) = x³ on [a, b] with 0 < a < b,

| x³ − y³ | ⁄ | x − y | = x² + xy + y² ≤ 3b²,

so Lip(x³, a, b) = 3b². On [1, 5] this is 75; on [2, 3] it is 27. On the whole of ℝ, however, x³ is not Lipschitz: the quotient x² + xy + y² is unbounded, so S is unbounded above.

Example 5 — Square root away from zero

For f(x) = √x on [1, ∞),

| √x − √y | = | x − y | ⁄ ( √x + √y ) ≤ ½ | x − y |,

so Lip(f) = ½. The bound comes from rationalising the numerator. On [0, 1], by contrast, the same function is not Lipschitz — see the next section.

Example 6 — A bounded derivative on an interval

Any function with a bounded derivative is Lipschitz. For instance f(x) = arctan x has f′(x) = 1 ⁄ (1 + x²), so |f′(x)| ≤ 1 and Lip(f) = 1 on ℝ.

4. Non-Examples

Non-Example 1 — x² on ℝ

Take f(x) = x². Then

| f(x) − f(0) | ⁄ | x − 0 | = | x | → ∞   as   x → ∞.

So S is unbounded above and f is not Lipschitz on ℝ. On any bounded interval [a, b], however, Lip(f, a, b) = |a| + |b|, since |x² − y²| = |x + y| |x − y| and |x + y| ≤ |a| + |b|.

Non-Example 2 — √x on [0, 1]

With y = 0 and x → 0⁺,

| √x − 0 | ⁄ | x − 0 | = 1 ⁄ √x → ∞.

So S(0, 1) is unbounded above and no finite K exists. This is important: √x is uniformly continuous on [0, 1] (it is continuous on a compact set), but it is not Lipschitz. Hence uniform continuity does not imply Lipschitz continuity.

Non-Example 3 — x^(1/3) on [−1, 1]

Near the origin the graph has a vertical tangent:

| x^(1/3) − 0 | ⁄ | x − 0 | = | x |^(−2/3) → ∞   as   x → 0.

Again uniformly continuous (compact domain), again not Lipschitz.

Non-Example 4 — sin(1/x) on (0, 1]

This function oscillates infinitely often near 0 with oscillations of fixed amplitude. It is not even uniformly continuous on (0, 1], so it certainly is not Lipschitz. Equivalently, it cannot be extended to a continuous function on [0, 1].

Non-Example 5 — A step function

Let

f(x) = 0 for x < 0,    f(x) = 1 for x ≥ 0.

Taking x = −1/n and y = 1/n gives a quotient of n/2, which is unbounded. In fact f is discontinuous, and (as we prove next) Lipschitz functions are always continuous.

5. Lipschitz ⟹ Uniformly Continuous ⟹ Continuous

Theorem

If f : A → ℝ is Lipschitz with constant K, then f is uniformly continuous on A.

Proof. Let ε > 0 be given. If K = 0, then f is constant and there is nothing to prove. Suppose K > 0 and choose

δ = ε ⁄ K.

Then for any x, y ∈ A with |x − y| < δ,

| f(x) − f(y) | ≤ K | x − y | < K · (ε ⁄ K) = ε.

Crucially, δ depends only on ε (and on the fixed constant K), not on the point x. Hence f is uniformly continuous. ∎

Since uniform continuity implies continuity, every Lipschitz function is continuous. We therefore have the chain

Lipschitz  ⟹  uniformly continuous  ⟹  continuous.

Neither arrow reverses.

  • √x on [0, 1] is uniformly continuous but not Lipschitz (Non-Example 2).
  • 1/x on (0, 1] is continuous but not uniformly continuous, hence not Lipschitz.

6. Bounded Derivative Implies Lipschitz

The single most useful tool for proving that a function is Lipschitz is the Mean Value Theorem.

Theorem

Let f : I → ℝ be differentiable on an interval I, and suppose there is a number M ≥ 0 with

| f′(x) | ≤ M    for all x ∈ I.

Then f is Lipschitz on I with Lip(f) ≤ M.

Proof. Let x, y ∈ I with x ≠ y. By the Mean Value Theorem there exists c strictly between x and y such that

( f(x) − f(y) ) ⁄ ( x − y ) = f′(c).

Taking absolute values,

| f(x) − f(y) | = | f′(c) | | x − y | ≤ M | x − y |.

So K = M is an admissible Lipschitz constant. ∎

The converse direction (when the derivative exists)

Suppose f is Lipschitz with constant K and is differentiable at a point x. Then for every h ≠ 0,

| ( f(x + h) − f(x) ) ⁄ h | ≤ K,

and letting h → 0 gives |f′(x)| ≤ K. So wherever the derivative exists, it is bounded by the Lipschitz constant.

Important caveat

A Lipschitz function need not be differentiable everywhere: f(x) = |x| is the standard example. Nevertheless, a deep theorem of Rademacher (1919) states that every Lipschitz function on ℝⁿ is differentiable almost everywhere with respect to Lebesgue measure. So the two notions are very close, but not identical.

Practical recipe for finding Lip(f, a, b)

  1. Derivative route. If f is differentiable, compute f′ and find M = LUB |f′| on [a, b]. Then K = M works, and often it is optimal.
  2. Algebraic route. Otherwise, simplify the quotient |f(x) − f(y)| ⁄ |x − y| (factor, rationalise, use triangle inequalities) and find its least upper bound directly.
  3. Check sharpness. Try to make the quotient approach your candidate K. If you can, no smaller constant works.

7. Local Lipschitz Continuity

A function f : A → ℝ is locally Lipschitz if every point x₀ ∈ A has a neighbourhood U such that the restriction f|U is Lipschitz. Equivalently, for each x₀ there is a δ > 0 and a constant K (both depending on x₀) with

| f(x) − f(y) | ≤ K | x − y |    whenever   x, y ∈ (x₀ − δ, x₀ + δ) ∩ A.

Local Lipschitz continuity is much weaker than global Lipschitz continuity, and it is what one usually meets in practice.

  • f(x) = x² is locally Lipschitz on ℝ but not globally Lipschitz there.
  • Any function with a continuous derivative on an open set is locally Lipschitz, because f′ is continuous and therefore bounded on compact subsets.
  • f(x) = √x on [0, ∞) is not locally Lipschitz at 0: no neighbourhood of 0 admits a finite Lipschitz bound.

8. Properties of Lipschitz Functions

  1. Closed under addition. If f and g are Lipschitz with constants K₁ and K₂, then f + g is Lipschitz with constant K₁ + K₂.
  2. Closed under scalar multiplication. If f is Lipschitz with constant K, then cf is Lipschitz with constant |c| K.
  3. Closed under composition. If f has constant K₁ and g has constant K₂, then g ∘ f has constant K₁ K₂.
  4. A Banach space. On a bounded set A, the Lipschitz functions form a Banach space under the norm
    ‖ f ‖Lip = LUBx ∈ A | f(x) | + Lip(f, A).
  5. Preservation of null sets. A Lipschitz function maps every set of Lebesgue measure zero to a set of measure zero. This makes Lipschitz maps well behaved in measure theory and integration.
  6. Uniqueness for ODEs. The Picard–Lindelöf theorem states that if f(t, y) is Lipschitz in y uniformly in t, then the initial value problem y′ = f(t, y), y(t₀) = y₀, has a unique solution near t₀. This is one of the most important applications of the concept.
  7. Robustness in applications. In machine learning and optimisation, the Lipschitz constant of a neural network bounds how much the output can change when the input is perturbed — the basis of certified robustness guarantees.

10. Conclusion

Lipschitz continuity is a strong, quantitative form of continuity: it says that a single number K controls how fast the function is allowed to change, everywhere and at every scale. It sits between “differentiable with bounded derivative” and “uniformly continuous” in the hierarchy of smoothness conditions, and it is exactly the right hypothesis in many theorems of analysis, differential equations and geometry.

The key takeaways:

  • The Lipschitz condition arises naturally from asking whether the set S = { |f(x) − f(y)| ⁄ |x − y| : x ≠ y } of secant slopes is bounded above; the answer, when it exists, is Lip(f, a, b) = LUB S.
  • Lipschitz  ⟹  uniformly continuous  ⟹  continuous, and no arrow reverses.
  • A bounded derivative implies Lipschitz continuity (Mean Value Theorem), and the bound K = LUB |f′| is usually the best one.
  • The Lipschitz constant need not be attained — it is a least upper bound of secant slopes, as the x³ example on [1, 5] shows, where K = 75 is approached but never reached.
  • For f(x) = x³ on [a, b] with 0 < a < b, the sharp constant is 3b² — it depends on the right endpoint only.
  • Lipschitz functions need not be differentiable (|x|), and uniformly continuous functions need not be Lipschitz (√x on [0, 1]).

Once you can look at a function and ask “is the set of its secant slopes bounded above?”, you have understood the heart of Lipschitz continuity.
