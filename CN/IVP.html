The Intermediate Value Property

When a function cannot jump over a value · Definition · Examples · Darboux · Integrals

1. Motivation: Skipping a Value

Think of the graph of a function as a path drawn on the plane. A natural question is whether the path can skip a horizontal level. If the graph starts below a line and later ends above it, must it cross the line at some point in between?

For a continuous function the answer is yes — this is the familiar Intermediate Value Theorem. But the interesting discovery is that continuity is not the only way to guarantee this crossing behaviour. Some very wild, discontinuous functions still manage to hit every intermediate value. The property of “never skipping a level” deserves its own name, because it can be studied independently of continuity.

The Question

Suppose f(a) < γ < f(b). Must there be a point c between a and b with f(c) = γ? What if we drop the assumption that f is continuous?

A first example of failure is a step function. Let f(x) = 0 for x < 0 and f(x) = 1 for x ≥ 0. On the interval [−1, 1] we have f(−1) = 0 and f(1) = 1, but the value γ = 0.5 is never attained. The function jumps over it. So the property can fail.

The plan of this article is to make the property precise, record the standard theorem that continuous functions have it, produce a discontinuous function that still has it, and then show two further sources of the property: differentiable functions (via Darboux's theorem) and Riemann integrable functions (via the continuity of the integral function).

2. Definition of the Intermediate Value Property

Let I be an interval and let f : I → ℝ.

Definition (Intermediate Value Property)

We say that f has the intermediate value property (IVP) on I if:

for all a, b ∈ I with a < b, and every γ strictly between f(a) and f(b), there exists c ∈ (a, b) with f(c) = γ.

Here “strictly between” means either f(a) < γ < f(b) or f(b) < γ < f(a). Functions with the IVP are sometimes called Darboux functions.

Equivalently: for every a < b in I, the image f((a, b)) contains every number between f(a) and f(b). In other words, the function cannot jump over a value that lies between two of its values.

IVP is not continuity

The IVP is a condition on the range of the function over intervals. It says nothing about how wildly the function may oscillate, and nothing about limits at a point. As we shall see, a function can have the IVP and still be discontinuous at some point.

3. Continuous Functions Have the IVP

Theorem (Intermediate Value Theorem)

If f is continuous on [a, b] and γ lies strictly between f(a) and f(b), then there exists c ∈ (a, b) with f(c) = γ. In particular, every continuous function has the IVP on every interval on which it is defined.

Proof. Assume f(a) < γ < f(b); the other case is handled by replacing f with −f. Consider the set

S = { x ∈ [a, b] : f(x) < γ }.

This set is nonempty, since a ∈ S, and it is bounded above by b. So S has a least upper bound; call it c. We claim that f(c) = γ.

  • Suppose f(c) < γ. Since f is continuous at c, there is δ > 0 such that |x − c| < δ implies f(x) < γ. Then points slightly to the right of c also lie in S, contradicting the fact that c is an upper bound for S.
  • Suppose f(c) > γ. Again by continuity, there is δ > 0 such that |x − c| < δ implies f(x) > γ. Then no point of (c − δ, c] belongs to S, so c − δ/2 is an upper bound for S smaller than c, contradicting the choice of c as the least upper bound.

The only remaining possibility is f(c) = γ. Finally, since f(a) < γ we have c > a, and since f(b) > γ we have c < b. Hence c ∈ (a, b). ∎

So continuity is a sufficient condition for the IVP. The natural next question is whether it is necessary. It is not.

4. A Discontinuous Function with the IVP

Consider the function defined on ℝ by

f(x) = sin(1/x)   for x ≠ 0,     f(0) = 0.

This function oscillates faster and faster as x approaches 0. Let us check the two claims: it is discontinuous at 0, and nevertheless it has the IVP on ℝ.

It is discontinuous at 0

For each positive integer n, set

xn = 1 ⁄ (π/2 + 2πn).

Then xn → 0, and

f(xn) = sin(π/2 + 2πn) = 1.

So f(xn) → 1, whereas f(0) = 0. The limit of f at 0 either does not exist or differs from the value f(0); either way, f is not continuous at 0.

It has the IVP on ℝ

Let a < b and let γ lie strictly between f(a) and f(b). We must find c ∈ (a, b) with f(c) = γ.

Case 1: 0 ∉ [a, b]. Then f is continuous on [a, b] (because sin(1/x) is continuous away from 0), so the IVT applies.

Case 2: 0 ∈ [a, b]. At least one of the open intervals (a, 0) or (0, b) is nonempty. Suppose, for instance, that b > 0, so that (0, b) ⊆ (a, b). As x runs over (0, b), the quantity 1/x runs over (1/b, ∞), an interval of infinite length. The sine function takes every value in [−1, 1] on any interval of length at least 2π, and (1/b, ∞) certainly contains such intervals. Hence

f((0, b)) = [−1, 1].

Now f(a) and f(b) both lie in [−1, 1], so any γ strictly between them also lies in [−1, 1]. Therefore γ = f(c) for some c ∈ (0, b) ⊆ (a, b). The same argument works if a < 0, using the interval (a, 0) instead.

Hence f has the IVP on ℝ, although it is discontinuous at 0. This shows that IVP does not imply continuity.

5. Derivatives Have the IVP: Darboux's Theorem

The next source of the IVP is differentiation. Even though a derivative need not be continuous, it can never jump over a value.

Theorem (Darboux, 1875)

Let f be differentiable on an open interval containing [a, b]. If γ lies strictly between f′(a) and f′(b), then there exists c ∈ (a, b) with f′(c) = γ. In other words, f′ has the intermediate value property on that interval.

Proof. Assume first that

f′(a) < γ < f′(b).

Define a new function g on [a, b] by

g(x) = f(x) − γx.

Since f is differentiable, it is continuous, so g is continuous on [a, b]. Its derivatives at the endpoints are

g′(a) = f′(a) − γ < 0,     g′(b) = f′(b) − γ > 0.

By the extreme value theorem, g attains a minimum at some point c ∈ [a, b]. We show that c is neither a nor b.

  • Why not a? Since g′(a) < 0,
    limh→0⁺ ( g(a + h) − g(a) ) ⁄ h < 0.
    So for all sufficiently small positive h we have g(a + h) < g(a). Hence a is not a minimum point.
  • Why not b? Since g′(b) > 0,
    limh→0⁻ ( g(b + h) − g(b) ) ⁄ h > 0.
    For all sufficiently small negative h, the quotient is positive; since h < 0, this forces g(b + h) < g(b). Hence b is not a minimum point.

Therefore c ∈ (a, b). Since g has an interior minimum at c and is differentiable there, we must have g′(c) = 0. Thus

f′(c) − γ = 0,    i.e.    f′(c) = γ.

The case f′(a) > γ > f′(b) follows by applying the argument above to −f (or equivalently, to −g). ∎

A derivative that is discontinuous but still has the IVP

Let

f(x) = x² sin(1/x)   for x ≠ 0,    f(0) = 0.

One checks that f is differentiable everywhere, with f′(0) = 0 and

f′(x) = 2x sin(1/x) − cos(1/x)   for x ≠ 0.

As x → 0, the term cos(1/x) oscillates between −1 and 1, so f′ has no limit at 0: the derivative is discontinuous there. Yet by Darboux's theorem, f′ has the IVP on every interval. This is a striking illustration that the IVP is strictly weaker than continuity.

6. Riemann Integrable Functions and the Continuity of F

Our final source of the IVP comes from integration. Given a Riemann integrable function f on [a, b], define its integral function by

F(x) = ∫ax f(t) dt,    x ∈ [a, b].

Even if f is very badly behaved — discontinuous at infinitely many points, for instance — as long as it is Riemann integrable, the function F turns out to be continuous.

Theorem (continuity of the integral function)

Let f be Riemann integrable on [a, b]. Then the function F(x) = ∫ax f(t) dt is continuous on [a, b]. Consequently, by the Intermediate Value Theorem, F has the IVP on [a, b].

Proof. Since f is Riemann integrable on [a, b], it is bounded there: there exists M ≥ 0 such that

| f(t) | ≤ M    for all t ∈ [a, b].

Let x, y ∈ [a, b] with x < y. By additivity of the integral,

F(y) − F(x) = ∫ay f(t) dt − ∫ax f(t) dt = ∫xy f(t) dt.

Taking absolute values and using the standard estimate for integrals,

| F(y) − F(x) | = | ∫xy f(t) dt | ≤ ∫xy | f(t) | dt ≤ M (y − x) = M | y − x |.

The case y < x is symmetric, and the case x = y is trivial. Hence

| F(y) − F(x) | ≤ M | y − x |    for all x, y ∈ [a, b].

Now let ε > 0. If M > 0, take δ = ε / M; if M = 0, then F is constant and any δ works. Then for x, y ∈ [a, b],

| x − y | < δ  ⟹  | F(y) − F(x) | ≤ M | y − x | < M · (ε / M) = ε.

So F is continuous on [a, b]. (The estimate actually shows that F is uniformly continuous there.) By the Intermediate Value Theorem, F has the IVP on [a, b]. ∎

Remarks

  • Continuity of F requires only that f be Riemann integrable — not that f be continuous. The boundedness of f, which is automatic for Riemann integrable functions, is what drives the proof.
  • If f happens to be continuous at a point x₀, then the Fundamental Theorem of Calculus gives the stronger conclusion that F is differentiable at x₀ with F′(x₀) = f(x₀). But continuity of F itself needs no such hypothesis.
  • The estimate |F(y) − F(x)| ≤ M|y − x| is exactly the kind of bound that guarantees uniform continuity. So the integral function is not merely continuous: it is uniformly continuous on [a, b].

7. Summary

Hypothesis on f Conclusion Name / Remark
Continuous on [a, b] f has the IVP on [a, b] Intermediate Value Theorem
Differentiable on an open interval containing [a, b] f′ has the IVP on [a, b] Darboux's Theorem (1875)
Riemann integrable on [a, b] F(x) = ∫ax f(t) dt is continuous, hence has the IVP Fundamental Theorem of Calculus, continuity part
Has the IVP on ℝ Does not imply continuity Example: sin(1/x) with f(0) = 0
Discontinuous at a point May still have the IVP Same example; also derivatives of differentiable functions

The logical relationships can be summarised in a single line:

continuous  ⟹  IVP,     differentiable  ⟹  derivative has IVP,     Riemann integrable  ⟹  integral function is continuous  ⟹  IVP,

and none of the arrows pointing towards the IVP can be reversed.

8. Conclusion

The intermediate value property captures a simple geometric idea: a function cannot skip over a horizontal level that lies between two of its values. Continuity is the most familiar way to guarantee this, but it is not the only way.

The key points of this article are:

  • Definition. f has the IVP on an interval I if, whenever a < b in I and γ lies between f(a) and f(b), there is c ∈ (a, b) with f(c) = γ.
  • Continuous ⟹ IVP. This is the Intermediate Value Theorem, proved by a least-upper-bound argument on the set {x : f(x) < γ}.
  • IVP does not imply continuous. The function f(x) = sin(1/x) for x ≠ 0, with f(0) = 0, is discontinuous at 0 yet attains every intermediate value on every interval.
  • Differentiable ⟹ derivative has IVP. This is Darboux's theorem. The proof applies the extreme value theorem to g(x) = f(x) − γx and shows that the minimum cannot occur at either endpoint.
  • Riemann integrable ⟹ integral function is continuous. Boundedness of f gives the estimate |F(y) − F(x)| ≤ M|y − x|, which yields continuity (indeed uniform continuity) of F. By the IVT, F then has the IVP.

Thus the intermediate value property sits at a curious crossroads: it is guaranteed by continuity, by differentiability (for the derivative), and by Riemann integrability (for the integral function), yet it is strictly weaker than continuity. Recognising this distinction is a first step towards the wilder corners of real analysis, where functions oscillate without limit yet still manage to respect the simple rule that no level between two values may be skipped.
