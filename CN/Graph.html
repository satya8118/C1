An Expository Guide to the Graph of a Function

In mathematics, the concept of a function establishes a rule of association between elements of two sets. However, to truly visualize and analyze the behavior of a function, we rely on its geometric representation: the graph.

1. Formal Definition

Definition: Graph of a Function (General Case)
Let \( f : X \to Y \) be a function. The graph \( G(f) \) of \( f \) is defined as the subset of the Cartesian product \( X \times Y \): \[ G(f) := \{(x, y) \in X \times Y : y = f(x)\} \]

When \( f \) is a real-valued function of a real variable, defined on a subset \( A \subseteq \mathbb{R} \), the definition specializes naturally to plane geometry:

Definition: Real Function Graph
Let \( f : A \subseteq \mathbb{R} \to \mathbb{R} \) be a function. The graph \( G(f) \) is given by: \[ G(f) = \{(a, f(a)) \in \mathbb{R}^2 : a \in A\} \] Thus, the graph of such a function is a geometric subset of the 2D Cartesian plane \(\mathbb{R}^2\).

2. Recognizing Graphs: The Vertical Line Test

Suppose we are given an arbitrary subset \( S \subseteq \mathbb{R}^2 \). Can we always find a subset \( X \subseteq \mathbb{R} \) and a function \( f : X \to \mathbb{R} \) such that \( S = G(f) \)?

The answer is no in general. A subset \( S \subseteq \mathbb{R}^2 \) represents the graph of a valid function if and only if every input \( x \) is mapped to at most one output \( y \).

The Vertical Line Test
A subset \( S \subseteq \mathbb{R}^2 \) is the graph of a function \( f : X \to \mathbb{R} \) (where \( X \) is the projection of \( S \) onto the x-axis) if and only if every vertical line in \(\mathbb{R}^2\) intersects \( S \) at at most one point.

Contrasting Examples: Circle vs. Upper Semi-Circle

  1. The Full Circle: The set \( S_1 = \{(x, y) \in \mathbb{R}^2 : x^2 + y^2 = 1\} \) is not the graph of any function. For any \( x \in (-1, 1) \), the vertical line passing through \( x \) intersects \( S_1 \) at two distinct points: \( y = \sqrt{1 - x^2} \) and \( y = -\sqrt{1 - x^2} \).
  2. The Upper Semi-Circle: The subset \( S_2 = \{(x, y) \in \mathbb{R}^2 : y \ge 0 \text{ and } x^2 + y^2 = 1\} \) is the graph of the function \( f : [-1, 1] \to \mathbb{R} \) defined by: \[ f(x) = \sqrt{1 - x^2} \] Every vertical line intersects this upper boundary at most once.
  3. The Sideways Absolute Value Curve: The equation \( x = |y| \) defines the set \( S_3 = \{(x, y) \in \mathbb{R}^2 : x = |y|\} \). This is not a graph of a function of \( x \) because for \( x > 0 \), both \( y = x \) and \( y = -x \) satisfy the relation (violating the vertical line test).

3. Key Examples of Function Graphs

Example 1: Linear Function
Let \( f : \mathbb{R} \to \mathbb{R} \) be defined by \( f(x) = 2x - 1 \). \[ G(f) = \{(x, 2x - 1) \in \mathbb{R}^2 : x \in \mathbb{R}\} \] Geometry: A straight line in \(\mathbb{R}^2\) with a slope of 2 and y-intercept at \((0, -1)\).
Example 2: Quadratic Function (Parabola)
Let \( f : \mathbb{R} \to \mathbb{R} \) be defined by \( f(x) = x^2 \). \[ G(f) = \{(x, x^2) \in \mathbb{R}^2 : x \in \mathbb{R}\} \] Geometry: A upward-opening parabola with its vertex at the origin \((0,0)\).
Example 3: Reciprocal Function (Hyperbola)
Let \( f : \mathbb{R} \setminus \{0\} \to \mathbb{R} \) be defined by \( f(x) = \frac{1}{x} \). \[ G(f) = \left\{\left(x, \frac{1}{x}\right) \in \mathbb{R}^2 : x \neq 0\right\} \] Geometry: A rectangular hyperbola with vertical asymptote at \( x = 0 \) and horizontal asymptote at \( y = 0 \).
Example 4: Discrete Domain Function
Let \( f : \{1, 2, 3\} \to \mathbb{R} \) be defined by \( f(x) = x^2 + 1 \). \[ G(f) = \{(1, 2), (2, 5), (3, 10)\} \] Geometry: A finite set of three discrete points in the Cartesian plane rather than a continuous curve.

4. The Horizontal Line Test: One-to-One (Injective) Functions

A function \( f : X \to Y \) is injective (or one-to-one) if distinct elements in the domain map to distinct elements in the codomain.

Horizontal Line Test for Injectivity
A function \( f : X \subseteq \mathbb{R} \to \mathbb{R} \) is one-to-one (injective) if and only if every horizontal line in \(\mathbb{R}^2\) intersects the graph \( G(f) \) at at most one point.
Example (One-to-One): \( f : \mathbb{R} \to \mathbb{R} \), \( f(x) = x^3 \)
Any horizontal line \( y = c \) intersects the graph at precisely one point \( (\sqrt[3]{c}, c) \). Thus, \( f \) is injective.
Non-Example (Not One-to-One): \( f : \mathbb{R} \to \mathbb{R} \), \( f(x) = x^2 \)
The horizontal line \( y = 4 \) intersects the graph at two distinct points: \((-2, 4)\) and \((2, 4)\). Because \( f(-2) = f(2) = 4 \), it fails injectivity.

5. The Horizontal Line Test: Onto (Surjective) Functions

A function \( f : X \to Y \) is surjective (or onto) if every element in the codomain \( Y \) is mapped to by at least one element in the domain \( X \) (i.e., Range = Codomain).

Horizontal Line Test for Surjectivity
A function \( f : X \subseteq \mathbb{R} \to Y \subseteq \mathbb{R} \) is onto (surjective) if and only if every horizontal line passing through any value \( y \in Y \) intersects the graph \( G(f) \) at at least one point.
Example (Onto): \( f : \mathbb{R} \to \mathbb{R} \), \( f(x) = x^3 - x \)
Because the polynomial extends continuously from \( -\infty \) to \( +\infty \), every horizontal line \( y = c \in \mathbb{R} \) intersects the graph at least once.
Non-Example (Not Onto): \( f : \mathbb{R} \to \mathbb{R} \), \( f(x) = x^2 \)
Any horizontal line below the x-axis (e.g., \( y = -1 \)) fails to intersect the graph. Since values in \( y < 0 \) are never attained, \( f \) is not onto over \( \mathbb{R} \).

6. Bijective Functions (One-to-One and Onto)

A function \( f : X \to Y \) is bijective (a complete one-to-one correspondence) if it is both injective and surjective.

Horizontal Line Test for Bijectivity
A function \( f : X \subseteq \mathbb{R} \to Y \subseteq \mathbb{R} \) is bijective if and only if every horizontal line corresponding to \( y \in Y \) intersects the graph \( G(f) \) at exactly one point.
Example (Bijective): \( f : \mathbb{R} \to \mathbb{R} \), \( f(x) = 2x + 3 \)
Every horizontal line \( y = c \) intersects the line at exactly one point \( \left(\frac{c-3}{2}, c\right) \), satisfying both injectivity (at most 1) and surjectivity (at least 1).
Non-Example (Not Bijective): \( f : \mathbb{R} \to \mathbb{R} \), \( f(x) = x^3 - x \)
While surjective over \( \mathbb{R} \), the horizontal line \( y = 0 \) intersects the graph at three points (\( x = -1, 0, 1 \)), violating injectivity and preventing bijectivity.
