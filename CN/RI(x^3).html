General Setup & Formulas

  • Function: f(x) = x³ on x ∈ [0, 6], partitioned into n equal subintervals.
  • Subinterval width: Δx = (6 − 0)/n = 6/n
  • Partition points: xᵢ = i·Δx = 6i/n,   i = 0, 1, …, n
  • Since f(x) = x³ is strictly increasing on [0, 6]:
       minimum in i-th subinterval: mᵢ = f(xᵢ₋₁) = ( 6(i−1)/n )³
       maximum in i-th subinterval: Mᵢ = f(xᵢ)   = ( 6i/n )³
  • Lower sum: L(f,P) = Σᵢ₌₁ⁿ mᵢ Δx = Σᵢ₌₁ⁿ ( 6(i−1)/n )³ · (6/n)
  • Upper sum: U(f,P) = Σᵢ₌₁ⁿ Mᵢ Δx = Σᵢ₌₁ⁿ ( 6i/n )³ · (6/n)
  • Difference: U − L = Σᵢ₌₁ⁿ (Mᵢ − mᵢ)Δx = ( f(6) − f(0) )·Δx = 216 · (6/n) = 1296/n
  • Closed forms: L = 324(n−1)²/n²,   U = 324(n+1)²/n²,   both → 324 as n → ∞.
