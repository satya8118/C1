Thomae's Function

An extraordinary real analysis function that is continuous at every irrational number, yet discontinuous at every rational number.

📌 Formal Definition

Define the function $f : \mathbb{R} \to \mathbb{R}$ by:

$$f(x) := \begin{cases} \dfrac{1}{q} & \text{if } x = \dfrac{p}{q} \in \mathbb{Q} \text{ in lowest terms } (\gcd(|p|, q) = 1, \, q > 0), \\[10pt] 0 & \text{if } x \notin \mathbb{Q} \text{ (irrational)}. \end{cases}$$
💡 Quick Examples to Build Intuition:
  • At $x = 0$: Write $0 = \frac{0}{1}$, so $q = 1 \implies f(0) = \frac{1}{1} = 1$.
  • At $x = \frac{1}{2}$: Denominator is $2 \implies f(\frac{1}{2}) = \frac{1}{2}$.
  • At $x = \frac{2}{3}$: Denominator is $3 \implies f(\frac{2}{3}) = \frac{1}{3}$.
  • At $x = \sqrt{2}$: Irrational number $\implies f(\sqrt{2}) = 0$.
🏆 The Fundamental Theorem

Thomae's function $f$ exhibits a striking asymmetry:

$$\text{Set of Continuity Points of } f = \mathbb{R} \setminus \mathbb{Q} \quad \text{(All Irrationals)}$$

It is discontinuous at every rational point and continuous at every irrational point.

📊 Visualizing the Function
Graph Concept: Rationals form isolated "spikes" of height $\frac{1}{q}$. As the denominator $q$ increases, these spikes become infinitely short and drop down toward $0$. Irrationals lie completely flat along the x-axis at $y = 0$.
⚡ Part 1 — Discontinuity at Every Rational Point
Intuitive Discovery (Rough Work): Take any rational number $a = \frac{p}{q}$. Here, the function value is $f(a) = \frac{1}{q} > 0$. However, no matter how close you zoom into $a$, you will always find irrational numbers arbitrarily close to it (since irrationals are dense in $\mathbb{R}$). At these nearby irrationals, $f(x) = 0$. Thus, the function continuously "jumps" between $0$ and $\frac{1}{q}$, preventing a limit from matching $f(a)$.
Formal Proof (Sequential Criterion) Let $a = \dfrac{p}{q} \in \mathbb{Q}$ in lowest terms, so $f(a) = \dfrac{1}{q} > 0$.

By the density of irrational numbers in $\mathbb{R}$, there exists a sequence of irrationals $(x_n)_{n=1}^\infty$ such that $x_n \to a$ as $n \to \infty$.

Since each $x_n \notin \mathbb{Q}$, we have $f(x_n) = 0$ for all $n \in \mathbb{N}$. Taking the limit: $$\lim_{n \to \infty} f(x_n) = \lim_{n \to \infty} 0 = 0$$ Since $\lim_{n \to \infty} f(x_n) = 0 \neq \dfrac{1}{q} = f(a)$, $f$ fails the sequential criterion for continuity.
Therefore, $f$ is discontinuous at every rational point $a$. $\blacksquare$
✨ Part 2 — Continuity at Every Irrational Point
The Key Finite-Set Argument: At an irrational $a$, we have $f(a) = 0$. To prove continuity, we need $f(x)$ to stay less than a small target $\varepsilon > 0$ when $x$ is near $a$.

• If $x$ is irrational, $f(x) = 0 < \varepsilon$ automatically.
• If $x = \frac{p}{q}$ is rational, $f(x) = \frac{1}{q}$. For $\frac{1}{q} \ge \varepsilon$, the denominator $q$ must be small ($q \le \frac{1}{\varepsilon}$).

Crucial Insight: In any bounded neighborhood around $a$, there are only finitely many rational fractions with small denominators $q \le \frac{1}{\varepsilon}$! Since $a$ is irrational, it is distinct from all of them. We can simply pick a small neighborhood $\delta$ that avoids these few "tall spikes"!
By choosing $\delta$ smaller than the distance to the nearest "tall spike", every rational inside $(a-\delta, a+\delta)$ will have a large denominator ($q > \frac{1}{\varepsilon}$), making $f(x) = \frac{1}{q} < \varepsilon$.
Formal Proof ($\varepsilon$-$\delta$ Definition) Let $a \in \mathbb{R} \setminus \mathbb{Q}$ be an irrational point, so $f(a) = 0$. Let $\varepsilon > 0$ be given.

Step 1: Isolate problematic rationals.
Define the set of rationals in $[a-1, a+1]$ whose function values are at least $\varepsilon$: $$S_\varepsilon := \left\{ \frac{p}{q} \in \mathbb{Q} \cap [a-1, a+1] : \gcd(|p|, q) = 1, \, q > 0, \, q \le \frac{1}{\varepsilon} \right\}$$ Step 2: Show $S_\varepsilon$ is a finite set.
For each integer denominator $q \in \{1, 2, \ldots, \lfloor 1/\varepsilon \rfloor\}$, there are only finitely many numerators $p$ such that $\frac{p}{q} \in [a-1, a+1]$. Thus, $S_\varepsilon$ is a finite set.

Step 3: Construct $\delta > 0$.
Since $a$ is irrational, $a \notin S_\varepsilon$. Because $S_\varepsilon$ is finite, the minimum distance from $a$ to any point in $S_\varepsilon$ is strictly positive: $$\delta := \min \left\{ |a - r| : r \in S_\varepsilon \right\} > 0$$ (If $S_\varepsilon = \emptyset$, simply set $\delta = 1$.)

Step 4: Verify the condition.
Take any $x \in \mathbb{R}$ with $|x - a| < \delta$:
  • If $x$ is irrational: $f(x) = 0$, so $|f(x) - f(a)| = |0 - 0| = 0 < \varepsilon$.
  • If $x = \frac{p}{q}$ is rational: Since $|x - a| < \delta$, $x$ cannot belong to $S_\varepsilon$. Furthermore, $x \in [a-1, a+1]$. Therefore, its denominator must satisfy $q > \frac{1}{\varepsilon}$, which implies: $$|f(x) - f(a)| = \frac{1}{q} < \varepsilon$$
In all cases, $|f(x) - f(a)| < \varepsilon$, proving that $f$ is continuous at $a$. $\blacksquare$

🎓 Advanced Mathematical Insights
  1. Density & Continuity Asymmetry: Thomae's function serves as a classic counterexample showing that a function can be continuous on an uncountable dense set ($\mathbb{R} \setminus \mathbb{Q}$) while being discontinuous on a countable dense set ($\mathbb{Q}$).
  2. Riemann Integrability: Even though it is discontinuous at infinitely many points (all rationals), Thomae's function is Riemann integrable on any interval $[a, b]$, and its integral is equal to $0$. This is because the set of discontinuities ($\mathbb{Q}$) has measure zero.
  3. Baire Category Theorem Connection: Is there a function that is continuous only on $\mathbb{Q}$ and discontinuous on $\mathbb{R} \setminus \mathbb{Q}$? No! By Baire's Theorem, the set of continuity points of any real-valued function must be a $G_\delta$ set (an intersection of countably many open sets). The set $\mathbb{R} \setminus \mathbb{Q}$ is a $G_\delta$ set, but $\mathbb{Q}$ is not.
