First, a game you already know

Before ε and δ, take a statement everyone accepts: for every real number x there is a natural number n with n > x. Read it as a game with two players. Try it.

Why does the definition say 0 < |x − a|?

Here g(x) = x + 1 for every x except x = 1, but g(1) = 5. Launches near 1 land near 2, so the limit at 1 should be 2. The odd value at x = 1 is only one launch position. Test it: keep a window that clearly works, then tick the box that makes the test include x = a.

When no δ exists

Now a launcher that jumps: launches left of a = 2 land at height 1, launches from 2 onward land at height 3. Someone claims the limit is L. Drag L and ε and see whether you can ever win against a small ε.
