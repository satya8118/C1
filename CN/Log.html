Intermediate Value Property, Logarithm, and Exponential Functions

Part 1: Intermediate Value Property (IVP)

Definition (IVP): Let \(I\) be an interval and \(f: I \to \mathbb{R}\). We say that \(f\) has the Intermediate Value Property if whenever \(f(a) < L < f(b)\) for some \(a, b \in I\), there exists an \(\alpha\) between \(a\) and \(b\) such that \(f(\alpha) = L\).

Theorem: Let \(I\) be an interval and \(f: I \to \mathbb{R}\) be a function that is Riemann integrable on every compact subinterval of \(I\). Let \(a \in I\) and define \(F(x) = \int_a^x f(t) dt\) for \(x \in I\). Then \(F\) has the Intermediate Value Property.

Let \(u, v \in I\) with \(u < v\). It is enough to show that \(F\) is continuous on \(I\), because then the standard Intermediate Value Theorem for continuous functions guarantees the desired property.

Fix \(x_0 \in I\). Choose a compact interval \(J \subseteq I\) containing \(x_0\). Since \(f\) is Riemann integrable on \(J\), it is bounded on \(J\). Thus, there exists a constant \(M > 0\) such that \(|f(t)| \le M\) for all \(t \in J\).

For any \(x \in J\), we have:

\[ |F(x) - F(x_0)| = \left| \int_{x_0}^x f(t) dt \right| \le \int_{x_0}^x |f(t)| dt \le M|x - x_0| \]

Let \(\epsilon > 0\). Choose \(\delta = \epsilon / M\). Then for any \(x \in J\) with \(|x - x_0| < \delta\), we have \(|F(x) - F(x_0)| \le M|x - x_0| < M(\epsilon/M) = \epsilon\). Thus, \(F\) is continuous at \(x_0\).

Since \(x_0 \in I\) was arbitrary, \(F\) is continuous on \(I\).

Now let \(u, v \in I\) and suppose \(L\) lies strictly between \(F(u)\) and \(F(v)\). Since \(F\) is continuous on the interval \([u, v]\), the Intermediate Value Theorem applies and gives some \(\alpha\) between \(u\) and \(v\) such that \(F(\alpha) = L\).

Hence \(F\) has the Intermediate Value Property. \(\square\)

Part 2: Logarithm and Exponential Functions

Definition of the Natural Logarithm

Consider the function \(f(x) = 1/x\) on \((0, \infty)\). It is monotone and hence integrable on every \([a, b] \subset (0, \infty)\). We use this observation to define the natural logarithm function by

\[ \log(x) = \int_1^x \frac{1}{t} dt \quad (x > 0) \]

By definition, \(\log(1) = 0\).

This definition gives \(\log : (0, \infty) \to \mathbb{R}\). The choice of lower limit \(1\) ensures \(\log(1)=0\), which is the natural starting point.

💡 Intuition: The logarithm of \(x\) is the signed area under the hyperbola \(y = \frac{1}{t}\) from \(t=1\) to \(t=x\). If \(x > 1\), the area is positive. If \(0 < x < 1\), the integral runs from \(1\) down to \(x\), so the area is negative.
🔎 Why is \(\log(x) < 0\) when \(0 < x < 1\)?

Direct proof from the integral:

\[ \log(x) = \int_{1}^{x} \frac{dt}{t} = -\int_{x}^{1} \frac{dt}{t} \]

For \(0 < x < 1\), the integrand \(\frac{1}{t}\) is positive on \([x, 1]\). Hence \(\int_{x}^{1} \frac{dt}{t} > 0\), so \(\log(x) = -(\text{positive}) < 0\).

Alternatively, using the quotient property (proved in Theorem 2.3.1 below): since \(\log(1) = \log(x \cdot \frac{1}{x}) = \log(x) + \log(\frac{1}{x})\), we have \(\log(x) = -\log(\frac{1}{x})\). If \(0 < x < 1\), then \(\frac{1}{x} > 1\). Because \(\log\) is strictly increasing (proved in Theorem 2.3.2 below) and \(\log(1)=0\), we get \(\log(\frac{1}{x}) > 0\), so \(\log(x) = -(\text{positive}) < 0\).

Theorem 2.3.1 (Algebraic Properties)

Let \(a, b > 0\). Then:

  1. \(\log(ab) = \log a + \log b\)
  2. \(\log(a/b) = \log a - \log b\)
  3. \(\log(a^m) = m \log a\) for any \(m \in \mathbb{Z}\)

1. Product Rule: We use the property of scaling of interval of integration:

\[ \log(ab) = \int_1^{ab} \frac{1}{t} dt = \int_1^a \frac{1}{t} dt + \int_a^{ab} \frac{1}{t} dt = \log a + \int_a^{ab} \frac{1}{t} dt \]

For the second integral, we use the scaling property \(\int_{\alpha}^{\beta} f(t) dt = \int_{k\alpha}^{k\beta} f(t/k) dt\). Let \(t = au\), so \(dt = a du\). The limits change from \(a \to ab\) to \(1 \to b\).

\[ \int_a^{ab} \frac{1}{t} dt = \int_1^b \frac{1}{au} (a du) = \int_1^b \frac{1}{u} du = \log b \]

Therefore, \(\log(ab) = \log a + \log b\).

2. Quotient Rule: Using the product rule, we have:

\[ \log(a/b) + \log b = \log\left(\frac{a}{b} \cdot b\right) = \log a \]

Subtracting \(\log b\) from both sides gives \(\log(a/b) = \log a - \log b\).

3. Power Rule:

  • If \(m = 0\), both sides are \(0\) since \(\log(1) = 0\).
  • For any \(m \in \mathbb{N}\) (positive integers), we use induction via the product rule: \[ \log(a^m) = \log(a \cdots a) = \log a + \cdots + \log a = m \log a \]
  • For negative integers, let \(m = -k\) where \(k \in \mathbb{N}\): \[ \log(a^{-m}) = \log(1/a^m) = \log 1 - \log(a^m) = 0 - m\log a = -m\log a \]

Thus, the property holds for all \(m \in \mathbb{Z}\).

Theorem 2.3.2 (Analytical Properties)

The function \(\log: (0, \infty) \to \mathbb{R}\) is a strictly increasing bijection.

Strictly Increasing: Let \(b > a > 0\). Then:

\[ \log b - \log a = \int_1^b \frac{1}{t} dt - \int_1^a \frac{1}{t} dt = \int_a^b \frac{1}{t} dt \]

Since \(1/t > 0\) on \((a, b)\), the integral \(\int_a^b \frac{1}{t} dt > 0\). Thus, \(\log b > \log a\). This also proves the function is one-to-one (injective).

Surjective (Onto): We must show that for any \(y \in \mathbb{R}\), there exists an \(x > 0\) such that \(\log x = y\).

  • Case 1: \(y > 0\). We know \(\log 2 > \log 1 = 0\). By the Archimedean property, there exists \(N \in \mathbb{N}\) such that \(y < N \log 2 = \log(2^N)\). Since \(\log 1 = 0 < y < \log(2^N)\), and the indefinite integral of a monotone function has the Intermediate Value Property (as proven in Part 1 above), there exists \(x \in (1, 2^N)\) such that \(\log x = y\).
  • Case 2: \(y < 0\). There exists \(x > 0\) such that \(\log x = -y > 0\) (from Case 1). Then \(\log(1/x) = -\log x = y\). So \(x' = 1/x\) works.
  • Case 3: \(y = 0\). \(x = 1\) works.

Hence, the function is onto. Since \(\log\) is strictly increasing and onto, it is a bijection.

Definition of the Exponential Function

Since \(\log: (0, \infty) \to \mathbb{R}\) is a strictly increasing bijection, it has an inverse function. We define the exponential function \(\exp: \mathbb{R} \to (0, \infty)\) by:

\[ y = \exp x \iff \log y = x \]

Since \(\log\) is strictly increasing, its inverse \(\exp\) is also strictly increasing.

Theorem 2.3.3 (Exponential Properties)

Let \(a, b \in \mathbb{R}\). Then:

  1. \(\exp(a+b) = \exp a \exp b\)
  2. \(\exp(a-b) = \frac{\exp a}{\exp b}\)
  3. \(\exp(ma) = (\exp a)^m\) for \(m \in \mathbb{Z}\)

Since \(\log\) is a one-to-one function, we can prove these identities by applying \(\log\) to both sides and observing that the resulting values are equal.

1. Product Rule:

\[ \log(\exp(a+b)) = a+b \] \[ \log(\exp a \exp b) = \log(\exp a) + \log(\exp b) = a + b \]

Since the logarithms are equal, the arguments must be equal: \(\exp(a+b) = \exp a \exp b\).

2. Quotient Rule:

\[ \log(\exp(a-b)) = a-b \] \[ \log\left(\frac{\exp a}{\exp b}\right) = \log(\exp a) - \log(\exp b) = a - b \]

Therefore, \(\exp(a-b) = \frac{\exp a}{\exp b}\).

3. Power Rule:

\[ \log(\exp(ma)) = ma \] \[ \log((\exp a)^m) = m \log(\exp a) = ma \]

Therefore, \(\exp(ma) = (\exp a)^m\).

🔗 Key takeaway: The natural logarithm is the unique continuous function satisfying \(\log(1)=0\), \(\log(ab)=\log a+\log b\), and whose derivative is \(1/x\). Its inverse is the exponential function \(e^x\).
