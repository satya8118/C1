Continuity on Isolated Domains

Discover why every single function defined on $J = \bigl\{\tfrac{1}{n} : n \in \mathbb{N}\bigr\}$ is automatically continuous.

📌 Theorem Statement

Let $J = \bigl\{\tfrac{1}{n} : n \in \mathbb{N}\bigr\} = \bigl\{1, \tfrac{1}{2}, \tfrac{1}{3}, \tfrac{1}{4}, \ldots\bigr\}$. Let $f : J \to \mathbb{R}$ be any function whatsoever.

Then $f$ is continuous at every point of $J$.

💡 Intuition & The Isolation Radius
The Key Observation: Every Point is Isolated Fix any point $a = \tfrac{1}{k} \in J$. The points of $J$ nearest to $a$ are $\tfrac{1}{k-1}$ (if $k \ge 2$) and $\tfrac{1}{k+1}$.

The distance to the closer neighbor $\tfrac{1}{k+1}$ defines an isolation radius: $$\delta_0 := \tfrac{1}{k} - \tfrac{1}{k+1} = \tfrac{1}{k(k+1)} > 0$$ By choosing a neighborhood radius $\delta \le \delta_0$, the only point of $J$ residing inside $(a-\delta, a+\delta)$ is $a$ itself!

When $x \in J$ and $|x-a| < \delta$, the condition forces $x = a$. Consequently: $$|f(x) - f(a)| = |f(a) - f(a)| = 0 < \varepsilon$$ holds vacuously for any $\varepsilon > 0$, regardless of how wild $f$ is!
Around $a = \tfrac{1}{3}$, the nearest neighbors are $\tfrac{1}{2}$ (distance $\tfrac{1}{6}$) and $\tfrac{1}{4}$ (distance $\tfrac{1}{12}$). Choosing $\delta \le \tfrac{1}{12}$ leaves $\tfrac{1}{3}$ as the single isolated point inside the window.
📜 Formal $\varepsilon$-$\delta$ Proof
Proof Fix any $a = \tfrac{1}{k} \in J$ (where $k \in \mathbb{N}$) and any $\varepsilon > 0$. We must find $\delta > 0$ such that: $$x \in J, \, |x - a| < \delta \implies |f(x) - f(a)| < \varepsilon$$ Step 1: Compute isolation radii.
The adjacent points to $\tfrac{1}{k}$ in $J$ are $\tfrac{1}{k+1}$ and $\tfrac{1}{k-1}$ (for $k \ge 2$). Their distances from $a$ are: $$\tfrac{1}{k} - \tfrac{1}{k+1} = \tfrac{1}{k(k+1)}, \qquad \tfrac{1}{k-1} - \tfrac{1}{k} = \tfrac{1}{k(k-1)}$$ Because $k(k+1) > k(k-1)$, the closer neighboring point is always $\tfrac{1}{k+1}$. Define: $$\delta_0 := \tfrac{1}{k(k+1)} > 0$$ (For $k=1$, the only neighboring point is $\tfrac{1}{2}$, so set $\delta_0 = \tfrac{1}{2}$.\/

Step 2: Choose $\delta$ and verify.
Set $\delta := \delta_0$. If $x \in J$ satisfies $|x - a| < \delta$, then because $\delta$ is strictly smaller than the distance from $a$ to any other point in $J$, we must have $x = a$.

Therefore: $$|f(x) - f(a)| = |f(a) - f(a)| = 0 < \varepsilon$$ Since $\varepsilon > 0$ was arbitrary, $f$ is continuous at $a$. Since $a \in J$ was arbitrary, $f$ is continuous on all of $J$. $\blacksquare$

Note: As $k \to \infty$, $\delta_0 \to 0$. Points closer to $0$ require progressively smaller neighborhoods, but a strictly positive $\delta_0$ exists for every individual point $a \in J$.

🎓 Conceptual Insights & Sequential Perspective
Sequential Definition Agreement: The sequential definition states that $f$ is continuous at $a$ if $x_n \to a \implies f(x_n) \to f(a)$ for any sequence $(x_n) \subseteq J$.

Because $a = \tfrac{1}{k}$ is isolated, any sequence in $J$ converging to $a$ must be eventually constant ($x_n = a$ for all sufficiently large $n$). For such sequences, $f(x_n) = f(a)$ eventually, making $f(x_n) \to f(a)$ trivial!
Crucial Contrast: The Point $0$ is NOT in $J$

Although $\tfrac{1}{n} \to 0$, $0 \notin J$. If we extended the domain to $\tilde{J} = J \cup \{0\}$, then $0$ would be a limit point (not isolated). Continuity at $0$ would require: $$\lim_{n \to \infty} f\left(\tfrac{1}{n}\right) = f(0)$$ This imposes a strict condition on $f(0)$. On $J$ alone, no limit points exist, so continuity holds vacuously everywhere.
