Monotonicity of Continuous & Injective Functions

A fundamental theorem in real analysis: Any continuous and one-to-one function defined on an interval must be strictly monotone.

📌 Theorem Statement

Let $J \subseteq \mathbb{R}$ be an interval and $f : J \to \mathbb{R}$ be continuous and one-to-one (injective). Then $f$ is strictly monotone: either $f$ is strictly increasing on $J$, or $f$ is strictly decreasing on $J$.

💡 Strategy & Proof Intuition
Proof Strategy (Contradiction via Intermediate Value Theorem): Suppose $f$ is not monotone. Then it is neither strictly increasing nor strictly decreasing:
  • Not strictly increasing: There exist $a_1 < a_2$ in $J$ with $f(a_1) > f(a_2)$ (strict inequality due to injectivity). Call this the decreasing pair.
  • Not strictly decreasing: There exist $b_1 < b_2$ in $J$ with $f(b_1) < f(b_2)$ (strict inequality due to injectivity). Call this the increasing pair.
By analyzing the possible geometric relative positions of $\{a_1, a_2\}$ and $\{b_1, b_2\}$ on the interval $J$, applying the Intermediate Value Theorem (IVT) forces $f$ to produce the same value $k$ at two distinct points—directly contradicting injectivity.
📊 The Geometric Configurations
Overview of Configurations: Regardless of how the four points are ordered on $J$, the Intermediate Value Theorem guarantees the existence of two distinct points $u \neq v$ where $f(u) = f(v)$, contradicting one-to-one behavior.
🔑 Key Lemma

Let $f: J \to \mathbb{R}$ be continuous and one-to-one on an interval $J$. If $p < q$ in $J$ and $f(p) < f(q)$, then:

$$f(x) < f(q) \quad \text{for all } x \in [p, q]$$

Geometric Interpretation: A continuous injective function cannot "go up and then come back down" (or vice versa) between any two points.

📜 Streamlined Complete Proof
Proof (By Contradiction) Suppose $f$ is not monotone on $J$. Then $f$ is neither strictly increasing nor strictly decreasing.

1. Extracting the Two Pairs:
  • Since $f$ is not strictly increasing, there exist $a_1 < a_2$ in $J$ with $f(a_1) > f(a_2)$ (strict inequality because $f$ is one-to-one). Call this the decreasing pair.
  • Since $f$ is not strictly decreasing, there exist $b_1 < b_2$ in $J$ with $f(b_1) < f(b_2)$ (strict inequality because $f$ is one-to-one). Call this the increasing pair.
2. Choosing the Target Value $k$:
Since $f(a_2) < f(a_1)$ and $f(b_1) < f(b_2)$, the open interval $$\left(\max\{f(a_2), f(b_1)\}, \, \min\{f(a_1), f(b_2)\}\right)$$ is non-empty. Select a value $k$ from this interval so that: $$f(a_2) < k < f(a_1) \quad \text{and} \quad f(b_1) < k < f(b_2)$$ 3. Applying the Intermediate Value Theorem (IVT):
By IVT applied to continuous $f$ on $[a_1, a_2]$, there exists $u \in (a_1, a_2)$ such that $f(u) = k$.
By IVT applied to continuous $f$ on $[b_1, b_2]$, there exists $v \in (b_1, b_2)$ such that $f(v) = k$.

4. Verifying $u \neq v$:
  • Disjoint Intervals: If $[a_1, a_2] \cap [b_1, b_2] = \emptyset$, then $u \in (a_1, a_2)$ and $v \in (b_1, b_2)$ immediately implies $u \neq v$.
  • Overlapping Intervals: Suppose $[a_1, a_2]$ and $[b_1, b_2]$ overlap (e.g., $a_1 < b_1 < a_2 < b_2$). Note that $a_2 \in [b_1, b_2]$ and $f(a_2) < k < f(b_2)$. Applying the IVT separately on $[a_1, a_2]$ yields $u \in (a_1, a_2)$ with $f(u) = k$, and on $[a_2, b_2]$ yields $v \in (a_2, b_2)$ with $f(v) = k$. Thus $u < a_2 < v$, which guarantees $u \neq v$.
5. Conclusion:
In all cases, we obtain two distinct points $u \neq v$ in $J$ such that $f(u) = f(v) = k$, contradicting the assumption that $f$ is one-to-one. Therefore, $f$ must be strictly monotone on $J$. $\blacksquare$
🎓 Corollary & Crucial Counterexample
Corollary: Continuity of the Inverse Function Let $J$ be an interval and $f : J \to \mathbb{R}$ be continuous and one-to-one.
  • The image $f(J)$ is an interval (by IVT).
  • The inverse function $f^{-1} : f(J) \to J$ exists and is strictly monotone.
  • $f^{-1}$ is continuous on the interval $f(J)$.

Why the "Interval" Domain Assumption is Essential:

The theorem fails if $J$ is not an interval. For instance, consider the discrete domain $J = \{1, 2, 3, 4\}$ and define:

$$f(1) = 1, \quad f(2) = 3, \quad f(3) = 2, \quad f(4) = 4$$

This function is strictly one-to-one and trivially continuous (since every function defined on a discrete domain is continuous), yet it is not monotone ($1 < 3 > 2 < 4$). The interval structure is indispensable because it enables the use of the Intermediate Value Theorem.
