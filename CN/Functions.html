1. Linear Functions & Proportionality

A function of the form $f(x) = mx + b$, for constants $m$ and $b$, is called a linear function. The function $f(x) = x$ (where $m = 1$ and $b = 0$) is called the identity function. Constant functions result when the slope $m = 0$.

Definition: Two variables $y$ and $x$ are proportional (to one another) if one is always a constant multiple of the other; that is, if $y = kx$ for some nonzero constant $k$.

Figure 1.14(a): Lines through the origin

Visualizing how the slope $m$ dictates the steepness and direction (positive/negative) of the line $f(x) = mx$.

\(f(x) = mx\)

1. Linear Functions: Constant Function

When $m = 0$, $f(x) = b$ is a constant function, representing a horizontal line with zero slope.

Figure 1.14(b): Constant Function

When the slope $m = 0$, the function stays fixed at $y = b$ regardless of $x$.

\(f(x) = 1.5\)

2. Power Functions: Positive Integer Powers

A function $f(x) = x^a$, where $a$ is a constant, is called a power function. When $a = n$ is a positive integer, domain is $(-\infty, \infty)$. Even powers are symmetric about the y-axis; odd powers are symmetric about the origin.

Figure 1.15: Positive Integer Powers

Notice how the functions flatten on the interval $(-1, 1)$ and rise more steeply for $|x| > 1$ as $n$ grows.

\(f(x) = x^n\) (\(n = 1, 2, 3, 4, 5\))

2. Power Functions: Negative Powers

For negative integers $a = -1, -2$, $f(x) = x^{-n} = \frac{1}{x^n}$. The domain excludes $x = 0$. These curves approach the coordinate axes as asymptotes.

Figure 1.16: Negative Powers (Reciprocals)

\(y = 1/x\) is a hyperbola symmetric about the origin. \(y = 1/x^2\) is symmetric about the y-axis.

\(f(x) = 1/x\) and \(f(x) = 1/x^2\)

2. Power Functions: Square Root

Figure 1.17(a): $y = \sqrt{x}$

Square root function $f(x) = x^{1/2}$.

Domain: $[0, \infty)$

Range: $[0, \infty)$

\(f(x) = \sqrt{x}\)

2. Power Functions: Cube Root

Figure 1.17(b): $y = \sqrt[3]{x}$

Cube root function $f(x) = x^{1/3}$.

Domain: $(-\infty, \infty)$

Range: $(-\infty, \infty)$

Symmetric about the origin, smoothly defined over all real numbers.

\(f(x) = \sqrt[3]{x}\)

2. Power Functions: Fractional Power $3/2$

Figure 1.17(c): $y = x^{3/2}$

Fractional exponent $f(x) = (\sqrt{x})^3$.

Domain: $[0, \infty)$

Grows faster than the linear function for $x > 1$.

\(f(x) = x^{3/2}\)

2. Power Functions: Fractional Power $2/3$

Figure 1.17(d): $y = x^{2/3}$

Fractional exponent $f(x) = (\sqrt[3]{x})^2$.

Domain: $(-\infty, \infty)$

Symmetric about the y-axis, forming a cusp at the origin $(0,0)$.

\(f(x) = x^{2/3}\)

3. Polynomial Functions: Cubic

A function $p$ is a polynomial if $p(x) = a_nx^n + a_{n-1}x^{n-1} + \dots + a_1x + a_0$. Domain is $(-\infty, \infty)$.

$$y = \frac{x^3}{3} - \frac{x^2}{2} - 2x + \frac{1}{3}$$

4. Rational Functions: Oblique Asymptote

A rational function is a ratio $f(x) = p(x)/q(x)$, where $p$ and $q$ are polynomials. Domain excludes roots of $q(x)$.

Figure 1.19(a)

Linear over linear structure with a vertical asymptote at $x = -4/7$.

$$y = \frac{2x^2 - 3}{7x + 4}$$

Rational Function (a)

4. Rational Functions: Horizontal Asymptote

Figure 1.19(b)

Equal degree numerator and denominator. Horizontal asymptote shown in red at $y = 5/3$.

$$y = \frac{5x^2 + 8x - 3}{3x^2 + 2}$$

Rational Function with $y = 5/3$

4. Rational Functions: Two Vertical Asymptotes

Figure 1.19(c)

Denominator $2x^2 - 1 = 0$ leads to two vertical asymptotes at $x = \pm 1/\sqrt{2}$.

$$y = \frac{11x + 2}{2x^2 - 1}$$

Rational Function with 2 Asymptotes
