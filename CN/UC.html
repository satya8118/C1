Uniformly Continuous Functions

From pointwise continuity to a single δ that works everywhere on a set

1. Motivation: Can One δ Serve Every Point?

Recall what it means for a function f to be continuous at a point x₀. For every ε > 0 there is a δ > 0 such that

| f(x) − f(x₀) | < ε    whenever   | x − x₀ | < δ.

The number δ is allowed to depend on ε and on the point x₀. At a place where the function changes quickly, we may need a very small δ; where it changes slowly, a larger δ will do. Continuity at a point is therefore a local property: it is decided separately at each point.

Now suppose we are interested in a whole set A at once, and we ask a stronger question:

The Question

Can we find a single δ > 0 that works simultaneously at every point of A? That is, for a given ε > 0, is there one δ such that

| f(x) − f(y) | < ε    whenever   x, y ∈ A and | x − y | < δ ?

A first test: f(x) = 1/x on (0, 1]

Take ε = 0.5 and look at two places on the graph.

  • At x₀ = 1. Here f(1) = 1, and we need |1/x − 1| < 0.5, i.e. 0.5 < 1/x < 1.5, i.e. 0.667 < x. So any δ ≤ 0.33 works comfortably around x₀ = 1.
  • At x₀ = 0.2. Here f(0.2) = 5, and we need 4.5 < 1/x < 5.5, i.e. 0.1818 < x < 0.2222. The largest safe δ is only about 0.018 — nearly twenty times smaller than before.

As x₀ → 0⁺, the needed δ shrinks to 0. No single δ > 0 can work at every point of (0, 1] for this ε. The function 1/x is continuous at every point of (0, 1], but the continuity is not uniform over the set.

A second test: f(x) = x² on ℝ

At a point x₀, the slope of the graph is about 2x₀. To keep the output within ε we need roughly δ ≈ ε / (2|x₀|). As |x₀| → ∞, this shrinks to 0. Again, no single δ works on all of ℝ.

These two examples show that the question is a genuine one, and that the answer is sometimes no. When the answer is yes, we say the function is uniformly continuous on the set. Let us now make this precise.

2. Definition

Let A ⊆ ℝ and let f : A → ℝ.

Definition (uniform continuity on a set)

We say that f is uniformly continuous on A if for every ε > 0 there exists δ > 0 such that

| f(x) − f(y) | < ε    whenever   x, y ∈ A and | x − y | < δ.

In quantifier form:   ∀ ε > 0,   ∃ δ > 0,   ∀ x, y ∈ A :   | x − y | < δ ⟹ | f(x) − f(y) | < ε.

Uniform continuity is on a set, not at a point

Notice carefully where the quantifiers sit. In the definition of uniform continuity, the phrase “∀ x, y ∈ A” comes after the choice of δ. This means one and the same δ must serve every pair of points in A.

It therefore makes no sense to say that a function is “uniformly continuous at a point”. The word uniform refers precisely to the fact that the same δ is used uniformly across the whole set. Uniform continuity is a property of the function on the set A, and it must always be read with the set named.

How it differs from ordinary continuity

Let us place the two definitions side by side, both written for the same set A.

Aspect Continuous on A Uniformly continuous on A
Quantifier order ∀ x₀ ∈ A,   ∀ ε > 0,   ∃ δ > 0 :   x ∈ A, | x − x₀ | < δ ⟹ | f(x) − f(x₀) | < ε ∀ ε > 0,   ∃ δ > 0,   ∀ x, y ∈ A :   | x − y | < δ ⟹ | f(x) − f(y) | < ε
What δ may depend on ε and the point x₀ ε only
Nature of the condition Local: decided separately at each point Global: one δ for the whole set A
How the negation reads ∃ x₀ ∈ A, ∃ ε > 0, ∀ δ > 0, ∃ x ∈ A : | x − x₀ | < δ and | f(x) − f(x₀) | ≥ ε ∃ ε > 0, ∀ δ > 0, ∃ x, y ∈ A : | x − y | < δ and | f(x) − f(y) | ≥ ε

Every uniformly continuous function on A is continuous on A: if a single δ works for all pairs, then in particular it works for all pairs involving a fixed x₀. The converse is not true, as the examples 1/x on (0, 1] and x² on ℝ show.

Uniformly continuous on A  ⟹  continuous on A   (but not conversely).

Geometric picture

Uniform continuity says the following. Fix ε > 0. Draw around the graph of f a band of vertical width 2ε. Uniform continuity guarantees that there is a horizontal width δ such that whenever two points of the domain are within δ of each other, the corresponding points of the graph are within ε vertically — and this same δ works everywhere along the graph. For 1/x on (0, 1], no such uniform horizontal width exists: the graph becomes steeper and steeper as we approach 0, so the horizontal window must shrink without bound.

3. Examples

Example 1 — Linear functions

Let f(x) = mx + b on ℝ. Then

| f(x) − f(y) | = | m | | x − y |.

If m = 0, take any δ > 0. If m ≠ 0, take δ = ε ⁄ |m|. Either way the choice of δ depends only on ε (and on the fixed slope m), not on the point. So linear functions are uniformly continuous on ℝ.

Example 2 — Sine and cosine

For f(x) = sin x on ℝ, the identity sin x − sin y = 2 cos((x+y)/2) sin((x−y)/2) gives

| sin x − sin y | ≤ | x − y |,

so δ = ε works everywhere. The same argument applies to cos. Both are uniformly continuous on ℝ.

Example 3 — Square root on [0, ∞)

For f(x) = √x on [0, ∞), rationalising gives

| √x − √y | = | x − y | ⁄ ( √x + √y ) ≤ √| x − y |.

So if |x − y| < ε², then |√x − √y| < ε. Taking δ = ε² — a number that depends only on ε — shows that √x is uniformly continuous on [0, ∞). Notice how different this is from 1/x: here the needed δ shrinks as ε → 0 (like ε²), but it does not depend on where we are in the domain.

Example 4 — 1/x away from the origin

For f(x) = 1/x on [1, ∞),

| 1/x − 1/y | = | x − y | ⁄ (xy) ≤ | x − y |,

so δ = ε works. The same function is not uniformly continuous on (0, 1]. The set matters: the very same formula can be uniformly continuous on one set and not on another.

Example 5 — A bounded derivative on an interval

If f is differentiable on an interval I and |f′(x)| ≤ M for all x ∈ I, then by the Mean Value Theorem, for some c between x and y,

| f(x) − f(y) | = | f′(c) | | x − y | ≤ M | x − y |.

So δ = ε ⁄ M works everywhere on I. For instance arctan x has |f′(x)| ≤ 1 on ℝ, so it is uniformly continuous on ℝ with δ = ε.

4. Non-Examples

Non-Example 1 — 1/x on (0, 1]

Take ε = 1/2. We show that no δ > 0 can work. Given any δ > 0, choose an integer n so large that 1/n < δ, and set

x = 1/n,    y = 1/(n+1).

Both lie in (0, 1], and

| x − y | = 1 ⁄ (n(n+1)) < 1/n < δ,    yet    | f(x) − f(y) | = | n − (n+1) | = 1 > 1/2.

So every candidate δ fails for this ε. The function is continuous on (0, 1], but not uniformly continuous there.

Non-Example 2 — x² on ℝ

Take ε = 1. Given any δ > 0, choose x = n and y = n + δ/2 with n large. Then |x − y| = δ/2 < δ, while

| f(x) − f(y) | = | n² − (n + δ/2)² | = nδ + δ²/4,

which exceeds 1 once n is large enough. So x² is not uniformly continuous on ℝ. On a bounded interval, however, it is uniformly continuous, because there the slope is bounded.

Non-Example 3 — sin(1/x) on (0, 1]

As x → 0⁺, the quantity 1/x runs through ever larger values, and sin(1/x) oscillates between −1 and 1 infinitely often. Whatever δ > 0 we try, we can find two points x, y within δ of each other where sin(1/x) = 1 and sin(1/y) = −1. So with ε = 1, no δ works.

Non-Example 4 — A function with a jump

Let f(x) = 0 for x < 0 and f(x) = 1 for x ≥ 0 on [−1, 1]. Taking x = −1/n and y = 1/n gives |f(x) − f(y)| = 1 for arbitrarily small |x − y|. So the function is not uniformly continuous — indeed it is not even continuous.

5. Some Useful Properties

  1. Sums and scalar multiples. If f and g are uniformly continuous on A, then so is f + g: given ε, choose δ₁ for f and δ₂ for g with tolerance ε/2, and take δ = min(δ₁, δ₂). Similarly cf is uniformly continuous for any constant c.
  2. Composition. If f : A → B is uniformly continuous on A and g : B → ℝ is uniformly continuous on B, then g ∘ f is uniformly continuous on A. One simply feeds the δ of g into the definition of uniform continuity for f.
  3. Restriction to a subset. If f is uniformly continuous on A and B ⊆ A, then f is uniformly continuous on B. The same δ continues to work, since there are fewer pairs to check.
  4. Products, when both factors are bounded. If f and g are both uniformly continuous and bounded on A, then fg is uniformly continuous on A. Write fg(x) − fg(y) = f(x)(g(x) − g(y)) + g(y)(f(x) − f(y)) and use the bounds. Without boundedness the conclusion can fail: f(x) = g(x) = x is uniformly continuous on ℝ but x² is not.
  5. Boundedness on a bounded interval. If f is uniformly continuous on a bounded interval (a, b), then f is bounded there. Indeed, apply the definition with ε = 1 to get a δ, split (a, b) into finitely many subintervals of length less than δ, and move from one subinterval to the next using the bound 1 at each step.
  6. Extension to the closure. If f is uniformly continuous on a bounded interval (a, b), then the limits limx→a⁺ f(x) and limx→b⁻ f(x) exist, and f can be extended to a continuous function on the closed interval [a, b]. This is one of the most useful consequences of uniform continuity.

6. Every Continuous Function on [a, b] Is Uniformly Continuous

The examples of failure — 1/x on (0, 1], x² on ℝ — all involved a domain that is either not closed or not bounded. The following theorem says that on a closed bounded interval, failure is impossible.

Theorem (Heine–Cantor)

Let f : [a, b] → ℝ be continuous on [a, b]. Then f is uniformly continuous on [a, b].

We prove this by contradiction, using bisection. The proof uses only the ε–δ definition of continuity at a point (not the sequential one), together with the nested interval property of the real line.

Proof. Suppose, towards a contradiction, that f is continuous on [a, b] but not uniformly continuous there. Unwinding the negation of uniform continuity, this means:

There exists ε₀ > 0 such that for every δ > 0 there are points x, y ∈ [a, b] with |x − y| < δ but |f(x) − f(y)| ≥ ε₀.   (∗)

We now build a nested sequence of closed intervals

I₀ ⊇ I₁ ⊇ I₂ ⊇ ⋯,

each of which still has property (∗) — that is, inside each Iₙ we can find pairs of points as close together as we like whose f-values differ by at least ε₀. Start with I₀ = [a, b], which has (∗) by assumption.

The bisection step. Suppose I = [u, v] has property (∗). Let m = (u + v)/2 be its midpoint, and consider the two closed halves [u, m] and [m, v]. We claim that at least one of these halves also has property (∗).

Suppose not. Then there are numbers δ₁ > 0 and δ₂ > 0 such that

| f(x) − f(y) | < ε₀   whenever   x, y ∈ [u, m]   and   | x − y | < δ₁,
| f(x) − f(y) | < ε₀   whenever   x, y ∈ [m, v]   and   | x − y | < δ₂.

Since f is continuous at m, there is δ₃ > 0 such that

| t − m | < δ₃  ⟹  | f(t) − f(m) | < ε₀ ⁄ 2.

Let δ = min(δ₁, δ₂, δ₃), and take any x, y ∈ [u, v] with |x − y| < δ. There are three cases.

  • Both in [u, m]. Then |x − y| < δ ≤ δ₁, so |f(x) − f(y)| < ε₀.
  • Both in [m, v]. Then |x − y| < δ ≤ δ₂, so |f(x) − f(y)| < ε₀.
  • One in each half, say x ∈ [u, m] and y ∈ [m, v]. Then x ≤ m ≤ y, so |x − m| ≤ |x − y| < δ ≤ δ₃ and |y − m| ≤ |x − y| < δ ≤ δ₃. Hence |f(x) − f(m)| < ε₀/2 and |f(y) − f(m)| < ε₀/2, so by the triangle inequality |f(x) − f(y)| < ε₀.

In every case we have |f(x) − f(y)| < ε₀ for all x, y ∈ [u, v] with |x − y| < δ. That contradicts property (∗) for I. Hence at least one half has property (∗), and we take it to be Iₙ₊₁.

Finishing the construction. Inductively we obtain closed intervals I₀ ⊇ I₁ ⊇ I₂ ⊇ ⋯, each with property (∗), whose lengths are

(b − a) ⁄ 2ⁿ  ⟶  0.

By the nested interval property of ℝ, the intersection ∩ₙ Iₙ contains exactly one point; call it c. Since f is continuous at c, there is η > 0 such that

| t − c | < η  ⟹  | f(t) − f(c) | < ε₀ ⁄ 2.

Choose n so large that the length of Iₙ is less than η. Since c ∈ Iₙ, the whole interval Iₙ lies inside (c − η, c + η). Therefore for any x, y ∈ Iₙ,

| f(x) − f(y) | ≤ | f(x) − f(c) | + | f(c) − f(y) | < ε₀ ⁄ 2 + ε₀ ⁄ 2 = ε₀.

But Iₙ has property (∗), which demands that some pair x, y ∈ Iₙ satisfies |f(x) − f(y)| ≥ ε₀. This is a contradiction. Hence f must be uniformly continuous on [a, b]. ∎

What made the proof work?

Two features of [a, b] were essential: it is bounded (so bisection produces intervals of length tending to 0), and it is closed (so the point c where the intervals shrink lies inside the domain, where f is assumed continuous). Drop either feature and the theorem can fail: 1/x on (0, 1] shows what happens when the interval is not closed, and x² on ℝ shows what happens when it is not bounded.

7. Consequences of the Theorem

  • A large supply of examples. Every continuous function on a closed bounded interval is uniformly continuous there. So x³, sin x, eˣ, ln(1 + x), and any polynomial are uniformly continuous on every interval [a, b], no matter how large the interval.
  • Boundedness. A continuous function on [a, b] is bounded. This follows from the theorem together with the property that a uniformly continuous function on a bounded interval is bounded.
  • Riemann integrability. A continuous function on [a, b] is Riemann integrable. The standard proof uses the uniform continuity of f to make all the upper and lower sums on a sufficiently fine partition differ by less than any prescribed ε.
  • Extension to the endpoints. If f is continuous on (a, b) and uniformly continuous there, then f extends continuously to [a, b]. Uniform continuity is exactly the extra hypothesis that rules out blow-ups at the endpoints, as in 1/x on (0, 1].

8. Summary

Where is the property decided? At each point x₀ separately On the whole set A at once

What δ depends on ε and x₀ ε only

9. Conclusion

Uniform continuity is what happens when we ask continuity to be uniform over a whole set rather than merely to hold point by point. The definition looks almost identical to ordinary continuity, but the position of the quantifiers makes all the difference: the same δ must serve every pair of points in A, so it is not permitted to depend on where we are.

The key points to remember:

  • Uniform continuity is a property on a set, not at a point. There is no such thing as being “uniformly continuous at x₀”.
  • Uniformly continuous on A implies continuous on A, but not conversely. The functions 1/x on (0, 1] and x² on ℝ are the standard counterexamples.
  • A bounded derivative on an interval gives uniform continuity there, with δ = ε ⁄ M.
  • The Heine–Cantor theorem says that on a closed bounded interval every continuous function is uniformly continuous. The proof is a bisection argument: if uniform continuity failed, we could trap a point c inside ever smaller intervals, and continuity at c would then contradict the failure.
  • Uniform continuity on (a, b) is exactly what is needed for f to extend continuously to the endpoints, for f to be bounded, and for f to be Riemann integrable on [a, b].

Once the distinction between “continuous at each point” and “continuous uniformly on the set” is clear, a large part of real analysis — integration, extension theorems, and the behaviour of functions on compact intervals — becomes much easier to organise.
