1. Mastering 2D Plotting

We will perform three tasks: one instructor demonstration followed by two student challenges. Focus on using correct mathematical syntax.

Instructor Demo

Task 1: Variables & Sliders

We don't just plot static lines. We add variables. Type:

y = a*x + 2

Desmos will ask "Add Slider?". Click a. Now drag the slider to see the slope change in real-time.

Student Challenge

Task 2: The Circle

Plot a circle centered at (0,0) with a radius of 5.

Hint: The equation of a circle is $x^2 + y^2 = r^2$.

Solution:
Type: x^2 + y^2 = 25
Note: Desmos supports implicit plotting (you don't need to solve for y).
Student Challenge

Task 3: Inequalities & Shading

Shade the area above the parabola $y = x^2 - 2$.

Solution:
Type: y > x^2 - 2
Desmos automatically handles the shading for inequalities.

2. Exploring 3D Surfaces

Switch to the Desmos 3D tab. Here we graph surfaces $z = f(x, y)$.

Instructor Demo

Task 4: Basic Surface

Let's plot a classic saddle shape (Hyperbolic Paraboloid).

Type: z = x^2 - y^2

Click and drag to rotate the 3D view. Right-click and drag (or two fingers) to pan.

Student Challenge

Task 5: The Paraboloid

Plot a bowl shape (Paraboloid) opening upwards, centered at the origin.

Solution:
Type: z = x^2 + y^2
Experiment with adding a slider to change the height!
Student Challenge

Task 6: Parametric Curve

Plot a Helix (Spiral) in 3D space.

Hint: You need to define a variable t and create an expression vector $(x, y, z)$.

Solution:
1. Add slider for t (let range go from 0 to 10).
2. Type: (cos(t), sin(t), t)
This creates a vector with x and y circling, and z rising linearly.

3. Self Assessment Quiz (SAQ)

Test your understanding of the concepts we just covered. Try to answer without peeking first!

Question 1

Restricting Domain

In Desmos 2D, how would you plot the line y = 2x + 1 only for x-values greater than 0?

Look at the syntax used for inequalities. You can append conditions to the end of an equation.
Type: y = 2x + 1 {x > 0}
Question 2

Visualizing Intersections

You have plotted a parabola and a line. How do you get Desmos to calculate and label the exact coordinates where they intersect?

It's not a button; it's an expression. You can type the equation for one function "equals" the equation for the other.
Type: y = x^2 {y = 2x} (Assuming your parabola is $y=x^2$ and line is $y=2x$).
Desmos will plot the points where $x^2 = 2x$.
Question 3

3D Cross Sections

You have plotted a surface z = x^2 + y^2. How do you visualize the cross-section of this shape at z = 4?

You need a second equation that defines a plane at height 4.
Type a second input: z = 4
The intersection line between the surface and the flat plane shows the cross-section.
Question 4

Variables in 3D

You want to plot a cylinder of radius 3. You type x^2 + y^2 = 9, but it looks like a flat tube in 3D. What is missing?

In 3D, equations must usually explicitly involve z to extend infinitely, OR you need to restrict the domain/inequality.
The equation $x^2 + y^2 = 9$ is technically an infinite cylinder, but 3D graphers often render it thinly or need a range.
A better way in Desmos 3D is using inequalities to give it "thickness" or extending a variable:
x^2 + y^2 < 9 { -10 < z < 10 } (Solid cylinder).
Question 5

Plotting Derivatives

If you type f(x) = x^2, how do you plot the derivative $f'(x)$ immediately on the same graph?

You don't need to calculate it manually (2x). You can use the prime notation in Desmos.
Type: y = f'(x)
Question 6

Piecewise Functions

How do you type a piecewise function where y = x when x > 0, and y = -x when x ≤ 0?

You use curly braces {} to separate the condition.
Type: y = {x > 0: x, -x}
