Lemma 1 — Existence of Integer Part

For any real number $x$, there exists an integer $m$ such that:

$$m \le x < m+1$$

Proof: Define the set $S_x = \{ z \in \mathbb{Z} \mid z \le x \}$.

  1. Proof that $S_x$ is non-empty by Contradiction: Assume $S_x = \emptyset$.
  2. If $S_x$ is empty, there exists no integer $z \in \mathbb{Z}$ such that $z \le x$.
  3. This implies that for every integer $z \in \mathbb{Z}$, we must have $z > x$.
  4. Consequently, $x$ becomes a lower bound for the set of integers $\mathbb{Z}$.
  5. However, this is a direct contradiction because the set of integers $\mathbb{Z}$ is not bounded below.
  6. Thus, our assumption must be false, proving that $S_x$ is indeed non-empty ($S_x \neq \emptyset$).
  7. $S_x$ is bounded above by the real number $x$ by definition of its elements.
  8. By the Least Upper Bound (LUB) Property, let $m = \text{lub}(S_x)$.
  9. Since $m-1 < m$, $m-1$ is not an upper bound of $S_x$, so there exists an integer $k \in S_x$ such that $k > m-1$, which means $k+1 > m$.
  10. Thus, we conclude that $m = k$, leading directly to the inequality $m \le x < m+1$.

Theorem — Uniqueness of the Integer Part

The integer $m$ satisfying the condition $m \le x < m+1$ is strictly unique.

Proof: Assume by contradiction that distinct integers $m$ and $n$ both satisfy $m \le x < m+1$ and $n \le x < n+1$.

Without loss of generality, assume $n > m$, which implies that $n \ge m+1$.

However, from $n \le x < m+1$, we obtain $n < m+1$.

This yields the clear contradiction $n \ge m+1$ and $n < m+1$.

Therefore, our initial assumption must be false, proving that $m = n$. $\blacksquare$

Step 1 — Reformulating Rational Density

Finding a rational number $\frac{m}{n}$ between $a$ and $b$ is equivalent to finding an integer $m$ inside the scaled interval:

$$na < m < nb$$

To guarantee that an integer exists between $na$ and $nb$, it suffices to make the width of the interval greater than 1.

This gives the inequality $n(b - a) > 1$, which simplifies to choosing $n > \frac{1}{b-a}$.

Theorem — Density of Rationals in $\mathbb{R}$

If $x, y \in \mathbb{R}$ with $x < y$, there exists a rational number $r \in \mathbb{Q}$ such that $x < r < y$.

Proof Outline:

  1. By the Archimedean property, choose a positive integer $n \in \mathbb{N}$ such that $n(y-x) > 1$, which gives $nx + 1 < ny$.
  2. Apply Lemma 1 to find an integer $m$ such that $m \le nx < m+1$.
  3. From $nx < m+1$, we get $x < \frac{m+1}{n}$.
  4. From $m \le nx \implies m+1 \le nx + 1 < ny$, we get $\frac{m+1}{n} < y$.
  5. Combining both inequalities yields $x < \frac{m+1}{n} < y$. Setting $r = \frac{m+1}{n} \in \mathbb{Q}$ completes the proof. $\blacksquare$
Theorem — Density of Irrationals in $\mathbb{R}$

If $a, b \in \mathbb{R}$ with $a < b$, there exists an irrational number $\xi \in \mathbb{R}\setminus\mathbb{Q}$ such that $a < \xi < b$.

Proof: We apply the density of rational numbers to the shifted endpoints $(a + \sqrt{2}, b + \sqrt{2})$.

By rational density, there exists a rational number $r \in \mathbb{Q}$ such that $a + \sqrt{2} < r < b + \sqrt{2}$.

Subtracting $\sqrt{2}$ across all terms yields the inequality $a < r - \sqrt{2} < b$.

Defining $\xi = r - \sqrt{2}$, we see that $\xi$ is strictly irrational because the difference of a rational and an irrational is irrational.

Hence, $a < \xi < b$ with $\xi \notin \mathbb{Q}$. $\blacksquare$
