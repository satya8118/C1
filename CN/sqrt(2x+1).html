Setup & Notation

  • Function:   f(x) = √(2x+1)   on the domain x ≥ −1/2
  • Point:   a = 4  •  Limit value:   L = f(4) = √9 = 3
  • We must prove:   ∀ε > 0  ∃δ > 0  such that   0 < |x − 4| < δ  ⟹  |√(2x+1) − 3| < ε
  • Key algebra (rationalize):   √(2x+1) − 3 = [(2x+1) − 9] / [√(2x+1) + 3] = 2(x − 4) / (√(2x+1) + 3)
  • Exact boundary:   setting √(2x+1) = 3 ± ε gives   x = ((3 ± ε)² − 1) / 2
  • Largest valid δ:   δ*(ε) = min{ 4 − ((3−ε)²−1)/2 ,  ((3+ε)²−1)/2 − 4 } = 3ε − ε²/2

General Proof

Claim:   limx→4 √(2x+1) = 3.

Step 1 — Rationalize.
For every x in the domain,
√(2x+1) − 3 = [(2x+1) − 9] / [√(2x+1) + 3] = 2(x − 4) / (√(2x+1) + 3)
Step 2 — Bound the denominator from below.
Since √(2x+1) ≥ 0,   √(2x+1) + 3 ≥ 3,   hence
1 / (√(2x+1) + 3) ≤ 1/3
Step 3 — Relate |f(x) − L| to |x − a|.
|√(2x+1) − 3| = 2|x − 4| / (√(2x+1) + 3) ≤ (2/3)·|x − 4|
Step 4 — Choose δ.
Let ε > 0 be given.   Choose   δ = 3ε/2.
Step 5 — Verify.
Suppose 0 < |x − 4| < δ.   Then
|√(2x+1) − 3| ≤ (2/3)|x − 4| < (2/3)δ = (2/3)(3ε/2) = ε.   ∎

Sharper (optimal) δ

Solve √(2x+1) = 3 ± ε  ⟹  x = ((3 ± ε)² − 1)/2.   Therefore
δ*(ε) = min{ 4 − ((3−ε)²−1)/2 , ((3+ε)²−1)/2 − 4 }
= min{ 3ε − ε²/2 ,   3ε + ε²/2 } = 3ε − ε²/2
As ε → 0⁺,   δ*/ε → 3.   So δ ≈ 3ε for tiny ε — much larger than 3ε/2.

The “board” version (δ = ε/2)

Because √(2x+1) + 3 > 1 we get the cruder bound
|√(2x+1) − 3| = 2|x − 4| / (√(2x+1) + 3) < 2|x − 4| < 2δ
Choosing δ = ε/2 gives   |√(2x+1) − 3| < 2·(ε/2) = ε.   ✓
Valid, but conservative: for ε = 0.2 it gives δ = 0.10 while the exact δ* = 0.58.
