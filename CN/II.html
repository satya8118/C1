INVERSE IMAGE OF A FUNCTION

1. DEFINITION (INVERSE IMAGE)

Let f : X → Y be a function and y ∈ Y.
The inverse image (or preimage) of y under f is the subset of X defined by

f⁻¹(y) = { x ∈ X | f(x) = y }.

It consists of all points in X that are mapped to y.

Examples of inverse images

  • f⁻¹(y₁) = {x₁}
  • f⁻¹(y₂) = {x₂, x₃}
  • f⁻¹(y₃) = {x₄}
  • f⁻¹(y₄) = ∅ (for some y₄ ∈ Y)

(An inverse image can be empty, a singleton, or have many elements.)

2. CHARACTERIZATIONS USING INVERSE IMAGES

(a) ONE–ONE (INJECTIVE)

f is one–one iff ∀y ∈ Y, f⁻¹(y) is a singleton or an empty set.

Singleton case: f⁻¹(y)={x}

Empty case: f⁻¹(y)=∅

no arrow reaches y FIXED

No y has two or more preimages.

(b) ONTO (SURJECTIVE)

f is onto iff ∀y ∈ Y, f⁻¹(y) is a nonempty set.

Every y ∈ Y has at least one preimage.

(c) BIJECTIVE

f is bijective iff ∀y ∈ Y, f⁻¹(y) is a singleton.

(One–one and onto)

3. INVERSE IMAGES OF DIFFERENT VALUES ARE DISJOINT

If y₁ ≠ y₂ in Y, then f⁻¹(y₁) ∩ f⁻¹(y₂) = ∅.

Proof. Let x ∈ f⁻¹(y₁) ∩ f⁻¹(y₂). Then f(x) = y₁ and f(x) = y₂. Hence y₁ = y₂, a contradiction. Therefore the intersection is empty.

Example. f : ℤ → ℕ ∪ {0}, f(x) = |x|.

f⁻¹(0)={0}

f⁻¹(1)={-1,1}

f⁻¹(2)={-2,2}

f⁻¹(3)={-3,3} FIXED

These preimage sets are pairwise disjoint.

4. UNION OF ALL INVERSE IMAGES IS THE WHOLE DOMAIN

For any function f : X → Y,

⋃y∈Y f⁻¹(y) = X.

Proof. Let x ∈ X. Put y = f(x) ∈ Y. Then x ∈ f⁻¹(y). Hence every x ∈ X lies in at least one f⁻¹(y). Conversely, if x ∈ f⁻¹(y) for some y ∈ Y, then x ∈ X. Thus the union equals X.

Example. f(x) = x², f : ℝ → ℝ.

Here f⁻¹(y) = {-√y, √y} if y>0; {0} if y=0; ∅ if y<0.

Then ⋃y∈ℝ f⁻¹(y) = ℝ.

5. MORE EXAMPLES WITH MAPPING DIAGRAMS

(a) f(x)=x², f:ℝ→ℝ FIXED

(Not one–one, not onto)

Inverse images: f⁻¹(-1)=∅, f⁻¹(0)={0}, f⁻¹(1)={-1,1}, f⁻¹(4)={-2,2}, f⁻¹(9)={-3,3}

  • Some inverse images have two elements.
  • Some are empty (e.g., -1).
  • Hence f is not one–one and not onto.

(b) f(x,y)=x²+y², f:ℝ²→ℝ

(Not one–one, onto)

f⁻¹(0)={(0,0)}, f⁻¹(1)={x²+y²=1} (radius 1), f⁻¹(4)={radius 2}, f⁻¹(9)={radius 3}, f⁻¹(-1)=∅

  • Every real number r ≥ 0 is attained (onto).
  • Each r>0 has infinitely many preimages.
  • Not one–one.

(c) g(x,y)=x, g:ℝ²→ℝ FIXED

(Onto, not one–one)

g⁻¹(2)={(2,y)}, g⁻¹(1)={(1,y)}, g⁻¹(0)={(0,y)}, g⁻¹(-1)={(-1,y)}

  • Every real number is attained (onto).
  • Each inverse image is an entire vertical line.
  • Hence not one–one.

6. TAKEAWAY

  • f⁻¹(y) collects all points of X mapping to y.
  • One–one ⇔ each inverse image is a singleton or empty.
  • Onto ⇔ each inverse image is nonempty.
  • Bijective ⇔ each inverse image is a singleton.
  • Inverse images of different y's are disjoint.
  • Union of all f⁻¹(y) over Y is the whole domain X.

8. NOTATION REMINDER

  • ∅ : empty set
  • singleton: set with exactly one element
  • ℕ = {1, 2, 3, …}
  • ℕ ∪ {0} = nonnegative integers
  • ℤ = integers
  • ℝ = real numbers
  • ℝ² = {(x,y) | x,y ∈ ℝ}
