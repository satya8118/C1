📐 Natural Logarithm

MAT101 Calculus I  ·  Expanded Proofs & Review
📅 September 29 👨‍🏫 Amber Habib 📘 Core Concept

1. Definition Integral form

The natural logarithm is defined as the integral of \( \frac{1}{t} \) from \( 1 \) to \( x \):

\[ \log(x) \;=\; \int_{1}^{x} \frac{1}{t} \, dt \qquad (x > 0) \]

This definition gives \(\log : (0, \infty) \to \mathbb{R}\). The choice of lower limit \(1\) ensures \(\log(1)=0\), which is the natural starting point.

💡 Intuition: The logarithm of \(x\) is the signed area under the hyperbola \(y = \frac{1}{t}\) from \(t=1\) to \(t=x\). If \(x > 1\), the area is positive. If \(0 < x < 1\), the integral runs from \(1\) down to \(x\), so the area is negative.
🔎 Why is \(\log(x) < 0\) when \(0 < x < 1\)?

Direct proof from the integral:

\[ \log(x) = \int_{1}^{x} \frac{dt}{t} = -\int_{x}^{1} \frac{dt}{t} \]

For \(0 < x < 1\), the integrand \(\frac{1}{t}\) is positive on \([x, 1]\). Hence \(\int_{x}^{1} \frac{dt}{t} > 0\), so \(\log(x) = -(\text{positive}) < 0\).

Alternatively, using the quotient property (proved below): since \(\log(1) = \log(x \cdot \frac{1}{x}) = \log(x) + \log(\frac{1}{x})\), we have \(\log(x) = -\log(\frac{1}{x})\). If \(0 < x < 1\), then \(\frac{1}{x} > 1\). Because \(\log\) is strictly increasing (proved in Section 4) and \(\log(1)=0\), we get \(\log(\frac{1}{x}) > 0\), so \(\log(x) = -(\text{positive}) < 0\).

2. Fundamental Properties Proved

For any \(a, b > 0\) and any integer \(m \in \mathbb{Z}\), the logarithm satisfies:

Product
\(\log(ab) = \log a + \log b\)
Quotient
\(\log(a/b) = \log a - \log b\)
Power
\(\log(a^m) = m \log a\)

📌 Proof of the Product Property

Starting from the integral definition:

\[ \log(ab) = \int_{1}^{ab} \frac{dt}{t} \]

Split the integral at \(a\):

\[ \log(ab) = \int_{1}^{a} \frac{dt}{t} + \int_{a}^{ab} \frac{dt}{t} \]

In the second integral, use the substitution \( t = a u \). Then \( dt = a\,du \). When \(t = a\), \(u = 1\). When \(t = ab\), \(u = b\).

\[ \int_{a}^{ab} \frac{dt}{t} = \int_{1}^{b} \frac{a\,du}{a u} = \int_{1}^{b} \frac{du}{u} = \log(b) \]

Therefore:

\[ \log(ab) = \int_{1}^{a} \frac{dt}{t} + \log(b) = \log(a) + \log(b) \]

📌 Proof of the Quotient Property

Using the product property just proved: \[ \log(a) = \log\left( \frac{a}{b} \cdot b \right) = \log\left(\frac{a}{b}\right) + \log(b) \] Subtracting \(\log(b)\) from both sides gives:

\[ \log\left(\frac{a}{b}\right) = \log(a) - \log(b) \]

📌 Proof of the Power Property

For \(m \in \mathbb{N}\), repeated application of the product property yields: \[ \log(a^m) = \log(a \cdot a \cdots a) = m \log(a) \] For \(m = 0\), \(\log(1) = 0 = 0 \cdot \log(a)\). For negative integers, \(m = -n\) with \(n > 0\): \[ \log(a^{-n}) = \log\left(\frac{1}{a^n}\right) = \log(1) - \log(a^n) = -n \log(a) = m \log(a) \] using the quotient property.

\[ \log(a^m) = m \log(a) \quad \text{for all } m \in \mathbb{Z} \]

These properties turn multiplication into addition, division into subtraction, and powers into multiplication — the very essence of logarithms.

4. Strictly Increasing Proof

The logarithm is strictly increasing: if \(b > a > 0\), then \(\log(b) > \log(a)\).

\[ \log(b) - \log(a) \;=\; \int_{1}^{b} \frac{dt}{t} - \int_{1}^{a} \frac{dt}{t} \;=\; \int_{a}^{b} \frac{dt}{t} \]
📐 Why is this integral positive?
On the interval \([a,b]\), we have \(t \le b\), so \(\frac{1}{t} \ge \frac{1}{b}\). Therefore: \[ \int_{a}^{b} \frac{dt}{t} \;\ge\; \int_{a}^{b} \frac{dt}{b} \;=\; \frac{b-a}{b} \;>\; 0 \] Hence \(\log(b) - \log(a) > 0\), i.e. \(\log(b) > \log(a)\).

Since \(\log\) is strictly increasing, it is one-to-one (injective). This is a key step toward showing it is a bijection.

5. Intermediate Value Property IVP

The logarithm has the intermediate value property: if \(0 < x < y\) and \(\log(x) < L < \log(y)\), then there exists \(c \in (x,y)\) such that \(\log(c) = L\).

🔍 Step 1: Define separating sets
Define \[ A = \{ a > 0 \mid \log(a) \le L \}, \qquad B = \{ b > 0 \mid \log(b) \ge L \}. \] By our assumption \(\log(x) < L < \log(y)\), we have \(x \in A\) and \(y \in B\), so both sets are non-empty. Because \(\log\) is strictly increasing, every \(a \in A\) is \(\le\) every \(b \in B\).
🔍 Step 2: Completeness axiom gives a separator
By the completeness axiom of the real numbers, there exists a real number \(c\) that separates \(A\) and \(B\). That is, \(a \le c \le b\) for all \(a \in A, b \in B\). Since \(x \le c \le y\), we have \(c \in (0,\infty)\).
🔍 Step 3: Trichotomy rules out inequalities

Suppose \(\log(c) < L\). Choose \(\delta = c\,(L - \log(c)) > 0\). Then using the integral definition: \[ \log(c+\delta) = \log(c) + \int_{c}^{c+\delta} \frac{dt}{t} \le \log(c) + \frac{\delta}{c} = L \] Hence \(c+\delta \in A\), but \(c+\delta > c\), contradicting that \(c\) is an upper bound for \(A\).

Suppose \(\log(c) > L\). Then \(\log(1/c) = -\log(c) < -L\). Applying the same argument as above to the sets \(A' = \{a > 0 \mid \log(a) \le -L\}\) and \(B' = \{b > 0 \mid \log(b) \ge -L\}\), we find that \(1/c\) separates \(A'\) and \(B'\). But then \(\log(1/c) < -L\) leads to a similar contradiction (by adding a small \(\delta\) to \(1/c\)).

Therefore, the only possibility left is \(\log(c) = L\).

📌 Key insight: The IVP ensures that \(\log\) takes every intermediate value between any two of its values. This is a consequence of continuity (which follows from the fundamental theorem of calculus).

6. Bijection: \(\log : (0,\infty) \to \mathbb{R}\) One-to-one & onto

We now show that \(\log\) is both one-to-one and onto, hence a bijection.

✓ Injective (one-to-one)

Since \(\log\) is strictly increasing (Section 4), it is injective: if \(\log(a) = \log(b)\), then \(a = b\).

✓ Surjective (onto)

Take any \(y \in \mathbb{R}\). We need to find \(x > 0\) such that \(\log(x) = y\).

📌 Case \(y > 0\)
By the Archimedean property of \(\mathbb{R}\), there exists \(n \in \mathbb{N}\) such that \(n \log(2) > y\). (Recall \(\log(2) \approx 0.693 > 0\)). Since \(\log(2^n) = n \log(2)\), we have: \[ \log(1) = 0 \quad < \quad y \quad < \quad n \log(2) = \log(2^n) \] By the Intermediate Value Property (Section 5), there exists a \(c \in (1, 2^n)\) such that \(\log(c) = y\).
📌 Case \(y < 0\)
Since \(-y > 0\), by the previous case there is \(c > 0\) such that \(\log(c) = -y\). Using the quotient property: \[ \log\left(\frac{1}{c}\right) = \log(1) - \log(c) = 0 - (-y) = y \] Hence \(\frac{1}{c} > 0\) is the desired preimage.
📌 Case \(y = 0\)
\(\log(1) = 0\), so \(x = 1\) works.
\[ \boxed{\log : (0,\infty) \;\longrightarrow\; \mathbb{R} \quad \text{is a bijection}} \]

Because \(\log\) is a bijection, it has an inverse function, which we call the exponential function \(\exp : \mathbb{R} \to (0,\infty)\).

7. Summary Reference

Property Statement How it’s proved / role
Definition \(\log(x) = \int_{1}^{x} \frac{dt}{t}\) Foundation
Product rule \(\log(ab) = \log a + \log b\) Substitution \(t = au\) in the integral
Quotient rule \(\log(a/b) = \log a - \log b\) Derived from product rule
Power rule \(\log(a^m) = m \log a\) Repeated product / quotient for integers
Strictly increasing \(b > a \Rightarrow \log b > \log a\) Integral of positive function over \([a,b]\)
Negativity for \(x<1\) \(0 < x < 1 \Rightarrow \log x < 0\) Integral from \(x\) to \(1\) is positive, or via quotient
IVP \(\log(x) < L < \log(y) \Rightarrow \exists c\) Completeness axiom + trichotomy
Bijection \((0,\infty) \leftrightarrow \mathbb{R}\) Injective (strict inc.) + surjective (IVP + Archimedean)
🔗 Key takeaway: The natural logarithm is the unique continuous function satisfying \(\log(1)=0\), \(\log(ab)=\log a+\log b\), and whose derivative is \(1/x\). Its inverse is the exponential function \(e^x\).
