Comprehensive Analysis of $f(x) = \frac{x}{1+x^2}$

Instructor's Sample Solution & Exploration Guide for Students

1. Fundamental Properties & Behavior

Function Definition: $$f(x) = \frac{x}{1+x^2}$$

  • Domain: $\mathbb{R} = (-\infty, \infty)$ since $1+x^2 \ge 1 \neq 0$ for all real $x$.
  • Range: $\left[-\frac{1}{2}, \frac{1}{2}\right]$ (bounded function).
  • Parity / Symmetry: $$f(-x) = \frac{-x}{1+(-x)^2} = -\frac{x}{1+x^2} = -f(x)$$ $f(x)$ is an odd function, symmetric about the origin $(0,0)$.
  • Local Linear Behavior near $x=0$: As $x \to 0$, $1+x^2 \approx 1$, yielding $f(x) \approx x$.
  • Asymptotic Limits: $$\lim_{x \to \infty} \frac{x}{1+x^2} = 0 \quad \text{and} \quad \lim_{x \to -\infty} \frac{x}{1+x^2} = 0$$ The line $y = 0$ is a horizontal asymptote.

Mapping Analysis (Injectivity & Surjectivity)

Is $f$ One-to-One (Injective)?
No. For example, $f(0.5) = 0.4$ and $f(2) = 0.4$. Because $f(0.5) = f(2)$ while $0.5 \neq 2$, it fails the Horizontal Line Test on $\mathbb{R}$.

Is $f$ Onto (Surjective)?
No (when codomain is $\mathbb{R}$). Values outside $\left[-\frac{1}{2}, \frac{1}{2}\right]$ (such as $y=2$) have no pre-image. However, $f$ is surjective onto the restricted codomain $\left[-\frac{1}{2}, \frac{1}{2}\right]$.

2. Differential Calculus: $f'(x)$ and $f''(x)$

First Derivative:

$$f'(x) = \frac{(1)(1+x^2) - x(2x)}{(1+x^2)^2} = \frac{1-x^2}{(1+x^2)^2}$$

Critical Points & Extrema: $f'(x) = 0 \implies 1-x^2 = 0 \implies x = \pm 1$.

  • Absolute Minimum: $\left(-1, -\frac{1}{2}\right)$
  • Absolute Maximum: $\left(1, \frac{1}{2}\right)$
  • Monotonicity:
    • Increasing on $(-1, 1)$ where $f'(x) > 0$.
    • Decreasing on $(-\infty, -1) \cup (1, \infty)$ where $f'(x) < 0$.

Second Derivative:

$$f''(x) = \frac{-2x(1+x^2)^2 - (1-x^2)\cdot 2(1+x^2)(2x)}{(1+x^2)^4} = \frac{2x(x^2 - 3)}{(1+x^2)^3}$$

Setting $f''(x) = 0 \implies x = 0, \pm \sqrt{3} \approx \pm 1.732$.

  • Inflection Points: $\left(-\sqrt{3}, -\frac{\sqrt{3}}{4}\right)$, $(0, 0)$, and $\left(\sqrt{3}, \frac{\sqrt{3}}{4}\right)$.
  • Concavity Intervals: Concave Down on $(-\infty, -\sqrt{3}) \cup (0, \sqrt{3})$; Concave Up on $(-\sqrt{3}, 0) \cup (\sqrt{3}, \infty)$.

3. Tangent Lines at Multiple Points

The tangent line equation at $x = x_0$ is $y - f(x_0) = f'(x_0)(x - x_0)$.

Point ($x_0$) $f(x_0)$ $f'(x_0)$ Tangent Line Equation Geometric Feature
$x_0 = 0$ $0$ $1$ $y = x$ Inflection tangent at the origin
$x_0 = 1$ $0.5$ $0$ $y = 0.5$ Horizontal tangent at global max
$x_0 = 2$ $0.4$ $-0.12$ $y = -0.12x + 0.64$ Tangent along decreasing tail

4. Taylor & Maclaurin Polynomial Approximations at $x=0$

Using the geometric series $\frac{1}{1+u} = \sum_{n=0}^{\infty} (-1)^n u^n$ for $|u| < 1$, substitute $u = x^2$:

$$f(x) = x \left( \frac{1}{1+x^2} \right) = x \left(1 - x^2 + x^4 - x^6 + \dots\right) = x - x^3 + x^5 - x^7 + \dots \quad (|x| < 1)$$

Taylor Polynomials at $x=0$:

  • $P_1(x) = x$
  • $P_2(x) = x$ (even terms are $0$)
  • $P_3(x) = x - x^3$
  • $P_4(x) = x - x^3$
  • $P_5(x) = x - x^3 + x^5$

Radius of Convergence: $R = 1$. The series converges for $x \in (-1, 1)$. Higher-degree Taylor polynomials rapidly converge near origin but diverge for $|x| > 1$.

5. Integral Calculus: Area & Arc Length

Indefinite Integral:

$$\int \frac{x}{1+x^2} dx = \frac{1}{2} \ln(1+x^2) + C$$

1. Area Under the Curve ($\int_a^b f(x)dx$):

  • Interval $[0, 1]$: $$\int_0^1 \frac{x}{1+x^2} dx = \left[ \frac{1}{2}\ln(1+x^2) \right]_0^1 = \frac{1}{2}\ln(2) \approx 0.34657$$
  • Interval $[0, 2]$: $$\int_0^2 \frac{x}{1+x^2} dx = \left[ \frac{1}{2}\ln(1+x^2) \right]_0^2 = \frac{1}{2}\ln(5) \approx 0.80472$$

2. Arc Length ($L = \int_a^b \sqrt{1 + [f'(x)]^2} dx$):

  • Interval $[0, 1]$: $$L_1 = \int_0^1 \sqrt{1 + \left(\frac{1-x^2}{(1+x^2)^2}\right)^2} dx \approx 1.15802$$
  • Interval $[0, 2]$: $$L_2 = \int_0^2 \sqrt{1 + \left(\frac{1-x^2}{(1+x^2)^2}\right)^2} dx \approx 2.16356$$

6. Applications of Integration: Solids of Revolution

Revolving the curve segment $y = f(x)$ on $x \in [0, 1]$ around the $x$-axis:

Volume of Revolution (Disk Method):

$$V = \pi \int_0^1 [f(x)]^2 dx = \pi \int_0^1 \frac{x^2}{(1+x^2)^2} dx$$

Using trig substitution $x = \tan\theta$:

$$V = \pi \left[ \frac{1}{2}\arctan(x) - \frac{x}{2(1+x^2)} \right]_0^1 = \pi \left( \frac{\pi}{8} - \frac{1}{4} \right) \approx 0.44830$$

Surface Area of Revolution:

$$S = 2\pi \int_0^1 f(x)\sqrt{1 + [f'(x)]^2} dx$$ $$S = 2\pi \int_0^1 \frac{x}{1+x^2} \sqrt{1 + \frac{(1-x^2)^2}{(1+x^2)^4}} dx \approx 2.38315$$

7. Restricted Bijective Domain & Inverse Function

By restricting $f(x)$ to the interval $D = [-1, 1]$ (where $f$ is strictly increasing) and codomain to $C = \left[-\frac{1}{2}, \frac{1}{2}\right]$, $f$ becomes bijective and possesses an inverse.

Derivation of Inverse Function $f^{-1}(y)$:

$$y = \frac{x}{1+x^2} \implies y x^2 - x + y = 0$$

Using the quadratic formula for $x$ in terms of $y$:

$$x = \frac{1 \pm \sqrt{1 - 4y^2}}{2y}$$

Selecting the appropriate branch so that $f^{-1}(0) = 0$ on $x \in [-1, 1]$:

$$f^{-1}(x) = \begin{cases} \frac{1 - \sqrt{1 - 4x^2}}{2x} & \text{if } x \in \left[-\frac{1}{2}, \frac{1}{2}\right] \setminus \{0\} \\ 0 & \text{if } x = 0 \end{cases}$$

Activity P1: Derivatives & Extremes Verification Script

import numpy as np
import matplotlib.pyplot as plt

# Define function and derivatives
x = np.linspace(-4, 4, 500)
f = x / (1 + x**2)
df = (1 - x**2) / (1 + x**2)**2
d2f = (2*x*(x**2 - 3)) / (1 + x**2)**3

# Plotting
plt.figure(figsize=(9, 5))
plt.plot(x, f, label=r'$f(x) = \frac{x}{1+x^2}$', color='blue', lw=2)
plt.plot(x, df, label=r"$f'(x)$", color='teal', linestyle='--')
plt.plot(x, d2f, label=r"$f''(x)$", color='orange', linestyle=':')

# Highlight Extrema
plt.scatter([-1, 1], [-0.5, 0.5], color='red', zorder=5, label='Extrema')

plt.title("Function & Derivatives Visualization")
plt.xlabel("x")
plt.ylabel("y")
plt.grid(True, alpha=0.3)
plt.legend()
plt.show()

Activity P2: Numerical Integration, Area, and Arc Length

import scipy.integrate as integrate

# 1. Definite Area Integration [0, 1]
area, _ = integrate.quad(lambda x: x / (1 + x**2), 0, 1)

# 2. Arc Length Calculation [0, 1]
arc_length, _ = integrate.quad(lambda x: np.sqrt(1 + ((1 - x**2)/(1 + x**2)**2)**2), 0, 1)

# 3. Volume of Revolution around X-axis [0, 1]
volume, _ = integrate.quad(lambda x: np.pi * (x / (1 + x**2))**2, 0, 1)

print(f"Area under curve [0,1]: {area:.5f}")
print(f"Arc length [0,1]:       {arc_length:.5f}")
print(f"Volume of revolution:  {volume:.5f}")

Activity P3: 3D Surface of Revolution Visualizer

import numpy as np
import matplotlib.pyplot as plt

# Generate grid for 3D surface of revolution
x_vals = np.linspace(0, 1, 100)
theta = np.linspace(0, 2 * np.pi, 100)
X, THETA = np.meshgrid(x_vals, theta)

# Radius r(x) = f(x)
R = X / (1 + X**2)
Y = R * np.cos(THETA)
Z = R * np.sin(THETA)

# Create 3D plot
fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(111, projection='3d')
ax.plot_surface(X, Y, Z, cmap='viridis', alpha=0.85)

ax.set_title("3D Solid of Revolution around X-axis (x in [0, 1])")
ax.set_xlabel("X axis")
ax.set_ylabel("Y axis")
ax.set_zlabel("Z axis")
plt.show()
