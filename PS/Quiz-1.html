QUESTION 1

Closure of the Unit Interval under Multiplication

Theorem: If $a, b \in [0,1]$, then their product satisfies $a \cdot b \in [0,1]$.

Part 1: Auxiliary Result (Squaring Lemma)

We first establish that squaring any element keeps it inside the unit interval $[0,1]$:

  • Boundary Case $a = 0$: Evaluating directly gives $a^2 = 0^2 = 0 \in [0,1]$.
  • Boundary Case $a = 1$: Evaluating directly gives $a^2 = 1^2 = 1 \in [0,1]$.
  • Interior Case $0 < a < 1$:
    • Multiplying the strict inequality $a < 1$ by the positive quantity $a > 0$ yields: $$a \cdot a < 1 \cdot a \implies a^2 < a$$
    • Chaining this result with the initial bounds $0 < a$ and $a < 1$ gives: $$0 < a^2 < a < 1$$
    • Hence, $a^2 \in (0,1) \subset [0,1]$.
  • Lemma Conclusion: In every possible configuration, $a^2 \in [0,1]$. $\blacksquare$

Part 2: Complete Proof of the Theorem

Let $a, b \in [0,1]$. We exhaustively analyze all positional relationship cases for $a$ and $b$:

  1. Zero Boundary Cases: If either $a = 0$ or $b = 0$, then $a \cdot b = 0 \in [0,1]$.
  2. Identity Boundary Cases:
    • If $a = 1$, then $a \cdot b = 1 \cdot b = b \in [0,1]$.
    • If $b = 1$, then $a \cdot b = a \cdot 1 = a \in [0,1]$.
  3. Equal Elements Case ($a = b \in (0,1)$): Reduces to $a \cdot b = a^2$, which belongs to $[0,1]$ by the Squaring Lemma.
  4. Strict Ordering Case ($0 < a < b < 1$):
    • Since $b > 0$, multiplying $a < 1$ by $b$ gives: $$a \cdot b < 1 \cdot b \implies a b < b < 1$$
    • Since $a > 0$ and $b > 0$, we also have $a b > 0$.
    • Combining these inequalities yields the explicit chain: $$0 < a b < b < 1$$
    • Thus, $a b \in (0,1) \subset [0,1]$.

Because all possible cases exhaust the domain $[0,1] \times [0,1]$, we conclude that $a b \in [0,1]$. $\blacksquare$

QUESTION 2

Discontinuity of the Dirichlet Function

Definition: The Dirichlet function $D: \mathbb{R} \to \mathbb{R}$ is defined by: $$D(x) = \begin{cases} 1 & \text{if } x \in \mathbb{Q} \\ 0 & \text{if } x \in \mathbb{R} \setminus \mathbb{Q} \end{cases}$$ This function is discontinuous at every point $a \in \mathbb{R}$.

Part 1: The Negated $\varepsilon$–$\delta$ Discontinuity Criterion

  • Continuity at $a$: $\forall \varepsilon > 0, \exists \delta > 0$ such that $\forall x \in \mathbb{R}$, $|x - a| < \delta \implies |D(x) - D(a)| < \varepsilon$.
  • Discontinuity at $a$ (Logical Negation): $\exists \varepsilon > 0$ such that $\forall \delta > 0$, $\exists x \in \mathbb{R}$ satisfying $|x - a| < \delta$ and $|D(x) - D(a)| \ge \varepsilon$.

Part 2: Concrete Demonstration at $x = 0$

  1. Evaluation at $0$: Since $0 \in \mathbb{Q}$, we have $D(0) = 1$.
  2. Fixing Error Threshold: Set $\varepsilon = \frac{1}{2}$.
  3. Testing Arbitrary $\delta > 0$:
    • Choose $n \in \mathbb{N}$ large enough such that $n > \frac{\sqrt{2}}{\delta}$ (guaranteed by the Archimedean Property).
    • Construct $x = \frac{\sqrt{2}}{n}$. Observe that $x$ is irrational and satisfies $0 < x < \delta$.
  4. Evaluating Function Jump: $$D(x) = 0 \implies |D(x) - D(0)| = |0 - 1| = 1 \ge \frac{1}{2} = \varepsilon$$
  5. Deduction: No $\delta > 0$ can constrain $D(x)$ within $\varepsilon = \frac{1}{2}$ of $D(0)$, so $D$ is discontinuous at $x = 0$.

Part 3: General Proof for Arbitrary $a \in \mathbb{R}$

We leverage the density of both $\mathbb{Q}$ and $\mathbb{R} \setminus \mathbb{Q}$ in $\mathbb{R}$:

  • Density Properties: Every open interval $(a - \delta, a + \delta)$ contains at least one rational number and at least one irrational number.
  • Fixed Challenge Parameter: Choose $\varepsilon = \frac{1}{2}$.
  • Case A ($a \in \mathbb{Q}$):
    • Here $D(a) = 1$.
    • For any $\delta > 0$, pick an irrational point $x^* \in (a - \delta, a + \delta)$.
    • Then $D(x^*) = 0$, yielding $|D(x^*) - D(a)| = |0 - 1| = 1 \ge \varepsilon$.
  • Case B ($a \in \mathbb{R} \setminus \mathbb{Q}$):
    • Here $D(a) = 0$.
    • For any $\delta > 0$, pick a rational point $x^* \in (a - \delta, a + \delta)$.
    • Then $D(x^*) = 1$, yielding $|D(x^*) - D(a)| = |1 - 0| = 1 \ge \varepsilon$.
  • Conclusion: $D(x)$ is everywhere discontinuous on $\mathbb{R}$. $\blacksquare$
QUESTION 3

Continuity of $f(x) = x^2$ via $\varepsilon$–$\delta$ Definition

Theorem: For every $a \in \mathbb{R}$, $\displaystyle\lim_{x \to a} x^2 = a^2$.

For interactive visuals, visit: Limit of $x^2$ Interactive Proof

Detailed Proof Breakdown

  1. Algebraic Factorization: Our goal is to bound the error term: $$|f(x) - f(a)| = |x^2 - a^2| = |x - a| \cdot |x + a|$$
  2. Bounding the Uncontrolled Term $|x + a|$:
    • Impose an initial constraint on $\delta$: require $\delta \le 1$.
    • If $|x - a| < \delta \le 1$, apply the Triangle Inequality: $$|x + a| = |(x - a) + 2a| \le |x - a| + 2|a| < 1 + 2|a|$$
  3. Forcing Product Inequality:
    • Using the bound $|x + a| < 1 + 2|a|$, we write: $$|x^2 - a^2| = |x - a| \cdot |x + a| < |x - a|(1 + 2|a|)$$
    • To guarantee $|x^2 - a^2| < \varepsilon$, it suffices to enforce: $$|x - a|(1 + 2|a|) \le \varepsilon \iff |x - a| < \frac{\varepsilon}{1 + 2|a|}$$
  4. Final Delta Selection: To satisfy both conditions ($\delta \le 1$ and $\delta \le \frac{\varepsilon}{1 + 2|a|}$), define: $$\delta = \min\left\{1, \frac{\varepsilon}{1 + 2|a|}\right\}$$
  5. Verification: If $0 < |x - a| < \delta$, then simultaneously $|x - a| < 1$ and $|x - a| < \frac{\varepsilon}{1 + 2|a|}$. Therefore: $$|x^2 - a^2| = |x - a| \cdot |x + a| < \left(\frac{\varepsilon}{1 + 2|a|}\right) (1 + 2|a|) = \varepsilon$$

This proves $f(x) = x^2$ is continuous everywhere on $\mathbb{R}$. $\blacksquare$

QUESTION 4

Existence of $n$th Roots via Intermediate Value Theorem

Theorem: Given $a \ge 0$ and integer $n \ge 1$, there exists a unique real number $c \ge 0$ such that $c^n = a$.

Elaborate Step-by-Step Proof

  1. Trivial Boundary Case: If $a = 0$, choosing $c = 0$ yields $0^n = 0 = a$.
  2. Constructing Continuous Auxiliary Function: Assume $a > 0$. Define $g: [0, \infty) \to \mathbb{R}$ by $g(x) = x^n - a$. As a polynomial function, $g$ is continuous on all of $\mathbb{R}$.
  3. Establishing Interval Endpoints:
    • Set $M = \max\{1, a\}$.
    • Lower Bound Evaluation: $g(0) = 0^n - a = -a < 0$.
    • Upper Bound Evaluation: Since $M \ge 1$, we have $M^n \ge M$. Furthermore, $M \ge a$. Thus: $$M^n \ge a \implies g(M) = M^n - a \ge 0$$
  4. Applying Intermediate Value Theorem (IVT):
    • The function $g$ is continuous on the closed interval $[0, M]$.
    • The target value $0$ lies between $g(0) < 0$ and $g(M) \ge 0$.
    • By the IVT, there exists at least one $c \in [0, M]$ such that: $$g(c) = 0 \implies c^n - a = 0 \implies c^n = a$$
  5. Uniqueness Proof:
    • Let $0 \le c_1 < c_2$.
    • Multiplying strict positive inequalities confirms $c_1^n < c_2^n$, meaning $g(x)$ is strictly increasing on $[0, \infty)$.
    • A strictly increasing function can cross zero at most once. Hence, $c = a^{1/n}$ is unique. $\blacksquare$
Note: IVT is a pure non-constructive existence theorem—it proves $c$ exists without explicit algorithmic representation.
QUESTION 5

Bounded Functions and Riemann Integrability

Core Analysis:
  • Part A: Is every bounded function on $[a,b]$ Riemann integrable? FALSE
  • Part B: Is every bounded, increasing function on $[a,b]$ Riemann integrable? TRUE

Part A: Counterexample for Bounded-Only Functions

  • Counterexample Construction: Consider the Dirichlet function $D(x)$ restricted to $[a,b]$ with $a < b$.
  • Boundedness Verification: $0 \le D(x) \le 1$ for all $x \in [a,b]$, so $D$ is bounded.
  • Partition Analysis:
    • Let $P = \{a = x_0 < x_1 < \dots < x_k = b\}$ be any partition of $[a,b]$.
    • By density, every subinterval $[x_{i-1}, x_i]$ contains both rationals and irrationals.
    • Subinterval Supremum: $M_i = \sup_{x \in [x_{i-1}, x_i]} D(x) = 1$.
    • Subinterval Infimum: $m_i = \inf_{x \in [x_{i-1}, x_i]} D(x) = 0$.
  • Darboux Sum Calculations:
    • Upper Sum: $U(D,P) = \sum_{i=1}^k 1 \cdot (x_i - x_{i-1}) = b - a$.
    • Lower Sum: $L(D,P) = \sum_{i=1}^k 0 \cdot (x_i - x_{i-1}) = 0$.
  • Integrability Failure: $$\overline{\int_a^b} D(x) dx = b - a \quad \neq \quad \underline{\int_a^b} D(x) dx = 0$$ Because upper and lower integrals do not coincide, $D(x)$ is not Riemann integrable. $\blacksquare$

Part B: Proof for Bounded & Increasing Functions

  1. Automatic Bounding: For any $x \in [a,b]$, monotonicity implies $f(a) \le f(x) \le f(b)$. If $f(a) = f(b)$, $f$ is constant and integrable. Assume $f(a) < f(b)$.
  2. Setting Up Uniform Partition:
    • Fix $\varepsilon > 0$. Divide $[a,b]$ into $n$ equal subintervals.
    • Width of each subinterval: $\Delta x = \frac{b - a}{n}$.
  3. Evaluating Endpoint Extremes: Since $f$ is increasing on $[x_{i-1}, x_i]$: $$M_i = f(x_i) \quad \text{and} \quad m_i = f(x_{i-1})$$
  4. Telescoping the Darboux Difference: $$U(f,P) - L(f,P) = \sum_{i=1}^n \big[f(x_i) - f(x_{i-1})\big] \Delta x = \Delta x \sum_{i=1}^n \big[f(x_i) - f(x_{i-1})\big]$$ Expanding the sum reveals a telescoping structure: $$\sum_{i=1}^n \big[f(x_i) - f(x_{i-1})\big] = f(x_n) - f(x_0) = f(b) - f(a)$$
  5. Epsilon Bound Choice: $$U(f,P) - L(f,P) = \frac{(b - a)[f(b) - f(a)]}{n}$$ By choosing $n > \frac{(b - a)[f(b) - f(a)]}{\varepsilon}$, we guarantee $U(f,P) - L(f,P) < \varepsilon$.
  6. Conclusion: By Riemann's Criterion, $f$ is Riemann integrable on $[a,b]$. $\blacksquare$

Theoretical Context

  • Lebesgue's Criterion for Integrability: A bounded function on $[a,b]$ is Riemann integrable if and only if its set of discontinuities has Lebesgue measure zero.
  • Monotone Functions: Monotone functions have at most countably many discontinuities (measure zero), making them integrable.
  • Dirichlet Function: Discontinuous everywhere on $[a,b]$, yielding a discontinuity set of measure $b - a > 0$, explaining integrability failure.
