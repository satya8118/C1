Functional Equations of One Variable

Interactive Exploration for Bridge Math & Early University Level

Problem 0: Introductory Change of Variable \( f(x+1) = x^2 - 3x + 2 \)

Given \( f(x + 1) = x^2 - 3x + 2 \), find the explicit expression for \( f(x) \).
Hint:
• Method 1: Factor the quadratic expression on the right and rewrite every term directly in terms of \( (x + 1) \).
• Method 2: Use a classic change of variable: let \( t = x + 1 \implies x = t - 1 \), then substitute into the equation.
Full Solution (Two Methods):

Method 1: Algebraic Manipulation & Factoring

First, factor the given quadratic expression:

\[ x^2 - 3x + 2 = (x - 1)(x - 2) \]

Rewrite each linear factor so that \( (x + 1) \) explicitly appears:

\[ (x - 1) = (x + 1) - 2 \] \[ (x - 2) = (x + 1) - 3 \]

Substitute these expressions back into the equation:

\[ f(x + 1) = \left[(x + 1) - 2\right]\left[(x + 1) - 3\right] \]

Replacing the input variable \( (x + 1) \) with \( x \):

\[ f(x) = (x - 2)(x - 3) = x^2 - 5x + 6 \]

Method 2: Variable Substitution (Let \( x + 1 = t \))

Let \( t = x + 1 \). Express \( x \) in terms of \( t \):

\[ x = t - 1 \]

Substitute \( x = t - 1 \) everywhere into \( f(x + 1) = x^2 - 3x + 2 \):

\[ f(t) = (t - 1)^2 - 3(t - 1) + 2 \]

Expand and simplify:

\[ f(t) = (t^2 - 2t + 1) - (3t - 3) + 2 \] \[ f(t) = t^2 - 5t + 6 \]

Replacing the dummy variable \( t \) with \( x \):

\[ f(x) = x^2 - 5x + 6 \]
Conclusion: The function is \( f(x) = x^2 - 5x + 6 \).

Problem 1: Cauchy's Additive Equation

Find all continuous functions \( f: \mathbb{R} \to \mathbb{R} \) satisfying: \[ f(x + y) = f(x) + f(y) \quad \forall x, y \in \mathbb{R} \]
1.5
Hint:
1. Set \( x = y = 0 \) to find \( f(0) \).
2. Show by induction that \( f(nx) = n f(x) \) for all \( n \in \mathbb{N} \).
3. Extend this result to integers \( \mathbb{Z} \), then to rational numbers \( \mathbb{Q} \).
4. Apply continuity to extend from \( \mathbb{Q} \) to all real numbers \( \mathbb{R} \).
Full Solution:
  1. Step 1 (Base Value): Letting \( x = y = 0 \) gives \( f(0) = f(0) + f(0) \implies f(0) = 0 \).
  2. Step 2 (Positive Integers): For \( n \in \mathbb{N} \), repeated application gives \( f(nx) = n f(x) \). Let \( f(1) = c \). Then \( f(n) = c \cdot n \).
  3. Step 3 (Naturals & Integers): \( f(x + (-x)) = f(0) = 0 \implies f(-x) = -f(x) \). Thus, \( f(q) = cq \) for all \( q \in \mathbb{Z} \).
  4. Step 4 (Rationals): For \( q = \frac{m}{n} \in \mathbb{Q} \), notice \( n f\left(\frac{m}{n}\right) = f\left(n \cdot \frac{m}{n}\right) = f(m) = cm \implies f\left(\frac{m}{n}\right) = c \frac{m}{n} \).
  5. Step 5 (Continuity): Every real number \( x \) is a limit of a sequence of rational numbers \( q_k \to x \). Since \( f \) is continuous: \[ f(x) = \lim_{k \to \infty} f(q_k) = \lim_{k \to \infty} c q_k = c x \]
Conclusion: The general continuous solution is \( f(x) = cx \) for any real constant \( c \).

Problem 2: Logarithmic-type Functional Equation

Find all continuous functions \( f: (0, \infty) \to \mathbb{R} \) satisfying: \[ f(xy) = f(x) + f(y) \quad \forall x, y > 0 \]
1.0
Hint:
Transform the multiplicative domain into an additive domain! Substitute \( x = e^u \) and \( y = e^v \), and define a new function \( g(u) = f(e^u) \).
Full Solution:

Let \( x = e^u \) and \( y = e^v \) for \( u, v \in \mathbb{R} \). Substituting these into the given relation:

\[ f(e^{u+v}) = f(e^u) + f(e^v) \]

Define \( g(u) = f(e^u) \). Then the equation becomes Cauchy's Additive Equation:

\[ g(u + v) = g(u) + g(v) \]

Since \( f \) is continuous, \( g \) is also continuous. From Problem 1, the continuous solution to Cauchy's equation is:

\[ g(u) = c u \quad \text{for some constant } c \]

Substituting back \( u = \ln x \):

\[ f(x) = g(\ln x) = c \ln x \]
Conclusion: The general continuous solution is \( f(x) = c \ln x \) (or \( k \log_b x \)).

Problem 3: Self-Inverses (Involutions)

Find continuous functions \( f: \mathbb{R} \setminus \{0\} \to \mathbb{R} \setminus \{0\} \) that are their own inverses: \[ f(f(x)) = x \quad \forall x \neq 0 \] Investigate the simple rational family \( f(x) = \frac{a}{x} \).
1.0
Hint:
Geometrically, the condition \( f(f(x)) = x \) means that the graph \( y = f(x) \) is symmetric across the main diagonal line \( y = x \).
Full Solution:

Functions satisfying \( f(f(x)) = x \) are called involutions.

  • The identity function \( f(x) = x \) is a trivial solution.
  • The reflection \( f(x) = -x \) is another straight-line solution.
  • For rational functions of the form \( f(x) = \frac{a}{x} \): \[ f(f(x)) = f\left(\frac{a}{x}\right) = \frac{a}{a/x} = x \] This satisfies the equation for any constant \( a \neq 0 \).
  • More generally, any function whose graph is symmetric about the line \( y = x \) satisfies \( f = f^{-1} \).
Key Insight: Geometric symmetry across \( y = x \) provides an infinite family of continuous non-linear involutions, such as \( f(x) = \frac{a}{x} \) or \( f(x) = c - x \).

Problem 4: Reciprocal Substitution Technique

Find all functions \( f: \mathbb{R} \setminus \{0\} \to \mathbb{R} \) satisfying: \[ 2 f(x) + 3 f\left(\frac{1}{x}\right) = x \quad \forall x \neq 0 \]
Hint:
Replace \( x \) with \( \frac{1}{x} \) throughout the equation to construct a second linear equation involving \( f(x) \) and \( f\left(\frac{1}{x}\right) \). Solve the system algebraically!
Full Solution:

Given the original equation:

\[ \text{(1)} \quad 2 f(x) + 3 f\left(\frac{1}{x}\right) = x \]

Substitute \( x \to \frac{1}{x} \) into (1):

\[ \text{(2)} \quad 2 f\left(\frac{1}{x}\right) + 3 f(x) = \frac{1}{x} \]

We now have a \( 2 \times 2 \) system of linear equations in terms of \( f(x) \) and \( f(1/x) \). Let's eliminate \( f(1/x) \):

  • Multiply equation (1) by 2: \( 4 f(x) + 6 f\left(\frac{1}{x}\right) = 2x \)
  • Multiply equation (2) by 3: \( 9 f(x) + 6 f\left(\frac{1}{x}\right) = \frac{3}{x} \)

Subtract the first result from the second:

\[ (9 f(x) - 4 f(x)) + 0 = \frac{3}{x} - 2x \] \[ 5 f(x) = \frac{3}{x} - 2x \] \[ f(x) = \frac{3}{5x} - \frac{2x}{5} \]
Conclusion: The unique solution is \( f(x) = \frac{3 - 2x^2}{5x} \).

Problem 5: Interaction with the Inverse Function

Let \( f: \mathbb{R} \to \mathbb{R} \) be a strictly increasing bijective function such that: \[ f(x) + f^{-1}(x) = 2x \quad \forall x \in \mathbb{R} \] Prove that \( f(x) = x + c \) for some real constant \( c \).
Hint:
Define a sequence by composition: let \( x_0 = a \), \( x_1 = f(x_0) \), \( x_2 = f(x_1) \), and so on. Rewrite the functional equation as a second-order linear recurrence relation: \( x_{n+1} - 2x_n + x_{n-1} = 0 \).
Full Solution:

Let \( x \in \mathbb{R} \). Define a sequence \( (x_n)_{n \in \mathbb{Z}} \) such that \( x_0 = x \) and \( x_{n+1} = f(x_n) \).

Since \( x_{n+1} = f(x_n) \), applying \( f^{-1} \) yields \( x_{n-1} = f^{-1}(x_n) \).

Substitute \( x = x_n \) into the original functional equation:

\[ f(x_n) + f^{-1}(x_n) = 2x_n \implies x_{n+1} + x_{n-1} = 2x_n \]

This is a linear second-order difference equation:

\[ x_{n+1} - 2x_n + x_{n-1} = 0 \]

The characteristic equation is \( r^2 - 2r + 1 = 0 \implies (r - 1)^2 = 0 \), which has a repeated root \( r = 1 \).

The general solution to this recurrence relation is:

\[ x_n = A + B n \]

For \( n = 0 \): \( x_0 = A = x \).

For \( n = 1 \): \( x_1 = f(x) = A + B = x + B \).

Notice that \( B = f(x) - x \). To ensure \( B \) is independent of \( x \), let \( B = f(0) - 0 = c \).

Conclusion: The general continuous solution is \( f(x) = x + c \) for any real constant \( c \).

Problem 6: Exponential-type Cauchy Equation

Find all continuous functions \( f: \mathbb{R} \to \mathbb{R} \) satisfying: \[ f(x + y) = f(x) f(y) \quad \forall x, y \in \mathbb{R} \]
2.0
Hint:
1. Test \( f(x) = 0 \) for all \( x \).
2. If \( f \) is not identically zero, show \( f(x) > 0 \) everywhere by writing \( f(x) = \left[f\left(\frac{x}{2}\right)\right]^2 \).
3. Take the logarithm of both sides to convert it into Cauchy's Additive Equation!
Full Solution:
  1. Case 1 (Trivial Solution): If \( f(x_0) = 0 \) for some \( x_0 \), then \( f(x) = f(x - x_0 + x_0) = f(x - x_0)f(x_0) = 0 \) for all \( x \). So \( f(x) \equiv 0 \) is a solution.
  2. Case 2 (Non-zero Solutions): Assume \( f(x) \neq 0 \) anywhere. Notice that: \[ f(x) = f\left(\frac{x}{2} + \frac{x}{2}\right) = \left[ f\left(\frac{x}{2}\right) \right]^2 > 0 \] Since \( f(x) > 0 \) for all \( x \), we can safely take the natural logarithm of both sides: \[ \ln f(x + y) = \ln(f(x) f(y)) = \ln f(x) + \ln f(y) \]
  3. Reduction to Additive Cauchy: Define \( g(x) = \ln f(x) \). Then \( g(x+y) = g(x) + g(y) \). Since \( f \) is continuous, \( g \) is continuous. Thus, \( g(x) = cx \) for some real constant \( c \).
  4. Exponentiate Back: \[ \ln f(x) = cx \implies f(x) = e^{cx} = (e^c)^x = a^x \quad \text{where } a = e^c > 0 \]
Conclusion: The continuous solutions are \( f(x) \equiv 0 \) and \( f(x) = a^x \) for any constant \( a > 0 \).

Problem 7: d'Alembert's (Cosine) Functional Equation

Find all continuous non-zero functions \( f: \mathbb{R} \to \mathbb{R} \) satisfying \( f(0) = 1 \) and: \[ f(x + y) + f(x - y) = 2 f(x) f(y) \quad \forall x, y \in \mathbb{R} \]
2.0
Hint:
Recall the trigonometric identity for the sum of cosines: \( \cos(x+y) + \cos(x-y) = 2 \cos x \cos y \). Also recall the hyperbolic cosine identity: \( \cosh(x+y) + \cosh(x-y) = 2 \cosh x \cosh y \).
Full Solution:

This fundamental relation in wave mechanics is known as d'Alembert's functional equation.

  • Symmetry: Setting \( x = 0 \) gives \( f(y) + f(-y) = 2 f(0) f(y) = 2 f(y) \implies f(-y) = f(y) \). Thus, \( f \) is an even function.
  • Bounded Case (\(|f(x)| \le 1\)): The trigonometric identity: \[ \cos(\omega(x+y)) + \cos(\omega(x-y)) = 2 \cos(\omega x) \cos(\omega y) \] shows that \( f(x) = \cos(\omega x) \) is a continuous solution for any real parameter \( \omega \).
  • Unbounded Case (\(|f(x)| \ge 1\)): The hyperbolic identity: \[ \cosh(kx+ky) + \cosh(kx-ky) = 2 \cosh(kx) \cosh(ky) \] shows that \( f(x) = \cosh(kx) \) is also a valid continuous solution.
Conclusion: The non-zero continuous solutions are \( f(x) = \cos(\omega x) \) and \( f(x) = \cosh(kx) \).

Problem 8: Cyclic Group Substitution (Order 3)

Find all functions \( f: \mathbb{R} \setminus \{0, 1\} \to \mathbb{R} \) satisfying: \[ f(x) + f\left(\frac{x - 1}{x}\right) = 1 + x \quad \forall x \neq 0, 1 \]
Hint:
Define the transformation \( T(x) = \frac{x - 1}{x} = 1 - \frac{1}{x} \). Compute \( T(T(x)) \) and \( T(T(T(x))) \) to reveal a cyclic loop of length 3!
Full Solution:

Let \( T(x) = \frac{x - 1}{x} \). Notice how repeating this substitution cycles back:

  1. \( T(x) = \frac{x - 1}{x} \)
  2. \( T(T(x)) = \frac{\frac{x-1}{x} - 1}{\frac{x-1}{x}} = \frac{-1/x}{(x-1)/x} = \frac{1}{1 - x} \)
  3. \( T(T(T(x))) = \frac{\frac{1}{1-x} - 1}{\frac{1}{1-x}} = \frac{x/(1-x)}{1/(1-x)} = x \)

Because \( T(T(T(x))) = x \), iterating three times produces a system of 3 linear equations:

  • Eq 1: \( f(x) + f\left(\frac{x-1}{x}\right) = 1 + x \)
  • Eq 2 (sub \( x \to \frac{x-1}{x} \)): \( f\left(\frac{x-1}{x}\right) + f\left(\frac{1}{1-x}\right) = 1 + \frac{x-1}{x} = 2 - \frac{1}{x} \)
  • Eq 3 (sub \( x \to \frac{1}{1-x} \)): \( f\left(\frac{1}{1-x}\right) + f(x) = 1 + \frac{1}{1-x} = \frac{2-x}{1-x} \)

To isolate \( f(x) \), add Eq 1 and Eq 3, then subtract Eq 2:

\[ 2 f(x) = (1 + x) + \left(\frac{2-x}{1-x}\right) - \left(2 - \frac{1}{x}\right) \] \[ f(x) = \frac{x^3 - x^2 - 1}{2x(x - 1)} \]
Conclusion: The unique solution is \( f(x) = \frac{x^3 - x^2 - 1}{2x(x - 1)} \).

Problem 9: Jensen's Midpoint Equation

Find all continuous functions \( f: \mathbb{R} \to \mathbb{R} \) satisfying: \[ f\left(\frac{x + y}{2}\right) = \frac{f(x) + f(y)}{2} \quad \forall x, y \in \mathbb{R} \]
1.0 0.5
Hint:
Define a shifted function \( g(x) = f(x) - f(0) \). Show that \( g(x) \) satisfies Cauchy's Additive Equation \( g(x+y) = g(x) + g(y) \).
Full Solution:
  1. Set \( y = 0 \): \[ f\left(\frac{x}{2}\right) = \frac{f(x) + f(0)}{2} \implies f(x) = 2 f\left(\frac{x}{2}\right) - f(0) \]
  2. Substitute this expression for \( f\left(\frac{x+y}{2}\right) \) into Jensen's equation: \[ \frac{f(x+y) + f(0)}{2} = \frac{f(x) + f(y)}{2} \implies f(x+y) + f(0) = f(x) + f(y) \]
  3. Define \( g(x) = f(x) - f(0) \). Then \( g(0) = 0 \), and subtracting \( 2f(0) \) from both sides gives: \[ g(x+y) = g(x) + g(y) \]
  4. Since \( f \) is continuous, \( g \) is continuous. From Cauchy's Additive Equation (Problem 1), \( g(x) = mx \) for some constant \( m \).
  5. Therefore: \[ f(x) = g(x) + f(0) = mx + b \quad \text{where } b = f(0) \]
Conclusion: The continuous solutions to Jensen's equation are all linear functions \( f(x) = mx + b \).

Problem 10: Polynomial Product-Sum Relation

Find all polynomials \( P(x) \) satisfying: \[ P(x) P\left(\frac{1}{x}\right) = P(x) + P\left(\frac{1}{x}\right) \quad \forall x \neq 0 \]
Hint:
Rearrange the equation into \( \left[ P(x) - 1 \right] \left[ P\left(\frac{1}{x}\right) - 1 \right] = 1 \). Let \( Q(x) = P(x) - 1 \) and compare degrees of terms!
Full Solution:

Rearranging the given equation:

\[ P(x) P\left(\frac{1}{x}\right) - P(x) - P\left(\frac{1}{x}\right) + 1 = 1 \] \[ \left[ P(x) - 1 \right] \left[ P\left(\frac{1}{x}\right) - 1 \right] = 1 \]

Define \( Q(x) = P(x) - 1 \). Then \( Q(x) Q\left(\frac{1}{x}\right) = 1 \).

Let \( Q(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_0 \). Then:

\[ \left( a_n x^n + \dots + a_0 \right) \left( a_n x^{-n} + \dots + a_0 \right) = 1 \]

Multiplying out the highest and lowest powers forces all intermediate coefficients to vanish: \( a_{n-1} = a_{n-2} = \dots = a_1 = 0 \), and \( a_0 = 0 \). Thus \( Q(x) = \pm x^n \).

Substituting back \( P(x) = Q(x) + 1 \):

\[ P(x) = 1 \pm x^n \quad \text{for } n \in \mathbb{N}_0 \]
Conclusion: The polynomial solutions are \( P(x) = 1 + x^n \) and \( P(x) = 1 - x^n \) (including the constant polynomial \( P(x) \equiv 2 \)).

Problem 11: Product of Derivatives Equals Scaling \( f'(x)f''(x) = f(2x) \)

Consider the nonlinear differential-functional equation: \[ f'(x) f''(x) = f(2x) \] Analyze the potential solutions under different functional classes:
  1. Polynomial Class: Show first that the degree of any non-zero polynomial solution must be 3. Then, assuming \( f(x) = ax^3 + bx^2 + cx + d \), show that \( a = 4/9 \) and \( b = c = d = 0 \).
  2. Exponential Class: If \( f(x) = A e^{kx} \), does a non-trivial solution exist?
  3. Trigonometric Class: If \( f(x) = A \sin(kx) \) or \( A \cos(kx) \), does a solution exist?
  4. Power Series Class: Analyze \( f(x) = \sum_{n=0}^\infty a_n x^n \).
Hint:
• Degree Proof: Equate leading powers: if \(\deg(f) = n\), the leading term of \(f'(x)f''(x)\) has power \((n-1)+(n-2) = 2n-3\), while \(f(2x)\) has power \(n\).
• Coefficient Matching: For \(f(x) = ax^3 + bx^2 + cx + d\), compute \(f'(x)\) and \(f''(x)\), expand the product, and equate coefficients with \(f(2x) = 8ax^3 + 4bx^2 + 2cx + d\) term-by-term starting from constant/linear terms up to \(x^3\).
Full Analysis by Functional Class:

1) Polynomial Class Analysis

Step A: Prove degree must be 3.
Let \( f(x) = A_n x^n + A_{n-1}x^{n-1} + \dots + A_0 \) with leading coefficient \( A_n \neq 0 \) and degree \( n \ge 2 \).
• The leading term of \( f'(x) \) is \( n A_n x^{n-1} \).
• The leading term of \( f''(x) \) is \( n(n-1) A_n x^{n-2} \).
• The leading term of \( f'(x) f''(x) \) is \( n^2 (n-1) A_n^2 x^{2n-3} \).
• The leading term of \( f(2x) \) is \( A_n (2x)^n = 2^n A_n x^n \).

Equating leading powers gives:

\[ 2n - 3 = n \implies n = 3 \]

Step B: Solve for coefficients of \( f(x) = ax^3 + bx^2 + cx + d \).
Compute derivatives and expansions:

  • \( f'(x) = 3ax^2 + 2bx + c \)
  • \( f''(x) = 6ax + 2b \)
  • \( f(2x) = 8ax^3 + 4bx^2 + 2cx + d \)

Multiply \( f'(x) f''(x) \):

\[ \begin{aligned} f'(x) f''(x) &= (3ax^2 + 2bx + c)(6ax + 2b) \\ &= 18a^2 x^3 + (6ab + 12ab)x^2 + (4b^2 + 6ac)x + 2bc \\ &= 18a^2 x^3 + 18ab x^2 + (4b^2 + 6ac)x + 2bc \end{aligned} \]

Equating coefficients of \( f'(x)f''(x) \) and \( f(2x) \):

  1. \( x^3 \)-term: \( 18a^2 = 8a \implies a = \frac{8}{18} = \frac{4}{9} \) (since \( a \neq 0 \)).
  2. \( x^2 \)-term: \( 18ab = 4b \implies \left(18 \cdot \frac{4}{9}\right) b = 4b \implies 8b = 4b \implies 4b = 0 \implies b = 0 \).
  3. Constant term: Comparing constants gives \( 2bc = d \). Since \( b = 0 \), we get \( d = 0 \).
  4. \( x \)-term: \( 4b^2 + 6ac = 2c \implies 0 + 6\left(\frac{4}{9}\right)c = 2c \implies \frac{8}{3}c = 2c \implies \frac{2}{3}c = 0 \implies c = 0 \).
Polynomial Solution: \( a = \frac{4}{9} \) and \( b = c = d = 0 \implies f(x) = \frac{4}{9}x^3 \) (or trivial \( f(x) \equiv 0 \)).

2) Exponential Class

Test \( f(x) = A e^{kx} \) for constants \( A \neq 0, k \neq 0 \):

  • \( f'(x) = A k e^{kx} \), \quad \( f''(x) = A k^2 e^{kx} \)
  • \( f'(x) f''(x) = A^2 k^3 e^{2kx} \)
  • \( f(2x) = A e^{2kx} \)

Equating both sides gives \( A^2 k^3 e^{2kx} = A e^{2kx} \implies A k^3 = 1 \implies A = \frac{1}{k^3} \).

Exponential Solution: \( f(x) = \frac{1}{k^3} e^{kx} \) for any real constant \( k \neq 0 \) (e.g., \( e^x \), \( \frac{1}{8}e^{2x} \)).

3) Trigonometric Class

Test \( f(x) = A \sin(kx) \):

  • \( f'(x) = A k \cos(kx) \), \quad \( f''(x) = -A k^2 \sin(kx) \)
  • \( f'(x) f''(x) = -A^2 k^3 \sin(kx) \cos(kx) = -\frac{1}{2} A^2 k^3 \sin(2kx) \)
  • \( f(2x) = A \sin(2kx) \)

Equating both sides: \( -\frac{1}{2} A^2 k^3 \sin(2kx) = A \sin(2kx) \implies A k^3 = -2 \implies A = -\frac{2}{k^3} \).

Trigonometric Solution: \( f(x) = -\frac{2}{k^3} \sin(kx) \) for any \( k \neq 0 \) (e.g., \( -2\sin x \)).

4) Power Series Class

Let \( f(x) = \sum_{n=m}^\infty a_n x^n \) where \( m \) is the lowest non-zero power (\( a_m \neq 0 \)). Equating lowest powers gives \( 2m - 3 = m \implies m = 3 \).

Summary of Solutions to \( f'(x)f''(x) = f(2x) \):
• Polynomial: \( f(x) = \frac{4}{9}x^3 \)
• Exponential: \( f(x) = \frac{1}{k^3} e^{kx} \)
• Trigonometric: \( f(x) = -\frac{2}{k^3} \sin(kx) \)
• Power Series: \( f(x) = \frac{4}{9}x^3 + \sum_{n=4}^\infty a_n x^n \) \(\blacksquare\)

Problem 12: Involutive Fraction Transformation

Find all functions \( f: \mathbb{R} \setminus \{1\} \to \mathbb{R} \) satisfying: \[ f\left(\frac{x}{x - 1}\right) = 2 f(x) + x^2 \quad \forall x \neq 1 \]
Hint:
Define the substitution transformation \( T(x) = \frac{x}{x - 1} \). Compute \( T(T(x)) \) to show that this transformation is an involution (its own inverse). Substitute \( u = \frac{x}{x-1} \) back into the functional equation to generate a second linear relation!
Full Solution:

Let \( T(x) = \frac{x}{x - 1} \). Check the iteration of \( T \):

\[ T(T(x)) = \frac{\frac{x}{x-1}}{\frac{x}{x-1} - 1} = \frac{\frac{x}{x-1}}{\frac{x - (x - 1)}{x-1}} = \frac{x}{1} = x \]

Since \( T(T(x)) = x \), substituting \( x \to \frac{x}{x-1} \) toggles the arguments back and forth, giving an order-2 linear system:

Equation (1): Original equation

\[ \text{(1)} \quad f\left(\frac{x}{x - 1}\right) - 2 f(x) = x^2 \]

Equation (2): Substitute \( x \to \frac{x}{x - 1} \) into (1):

\[ f(x) - 2 f\left(\frac{x}{x - 1}\right) = \left(\frac{x}{x - 1}\right)^2 \]

We now eliminate \( f\left(\frac{x}{x-1}\right) \) from the system:

  • Multiply Equation (1) by 2: \[ 2 f\left(\frac{x}{x - 1}\right) - 4 f(x) = 2x^2 \]
  • Add Equation (2) to this result: \[ \left[ 2 f\left(\frac{x}{x - 1}\right) - 4 f(x) \right] + \left[ f(x) - 2 f\left(\frac{x}{x - 1}\right) \right] = 2x^2 + \frac{x^2}{(x - 1)^2} \]
  • Simplify the left-hand side: \[ -3 f(x) = 2x^2 + \frac{x^2}{(x - 1)^2} \]

Divide both sides by \(-3\):

\[ f(x) = -\frac{2}{3}x^2 - \frac{x^2}{3(x - 1)^2} \]

Combine into a single common rational fraction:

\[ f(x) = -\frac{x^2 \left(2(x - 1)^2 + 1\right)}{3(x - 1)^2} = -\frac{x^2 (2x^2 - 4x + 3)}{3(x - 1)^2} \]
Conclusion: The unique solution is \( f(x) = -\frac{2x^4 - 4x^3 + 3x^2}{3(x - 1)^2} \).

Problem 13: Algebraic Identity Substitution \( f\left(x - \frac{1}{x}\right) = x^3 - \frac{1}{x^3} \)

Find all functions \( f: \mathbb{R} \to \mathbb{R} \) satisfying: \[ f\left(x - \frac{1}{x}\right) = x^3 - \frac{1}{x^3} \quad \forall x \neq 0 \]
Hint:
Let \( t = x - \frac{1}{x} \). Express the right-hand side \( x^3 - \frac{1}{x^3} \) in terms of \( t \) by expanding \( t^3 = \left(x - \frac{1}{x}\right)^3 \).
Full Solution:

Let \( t = x - \frac{1}{x} \). We cube both sides of this substitution:

\[ t^3 = \left(x - \frac{1}{x}\right)^3 = x^3 - 3x^2\left(\frac{1}{x}\right) + 3x\left(\frac{1}{x^2}\right) - \frac{1}{x^3} \]

Group the terms to highlight \( \left(x - \frac{1}{x}\right) \):

\[ t^3 = x^3 - \frac{1}{x^3} - 3\left(x - \frac{1}{x}\right) \]

Substitute \( t = x - \frac{1}{x} \) back into the identity:

\[ t^3 = x^3 - \frac{1}{x^3} - 3t \]

Rearranging to solve for \( x^3 - \frac{1}{x^3} \):

\[ x^3 - \frac{1}{x^3} = t^3 + 3t \]

Since \( f\left(x - \frac{1}{x}\right) = x^3 - \frac{1}{x^3} \), substituting \( t \) gives:

\[ f(t) = t^3 + 3t \]

Since the range of \( t = x - \frac{1}{x} \) for \( x \neq 0 \) covers all of \( \mathbb{R} \), this relationship holds for all real numbers.

Conclusion: The unique solution is \( f(x) = x^3 + 3x \).

Problem 14: Cyclic Linear Fraction System \( f(x) + f\left(\frac{1}{1-x}\right) = x \)

Find all functions \( f: \mathbb{R} \setminus \{0, 1\} \to \mathbb{R} \) satisfying: \[ f(x) + f\left(\frac{1}{1-x}\right) = x \quad \forall x \neq 0, 1 \]
Hint:
Define the transformation \( T(x) = \frac{1}{1-x} \). Calculate \( T(T(x)) \) and \( T(T(T(x))) \) to reveal an order-3 cyclic loop. Successively substitute these arguments into the functional equation to set up a system of 3 linear equations.
Full Solution:

Consider the substitution map \( T(x) = \frac{1}{1-x} \). Let's trace its iterations:

  1. \( T(x) = \frac{1}{1-x} \)
  2. \( T(T(x)) = \frac{1}{1 - \frac{1}{1-x}} = \frac{1}{\frac{-x}{1-x}} = \frac{x-1}{x} = 1 - \frac{1}{x} \)
  3. \( T(T(T(x))) = \frac{1}{1 - \left(1 - \frac{1}{x}\right)} = \frac{1}{1/x} = x \)

Because \( T(T(T(x))) = x \), performing three successive substitutions generates a system of 3 linear equations in terms of \( f(x) \), \( f\left(\frac{1}{1-x}\right) \), and \( f\left(\frac{x-1}{x}\right) \):

  • Eq 1: \( f(x) + f\left(\frac{1}{1-x}\right) = x \)
  • Eq 2 (sub \( x \to \frac{1}{1-x} \)): \( f\left(\frac{1}{1-x}\right) + f\left(\frac{x-1}{x}\right) = \frac{1}{1-x} \)
  • Eq 3 (sub \( x \to \frac{x-1}{x} \)): \( f\left(\frac{x-1}{x}\right) + f(x) = \frac{x-1}{x} \)

To isolate \( f(x) \), sum Eq 1 and Eq 3, then subtract Eq 2:

\[ 2f(x) = x + \left(\frac{x-1}{x}\right) - \left(\frac{1}{1-x}\right) \] \[ 2f(x) = x + 1 - \frac{1}{x} + \frac{1}{x-1} \] \[ 2f(x) = \frac{x \cdot x(x-1) + 1 \cdot x(x-1) - 1 \cdot (x-1) + 1 \cdot x}{x(x-1)} \] \[ 2f(x) = \frac{x^3 - x^2 + x^2 - x - x + 1 + x}{x(x-1)} = \frac{x^3 - x + 1}{x(x-1)} \]

Dividing by 2 gives:

\[ f(x) = \frac{x^3 - x + 1}{2x(x-1)} \]
Conclusion: The unique solution is \( f(x) = \frac{x^3 - x + 1}{2x(x-1)} \).

Problem 15: Coupled Product-Sum Relation \( f(x)f(y) = f(x+y) + xy \)

Find all functions \( f: \mathbb{R} \to \mathbb{R} \) satisfying: \[ f(x) f(y) = f(x + y) + xy \quad \forall x, y \in \mathbb{R} \]
Hint:
1. Set \( x = y = 0 \) to determine the possible values of \( f(0) \).
2. Set \( y = 0 \) to see what \( f(0) \) forces upon \( f(x) \).
3. Test linear functions of the form \( f(x) = ax + b \) or test small integer inputs to narrow down the possible functional form.
Full Solution:

Step 1: Evaluate at origin

Let \( x = 0 \) and \( y = 0 \):

\[ f(0)^2 = f(0) + 0 \implies f(0)^2 - f(0) = 0 \implies f(0)(f(0) - 1) = 0 \]

Thus, either \( f(0) = 0 \) or \( f(0) = 1 \).

Case 1: Assume \( f(0) = 0 \)

Set \( y = 0 \) in the original equation:

\[ f(x) f(0) = f(x + 0) + 0 \implies f(x) \cdot 0 = f(x) \implies f(x) = 0 \quad \forall x \in \mathbb{R} \]

Checking \( f(x) \equiv 0 \) in the main equation gives \( 0 = 0 + xy \implies xy = 0 \), which is not true for all \( x, y \). Hence, \( f(0) \neq 0 \).

Case 2: Assume \( f(0) = 1 \)

Set \( y = -x \):

\[ f(x) f(-x) = f(0) - x^2 = 1 - x^2 \]

Now set \( y = 1 \):

\[ f(x) f(1) = f(x + 1) + x \]

Let \( f(1) = k \). Then \( f(x+1) = k f(x) - x \).

Testing candidate solutions of linear form \( f(x) = ax + b \):

  • Since \( f(0) = 1 \), we have \( b = 1 \), so \( f(x) = ax + 1 \).
  • Substitute \( f(x) = ax + 1 \) into the main functional equation: \[ (ax + 1)(ay + 1) = a(x + y) + 1 + xy \] \[ a^2 xy + a x + a y + 1 = a x + a y + 1 + xy \]

Comparing the \( xy \) terms on both sides:

\[ a^2 xy = xy \implies a^2 = 1 \implies a = 1 \text{ or } a = -1 \]

Verification:

  1. If \( a = 1 \implies f(x) = x + 1 \): \[ (x + 1)(y + 1) = xy + x + y + 1 = (x + y + 1) + xy = f(x + y) + xy \quad \checkmark \]
  2. If \( a = -1 \implies f(x) = 1 - x \): \[ (1 - x)(1 - y) = 1 - x - y + xy = (1 - (x + y)) + xy = f(x + y) + xy \quad \checkmark \]
Conclusion: The only solutions are \( f(x) = x + 1 \) and \( f(x) = 1 - x \).
