Lecture 8 · Functions

Functions: the object calculus is actually about

Lecture 1 ended with a promise: everything in this course — limits, derivatives, integrals — is a statement about functions. Today we make "function" precise, and get comfortable with the vocabulary (domain, codomain, range, equality) and the two properties (one-one, onto) that will keep coming back all semester.

01Getting precise

The definition of a function

Let \(X\) and \(Y\) be two nonempty sets. A function (also called a map or mapping) from \(X\) to \(Y\) is a rule that assigns to each element of \(X\) a unique element of \(Y\).

Two separate requirements are hiding inside that one sentence, and it's worth pulling them apart, because most "is this a function?" mistakes come from missing one of them:

1. Every input is used. Each element of \(X\) must be associated with some element of \(Y\) — no input is left without an output.
2. No input is ambiguous. No element of \(X\) may be associated with more than one element of \(Y\) — the rule can't hand back two different answers for the same input.

Compactly:

\(f:X\to Y\) is a function if \(\forall x\in X,\ \exists\) unique \(y\in Y\ \big(f(x)=y\big).\)
Interactive — is this a rule from \(X\) to \(Y\) actually a function?

Every dot in \(X\) sends out exactly one arrow, and every arrow lands in \(Y\). That's all a function is — no formula required.

Two classic failure modes: (a) the rule simply isn't defined for some inputs — e.g. "the reciprocal of \(x\)" isn't defined at \(x=0\), so as a rule on all of \(\mathbb{R}\) it fails requirement 1; (b) the rule is ambiguous — e.g. "a square root of \(x\)" for \(x>0\) has two answers, \(+\sqrt x\) and \(-\sqrt x\), so it fails requirement 2 unless you specify which root you mean.

If \(f:X\to Y\) is a function and \(f(x)=y\), the vocabulary is:

Domain. \(X\) is the domain of \(f\) — the set of legal inputs.
Codomain. \(Y\) is the codomain of \(f\) — the set the outputs are declared to live in (not necessarily all reached — more on this soon).
Image. \(y\) is the image of \(x\) under \(f\) — there's only one, by requirement 2.
Preimage. \(x\) is a preimage of \(y\) — there could be more than one \(x\) mapping to the same \(y\), which is why it's "a" and not "the."
02Stress-testing the definition

Is it a function? Three familiar "rules"

Let \(H\) be the set of all human beings. For each rule below, ask: does every person have exactly one output, or does the rule break requirement 1, requirement 2, or both?

\(x \mapsto\) father of \(x\) function

Every person has exactly one biological father, and that father is himself a person in \(H\). Both requirements hold.

\(x \mapsto\) parent of \(x\) not a function

A person typically has two parents, not one. "Parent of \(x\)" doesn't pin down a unique output — requirement 2 fails.

\(x \mapsto\) child of \(x\) not a function

Some people have zero children (requirement 1 fails) and some have several (requirement 2 fails also). This rule fails on both counts.

A working example: "\(s\mapsto\) the student sitting to \(s\)'s immediate right in the last session" — as long as every seat has a well-defined neighbour and no student is seated at the very end with nobody there (or you fix that edge case, e.g. by seating students in a circle). Notice how quickly the two requirements from Section 1 become the actual thing you have to check by hand. A few more to test on your own: "\(s\mapsto\) \(s\)'s registration number," "\(s\mapsto\) the first student alphabetically in \(s\)'s discussion group," "\(s\mapsto\) \(s\)'s best friend in the class."
03Named examples you'll reuse constantly

Constant functions, the identity, and inclusion

Let \(X\) and \(Y\) be nonempty sets and fix some \(y_0\in Y\). The function defined by \(f(x)=y_0\) for every \(x\in X\) is a constant function:

\(\forall x\in X\ \big(f(x)=y_0\big).\)

More precisely, \(f:X\to Y\) is a constant map if \(\exists y_0\in Y\ \big(\forall x\in X\ (f(x)=y_0)\big)\) — note where the quantifiers sit: one fixed \(y_0\) has to work for every \(x\).

If \(|X|=1\): every function \(f:X\to Y\) is automatically constant — with only one input, there's nothing for the output to vary against.

Converse? No. \(|Y|=1\) also forces every function to be constant (there's only one possible output value), regardless of the size of \(X\). So "every function \(X\to Y\) is constant" can happen for a reason having nothing to do with \(|X|=1\).

Iff statement: "Every function from \(X\) to \(Y\) is constant \(\iff\) \(|X|=1\) or \(|Y|=1\)" — this direction is true. (Try to see why \(|X|,|Y|\ge 2\) always lets you build a non-constant function.)

Counting them: if \(|Y|=n\), there are exactly \(n\) different constant functions \(X\to Y\) — one for each choice of \(y_0\).

Let \(X\) be a nonempty set. The function \(f:X\to X\) defined by \(f(x)=x\) is the identity function on \(X\).

Exactly one — the rule \(x\mapsto x\) is completely determined once \(X\) is fixed, unlike a constant function where \(y_0\) could be any of \(|Y|\) choices.

Finally, if \(\emptyset\ne A\subseteq B\), the map \(\iota:A\to B\) defined by \(x\mapsto x\) is the inclusion map, written \(A\hookrightarrow B\). It looks identical to the identity function as a formula, but it isn't one — the codomain is \(B\), not \(A\), which matters once we get to "onto" in a few sections.

04Codomain vs. what's actually hit

The range of a function

The codomain of \(f:X\to Y\) is the set of allowed outputs. The range, \(R(f)\), is the set of outputs that actually get hit:

\(R(f)=\{y\in Y \mid \exists x\in X \text{ such that } f(x)=y\}.\)
Q1

\(R(f)\) is a subset of what?

\(R(f)\subseteq Y\), the codomain. It need not equal \(Y\) — when it does, we'll call \(f\) "onto," coming up in Section 6.
Q2

Let \(W\) be the set of all Indian states and union territories. Is \(f:S\to W\), \(s\mapsto\) the state where \(s\)'s present institute is located, a function? If so, what is its range?

Yes — every student's institute sits in exactly one state or union territory, so both requirements from Section 1 hold. The range is whichever subset of \(W\) actually contains a state where at least one student's institute is located — for a real class this is typically a small handful of states, far from all of \(W\).
Q3

For \(A\subseteq X\), define \(f(A)=\{y\in Y \mid \exists x\in A \text{ such that } f(x)=y\}\) (the image of the set \(A\)). Let \(S=\{A\subseteq X \mid f(A)=R(f)\}\). Is it true that \(S\ne\emptyset\)?

Yes. \(X\) itself is in \(S\), since \(f(X)=R(f)\) by definition of range. So \(S\) is never empty — though it can contain much smaller sets too; in fact, taking one preimage per element of \(R(f)\) already gives a (possibly much smaller) set in \(S\).
Q4 — for discussion

Let \(\mathbb{N}=\{1,2,3,\dots\}\). Give an example of a map from \(S\) (your class) to \(\mathbb{N}\). Find its range. Can the range equal the codomain? What are the possible values of \(|R(f)|\)?

One natural choice: \(s\mapsto\) the number of letters in \(s\)'s first name. This is a function (every name has a definite length), and its range is whatever set of positive integers actually occurs as a name-length in your class — typically a handful of small values, so \(R(f)\ne\mathbb{N}\) (the codomain is infinite, but a finite class can only hit finitely many values). In general \(|R(f)|\) can be anything from \(1\) (if the map happens to be constant) up to \(|S|\) (if the map is one-one) — but it can never equal \(|\mathbb{N}|\) here, since \(G_1\) itself is finite. Other natural choices your class might try: mobile number, roll number, age in years.
05Same formula isn't the whole story

Equality of functions

Two functions \(f:A\to B\) and \(g:C\to D\) are equal, \(f=g\), exactly when:

1. \(A=C\) and \(B=D\) — same domain and same codomain.
2. For every \(x\in A=C\), \(f(x)=g(x)\) — they agree at every point.

Both conditions matter: domain and codomain must match and the outputs must agree everywhere. A formula alone doesn't determine a function — the domain and codomain are part of its identity.

Try it

Let \(f,g:[0,\infty)\to\mathbb{R}\) with \(f(x)=x|x|\) and \(g(x)=x^2\). Are \(f\) and \(g\) equal?

Yes. On \([0,\infty)\), \(|x|=x\), so \(f(x)=x\cdot x=x^2=g(x)\) for every \(x\) in the shared domain, and the domains/codomains already match. (Off this domain the two formulas would disagree — for \(x<0\), \(x|x|=-x^2\ne x^2\) — which is exactly why the domain is part of the problem statement, not a footnote.)
Try it

Let \(A\subseteq\mathbb{R}\) and \(f,g:A\to\mathbb{R}\) with \(f(x)=x\) and \(g(x)=x^3\). Is \(f=g\)?

It depends entirely on \(A\). \(x=x^3\) exactly when \(x^3-x=0\), i.e. \(x(x-1)(x+1)=0\), i.e. \(x\in\{-1,0,1\}\). So \(f=g\) only when \(A\subseteq\{-1,0,1\}\); for any larger \(A\) (in particular \(A=\mathbb{R}\)), \(f\ne g\) even though both are perfectly good functions on \(A\).
Try it

Let \(f,g:\mathbb{R}\to\mathbb{R}\) with \(f(x)=x^4+4\) and \(g(x)=(x^2-2x+2)(x^2+2x+2)\). Is \(f=g\)?

Yes. Expand the product: \((x^2+2)^2-(2x)^2 = x^4+4x^2+4-4x^2=x^4+4\), matching \(f\) exactly — so they agree at every real \(x\), and the domain/codomain already match. This is a nice example of a factorization identity in disguise: \(x^4+4=(x^2-2x+2)(x^2+2x+2)\), a special case of the Sophie Germain identity.
Forward direction: true. If \(f\) and \(g\) are literally the same function, their ranges are trivially the same set. Converse: false. Two functions can have identical ranges without being equal — e.g. \(f,g:\mathbb{R}\to\mathbb{R}\) with \(f(x)=\sin x\) and \(g(x)=\cos x\) both have range \([-1,1]\), but \(f(0)=0\ne 1=g(0)\), so \(f\ne g\).
06No collisions allowed

One-one (injective) functions

A function \(f:X\to Y\) is one-one (injective) if distinct inputs always produce distinct outputs. Two equivalent ways to say it:

Def 1 (direct). \(\forall x_1,x_2\in X,\ x_1\ne x_2 \implies f(x_1)\ne f(x_2).\)
Def 2 (contrapositive). \(\forall x_1,x_2\in X,\ f(x_1)=f(x_2) \implies x_1=x_2.\)
They're contrapositives of each other. The statement "\(x_1\ne x_2\implies f(x_1)\ne f(x_2)\)" and the statement "\(f(x_1)=f(x_2)\implies x_1=x_2\)" say the same thing from opposite directions — and a statement is always logically equivalent to its contrapositive. In practice, Def 2 is usually the easier one to actually prove.
Worked example. Is \(f:\mathbb{R}\to\mathbb{R}\), \(f(x)=x^3\), one-one?

Take \(x\ne y\); we want \(f(x)\ne f(y)\), i.e. \(x^3-y^3\ne 0\). Factor: \(x^3-y^3=(x-y)(x^2+xy+y^2)\). Since \(x\ne y\), the first factor is nonzero, so it's enough to show the second factor \(x^2+xy+y^2\ne 0\). Three cases cover everything:

  • If one of \(x,y\) is \(0\) (say \(y=0\), \(x\ne0\)): the expression is \(x^2>0\).
  • If \(x,y\) have the same sign: every term \(x^2,\,xy,\,y^2\) is \(\ge0\) and \(x^2+y^2>0\), so the sum is positive.
  • If \(x,y\) have opposite signs: complete the square, \(x^2+xy+y^2=\left(x+\tfrac{y}{2}\right)^2+\tfrac{3y^2}{4}\ge \tfrac{3y^2}{4}>0\) since \(y\ne0\).

In every case the second factor is strictly positive, so \(x^3-y^3\ne0\) whenever \(x\ne y\). Hence \(f(x)=x^3\) is one-one on all of \(\mathbb{R}\).

The negation is worth stating explicitly, since "show it's not one-one" is usually the easier direction in practice:

\(f:X\to Y\) is not one-one if \(\exists\, x_1,x_2\in X,\ x_1\ne x_2,\ f(x_1)=f(x_2).\)

One explicit counterexample pair is all it ever takes to kill injectivity — you never need to check every pair.

07Nothing in the codomain is left out

Onto (surjective) functions

A function \(f:X\to Y\) is onto (surjective) if every element of the codomain actually gets hit:

Def 1. \(\forall y\in Y,\ \exists x\in X\ (f(x)=y).\)
Def 2. \(R(f)=f(X)=Y.\)
\(R(f)\subseteq Y\) always holds (Section 4, Q1). Def 1 says every \(y\in Y\) has a preimage, i.e. \(Y\subseteq R(f)\). Combine the two containments and you get \(R(f)=Y\), which is exactly Def 2 — and the argument reverses just as easily.
Which of these are onto?
  1. \(f:\mathbb{N}\to\mathbb{N}\), \(f(n)=n+1\).
  2. \(f:\mathbb{R}\to\mathbb{R}\), \(f(x)=\sin x\).
  3. \(f:\mathbb{N}\to\mathbb{N}\), where \(f(n)\) is the number of positive divisors of \(n\).
  4. \(f:\mathbb{R}\to\mathbb{R}\), \(f(x)=x^2+1\).

1. Not onto. \(1\in\mathbb{N}\) is never hit — \(n+1\ge2\) for every \(n\in\mathbb{N}\).

2. Not onto. \(\sin x\in[-1,1]\) always, so nothing outside \([-1,1]\) (e.g. \(2\)) is ever reached.

3. Onto. This one is easy to doubt but true: for any \(k\in\mathbb{N}\), the number \(n=p^{k-1}\) (for any prime \(p\)) has exactly \(k\) divisors, \(1,p,p^2,\dots,p^{k-1}\). So every positive integer \(k\) is hit by some \(n\) — the divisor-count function is onto \(\mathbb{N}\), even though it's very far from one-one.

4. Not onto. \(x^2+1\ge1\) always, so no value below \(1\) is ever reached.

A concrete picture: the cinema theatre. Let \(A\) be the set of patrons in a theatre and \(B\) the set of seats, with the natural map \(A\to B\) sending each patron to their assigned seat. This map is onto exactly when every seat has someone in it — which is precisely the moment the manager puts up the "Housefull" board. Onto has nothing to do with whether two patrons share a seat (that's the one-one question, and hopefully never happens); it's purely about whether the codomain — every seat — gets covered.
08Both properties at once

Bijections

A function that is both one-one and onto is a bijection. It's the sharpest kind of function: every element of the codomain is hit, and it's hit by exactly one element of the domain — so a bijection pairs up \(X\) and \(Y\) perfectly, element for element.

Interactive — one-one, onto, both, or neither?

A bijection is the only pattern where every dot on both sides has exactly one arrow touching it.

Try it

Give three different bijections from \(\mathbb{N}\) to \(\mathbb{N}\).

1. The identity, \(f(n)=n\).

2. Swap consecutive pairs: \(f(n)=n+1\) if \(n\) is odd, \(f(n)=n-1\) if \(n\) is even (so \(1\leftrightarrow2\), \(3\leftrightarrow4\), \(5\leftrightarrow6,\dots\)).

3. Swap two specific elements and fix everything else: \(f(1)=2\), \(f(2)=1\), \(f(n)=n\) for all \(n\ge3\).

There are, in fact, infinitely many bijections \(\mathbb{N}\to\mathbb{N}\) — far more than there are elements of \(\mathbb{N}\) itself, though making that precise needs cardinality arguments from later in the course.

Try it

Give examples of maps \(\mathbb{R}\to\mathbb{R}\) that are: (a) one-one but not onto, (b) onto but not one-one, (c) neither, (d) both.

(a) \(f(x)=e^x\): every output is distinct (one-one), but the range is only \((0,\infty)\), missing everything \(\le0\).

(b) \(f(x)=x^3-x\): a cubic, so it's onto \(\mathbb{R}\) (odd-degree polynomials always are), but it's not one-one — e.g. \(f(-1)=f(0)=f(1)=0\).

(c) \(f(x)=x^2\): misses negative outputs (not onto) and \(f(-1)=f(1)\) (not one-one).

(d) \(f(x)=x\), or any other odd-degree polynomial with positive leading coefficient and no repeated behaviour, e.g. \(f(x)=x^3\) is both one-one (shown in Section 6) and onto (every real number has a real cube root).

Try it

Let \(\varphi:\mathbb{N}\to\mathbb{N}\) be defined by \(\varphi(n)=|\{m\in\mathbb{N}\mid \gcd(m,n)=1,\ 1\le m\le n\}|\). What questions would you naturally ask about \(\varphi\)?

This \(\varphi\) is Euler's totient function — you'll meet it properly if you take number theory. Natural questions to ask of any new function, and worth asking here: Is it one-one? (No — \(\varphi(3)=\varphi(4)=\varphi(6)=2\).) Is it onto? (No — \(\varphi(n)\) is even for every \(n\ge3\), so odd values \(\ge3\) are never hit.) What is \(R(\varphi)\)? Can you compute \(\varphi(n)\) for small \(n\) by hand and look for a pattern? This is exactly the reflex — domain, range, one-one?, onto? — you now have for interrogating any function you meet for the first time.
Try it

Can you find a bijection from \(\mathbb{N}\) to \(\mathbb{Z}\)?

Yes — zig-zag through the integers, alternating sides of \(0\): \[ f(n)=\begin{cases}\dfrac{n-1}{2} & n \text{ odd} \\[4pt] -\dfrac{n}{2} & n \text{ even}\end{cases} \] So \(1\mapsto0,\ 2\mapsto-1,\ 3\mapsto1,\ 4\mapsto-2,\ 5\mapsto2,\dots\) — every integer, positive, negative, or zero, appears exactly once. This innocent-looking bijection is the first hint of something surprising later in the course: \(\mathbb{N}\) and \(\mathbb{Z}\) turn out to be "the same size" as infinite sets, even though \(\mathbb{Z}\) looks twice as big.
09Before next lecture

Self-assessment

Part A — recall

State the two requirements a rule must satisfy to be a function \(X\to Y\).

Every \(x\in X\) must be assigned some \(y\in Y\) (existence), and no \(x\) may be assigned more than one \(y\) (uniqueness).
Part A — recall

What is the difference between the codomain and the range of \(f:X\to Y\)?

The codomain \(Y\) is the declared set of possible outputs; the range \(R(f)\subseteq Y\) is the set of outputs actually achieved. They coincide exactly when \(f\) is onto.
Part B — apply

Is \(f:\mathbb{N}\to\mathbb{N}\), \(f(n)=n+1\), one-one? Is it onto?

One-one: yes — if \(n_1+1=n_2+1\) then \(n_1=n_2\). Onto: no — \(1\) is never in the range, since \(n+1\ge2\) for all \(n\in\mathbb{N}\). This is a clean example of one-one without onto on an infinite set — something that can't happen on a finite set of the same size on both sides.
Part B — apply

Are \(f,g:\mathbb{R}\to\mathbb{R}\) with \(f(x)=|x|\) and \(g(x)=\sqrt{x^2}\) equal functions?

Yes. Domains and codomains match (\(\mathbb{R}\to\mathbb{R}\)), and \(\sqrt{x^2}=|x|\) for every real \(x\) — this is in fact the standard definition of \(|x|\) in terms of the square root.
Part C — think

Explain why Def 2 of "one-one" (the contrapositive form) is usually easier to work with in a direct proof than Def 1.

Def 1 asks you to start from "\(x_1\ne x_2\)," a negative statement that's awkward to compute with. Def 2 asks you to start from "\(f(x_1)=f(x_2)\)," a positive equation you can manipulate algebraically (as in the \(x^3\) proof) until you conclude \(x_1=x_2\). Working forward from an equation is almost always easier than working forward from a "not equal."
Part C — think

A function \(f:X\to Y\) between two finite sets with \(|X|=|Y|\) is one-one if and only if it is onto. Why does this shortcut fail for infinite sets — and which example from today already proves it fails?

On a finite set, injectivity forces the images to be \(|X|\) distinct elements of \(Y\); if \(|X|=|Y|\), that already uses up every element of \(Y\), so one-one forces onto (and the symmetric argument gives the converse). On an infinite set there's room to "shift without running out" — exactly what \(f(n)=n+1\) on \(\mathbb{N}\) does in Part B above: it's one-one but misses \(1\), something no finite same-size example could ever do.
