Special Lecture · Real Analysis

The Intermediate Value Theorem, and how to actually use it

You don't need to solve every problem below yourself — the point of this lecture is to show you the pattern behind writing an IVT argument, so you recognize it instantly the next time it's hiding inside a problem. Every question here has a "Show solution" button: try the problem first, then click.

01Where it all starts

Bolzano's Theorem

If a continuous function is positive somewhere and negative somewhere else, it must be zero somewhere in between — you can't get from positive to negative without crossing zero if the graph never jumps.

f continuous, f(a) > 0, f(b) < 0
If \(f\) is continuous on \([a,b]\) and \(f(a)f(b)<0\), then there exists at least one \(c\in[a,b]\) with \(f(c)=0\).

It's automatic that \(c\in(a,b)\), strictly inside — since \(f(a)\ne0\) and \(f(b)\ne0\) (they're strictly positive/negative, as \(f(a)f(b)<0\) demands), \(c\) can't be an endpoint.

The condition \(f(a)f(b)<0\) is just a compact way of saying \(f(a)\) and \(f(b)\) have opposite signs — one is positive, one is negative, in either order. A continuous function genuinely cannot "skip over" zero to get from one sign to the other.

02Bolzano, generalized

The Intermediate Value Theorem

Bolzano's theorem is really just the special case where the target value is \(0\). Nothing about the argument cares that \(0\) is special — a continuous function hits every value between \(f(a)\) and \(f(b)\).

f continuous, k between f(a) and f(b)
If \(f\) is continuous on \([a,b]\) and \(k\) is any number between \(f(a)\) and \(f(b)\), then there exists at least one \(c\in[a,b]\) with \(f(c)=k\).

Yes — they're logically equivalent, meaning each can be proved from the other.

IVT \(\Rightarrow\) Bolzano: immediate — just take \(k=0\).

Bolzano \(\Rightarrow\) IVT: given \(f\) continuous on \([a,b]\) and \(k\) between \(f(a)\) and \(f(b)\), define \(g(x)=f(x)-k\). Then \(g\) is continuous, and \(g(a)g(b)=(f(a)-k)(f(b)-k)<0\) (since \(k\) sits strictly between \(f(a)\) and \(f(b)\), one factor is positive and one is negative). By Bolzano's theorem, \(\exists c\in(a,b)\) with \(g(c)=0\), i.e. \(f(c)=k\).

This shift-by-a-constant trick — replace "hits the value \(k\)" with "the shifted function hits \(0\)" — is the single most common move in every problem below. Watch for it.

03Problem 0

The image of an interval is an interval

Claim

Let \(J\subseteq\mathbb{R}\) be an interval and \(f:J\to\mathbb{R}\) continuous. Then \(f(J)\) is again an interval.

Recall what "interval" means for a set of real numbers: \(S\) is an interval exactly when, for any two points of \(S\), every point between them is also in \(S\). So take \(y_1,y_2\in f(J)\) with \(y_1

Write \(y_1=f(x_1)\) and \(y_2=f(x_2)\) for some \(x_1,x_2\in J\). Since \(y\) sits between \(f(x_1)\) and \(f(x_2)\), and \(f\) is continuous, the IVT gives some \(x\) between \(x_1\) and \(x_2\) with \(f(x)=y\). That \(x\) is in \(J\) too (intervals contain everything between two of their points), so \(y=f(x)\in f(J)\). Hence \(f(J)\) is an interval.

This single fact is the engine behind almost every problem that follows: once you know \(f\) is continuous on an interval, you're allowed to reason about which values it "must" hit just from knowing two values it already hits.

04Problems 1–2

Two warm-ups: existence of a root, and a fixed point

Problem 1

Show that the equation \(x^3+2x-5=0\) has a real root.

First understand what's being asked: existence of a root, not finding one.

Let \(f(x)=x^3+2x-5\). This is a polynomial, so \(f:\mathbb{R}\to\mathbb{R}\) is continuous. Check the endpoints of a convenient interval: \(f(1)=1+2-5=-2<0\) and \(f(2)=8+4-5=7>0\). By Bolzano's theorem, \(\exists c\in(1,2)\) with \(f(c)=0\).
Problem 2 — a fixed-point theorem

If \(f\) is continuous on \([0,1]\) with \(f(0)\ge0\) and \(f(1)\le1\), and \(f:[0,1]\to[0,1]\), show there is some \(c\in[0,1]\) with \(f(c)=c\).

\(c\) is called a fixed point: \(f\) sends \(c\) right back to itself. This says every continuous function from \([0,1]\) to itself must touch the line \(y=x\) at least once — try sketching a counterexample and you'll see why it's impossible without lifting your pen off the square.

A continuous f : [0,1] → [0,1] must cross y = x

The dashed line is \(y=x\); the solid curve is a sample continuous \(f\) with \(f(x)\in[0,1]\) throughout. Wherever the curve crosses the dashed diagonal — here at the point \(p\) — is a fixed point, \(f(p)=p\).

Since \(f:[0,1]\to[0,1]\), we know \(0\le f(x)\le1\) for every \(x\in[0,1]\). Two cases:

Case 1: \(f(0)=0\) or \(f(1)=1\). Then \(0\) or \(1\) is itself a fixed point — done immediately.

Case 2: \(f(0)\ne0\) and \(f(1)\ne1\). Combined with \(f:[0,1]\to[0,1]\), this forces \(00\) and \(f(1)<1\). Define \(g(x)=f(x)-x\), continuous on \([0,1]\) (difference of two continuous functions). Then \(g(0)=f(0)-0=f(0)>0\) and \(g(1)=f(1)-1<0\). By Bolzano's theorem, \(\exists c\in(0,1)\) with \(g(c)=0\), i.e. \(f(c)=c\).

05Problems 3–4

Finding two points exactly one unit apart with equal value

Problem 3

Suppose \(f:[0,2]\to\mathbb{R}\) is continuous and \(f(0)=f(2)\). Prove there exist \(x_1,x_2\in[0,2]\) with \(x_2-x_1=1\) and \(f(x_1)=f(x_2)\).

It suffices to find some \(c\in[0,1]\) with \(f(c)=f(c+1)\) (then \(x_1=c\), \(x_2=c+1\) works). Define \(g(x)=f(x)-f(x+1)\) on \([0,1]\), continuous since \(f\) is. Then:

\[ g(0)=f(0)-f(1), \qquad g(1)=f(1)-f(2)=f(1)-f(0) \]

using \(f(0)=f(2)\) in the last step. So \(g(1)=-g(0)\). If \(g(0)=0\), we're already done (\(c=0\)). Otherwise \(g(0)\) and \(g(1)=-g(0)\) have opposite signs, so by Bolzano's theorem \(\exists c\in(0,1)\) with \(g(c)=0\), i.e. \(f(c)=f(c+1)\).

Problem 4

Let \(f:\mathbb{R}\to\mathbb{R}\) be continuous with period \(2\) (meaning \(f(t)=f(t+2)\) for all \(t\)). Prove the graphs of \(y=f(x)\) and \(y=f(x+1)\) intersect somewhere.

This is Problem 3 in disguise. Periodicity with period \(2\) gives \(f(0)=f(2)\) directly, and in fact \(f(t)=f(t+2)\) for every \(t\), which is exactly the hypothesis Problem 3 needed. The same argument produces \(c\) with \(f(c)=f(c+1)\) — meaning the point \((c,f(c))\) lies on both graphs, \(y=f(x)\) and \(y=f(x+1)\).
06Problems 5–6

Hitting a moving target, and a surprising rigidity

Problem 5

If \(f\) is continuous on \([0,2]\) with \(f(0)>0\) and \(f(2)<4\), show there is some \(c\in[0,2]\) with \(f(c)=c^2\).

Same shift trick as always: let \(g(x)=f(x)-x^2\), continuous on \([0,2]\) since both \(f\) and \(x^2\) are.

\[ g(0)=f(0)-0^2=f(0)>0, \qquad g(2)=f(2)-4<0 \]

By Bolzano's theorem, \(\exists c\in[0,2]\) with \(g(c)=0\), i.e. \(f(c)=c^2\).

Problem 6

Let \(f:\mathbb{R}\to\mathbb{Z}\) be continuous. Show \(f\) must be a constant function.

By contradiction. Suppose \(f\) is not constant: then there exist \(a\ne b\) (say \(a

Since \(r\) lies between \(f(a)\) and \(f(b)\) and \(f\) is continuous, the IVT gives some \(c\) between \(a\) and \(b\) with \(f(c)=r\). But \(r\notin\mathbb{Z}\), while \(f(c)\) must be in \(\mathbb{Z}\) by hypothesis — contradiction. So our assumption was false, and \(f\) is constant.

This is a nice one to sit with: it's a purely topological fact about continuity, with almost no algebra involved, and yet it completely rules out an entire class of functions.

07Problem 7

The Tibetan monk

Problem 7

A monk starts up a mountain to a monastery at 7 am and arrives at the top (elevation 5000 ft) at 7 pm. The next day he starts back down at 7 am along the same path, arriving at the bottom at 7 pm. Show there must be a time between 7 am and 7 pm when he was at exactly the same elevation on both days.

Going up (day 1) vs. coming down (day 2)

Let \(t\) range over \([0,12]\) (hours after 7 am). Let \(u(t)\) be his elevation after \(t\) hours going up, so \(u(0)=0\) and \(u(12)=5000\). Let \(d(t)\) be his elevation \(t\) hours into coming down, so \(d(0)=5000\) and \(d(12)=0\). Both are continuous on \([0,12]\) (elevation changes continuously as he walks).

Let \(f(t)=u(t)-d(t)\), continuous on \([0,12]\), with

\[ f(0)=0-5000=-5000, \qquad f(12)=5000-0=5000. \]

By Bolzano's theorem, \(\exists c\in[0,12]\) with \(f(c)=0\), i.e. \(u(c)=d(c)\) — at time \(c\) hours after 7 am, he was at the same elevation on both days.

Notice this argument works even if he stops to rest, walks backward briefly, or changes pace — the only thing that matters is that elevation-vs-time is continuous on both days.

08Problem 8

From existence to a number: approximating √105

Problem 8 — the Bisection Method

Find \(\sqrt{105}\) — that is, find \(c\in\mathbb{R}\) with \(c^2=105\).

Let \(f(x)=x^2-105\). Then \(f(10)=-5<0\) and \(f(11)=16>0\). By Bolzano's theorem, there is a \(c\in[10,11]\) with \(f(c)=0\), i.e. \(c^2=105\). But Bolzano's theorem only promises \(c\) exists — it doesn't say where. The bisection method turns that existence proof into an algorithm: repeatedly cut the interval in half, and use the sign of \(f\) at the midpoint to decide which half still contains \(c\).

Split \([10,11]\) into \([10,10.5]\) and \([10.5,11]\). Since \(10.5^2=110.25>105\), we have \(f(10.5)>0\), so \(c\in[10,10.5]\). Split again into \([10,10.25]\) and \([10.25,10.5]\). Since \(10.25^2=105.0625>105\), \(f(10.25)>0\), so \(c\in[10,10.25]\). Continue this process indefinitely — this is exactly what the interactive demo above automates.
09Problem 9

Existence of nth roots, for any n

Problem 9

Let \(\alpha\ge0\) and \(n\in\mathbb{N}\). Show there exists \(\beta\ge0\) with \(\beta^n=\alpha\).

If \(\alpha=0\), take \(\beta=0\) — done. Now suppose \(\alpha>0\). Choose \(N\in\mathbb{N}\) with \(N>\alpha\); then \(N^n\ge N>\alpha\) (since \(N\ge1\)).

Consider \(f:[0,\infty)\to[0,\infty)\), \(f(x)=x^n-\alpha\). Then \(f(0)=-\alpha<0\) and \(f(N)=N^n-\alpha>0\). Applying the IVT to \(f\) on \([0,N]\) gives some \(c\in[0,N]\) with \(f(c)=0\), i.e. \(c^n=\alpha\). Take \(\beta=c\).

The key identity is the factorization \(a^n-b^n=(a-b)(b^{n-1}+ab^{n-2}+a^2b^{n-3}+\cdots+a^{n-1})\), which comes from the geometric-series identity \(x^n-1=(x-1)(1+x+\cdots+x^{n-1})\) applied to \(x=a/b\).

For \(a,b\ge0\): if \(a=b\) then clearly \(a^n=b^n\). Conversely, if \(a^n=b^n\), the factorization forces \(a-b=0\) or \(b^{n-1}+ab^{n-2}+\cdots+a^{n-1}=0\); the second sum is a sum of nonnegative terms that's only zero when \(a=b=0\) — either way, \(a=b\). And if \(a\ge b\ge0\), the same factorization (now with \(a-b\ge0\) and every term of the sum \(\ge0\)) shows \(a^n\ge b^n\). This one-one, order-preserving behavior of \(x\mapsto x^n\) on \([0,\infty)\) is exactly what the next problem is about.

10Problem 10, and two exercises

xⁿ is a bijection on [0, ∞)

Problem 10

If \(n\in\mathbb{N}\) and \(f:[0,\infty)\to[0,\infty)\) is defined by \(f(x)=x^n\), show \(f\) is bijective.

One-one: if \(f(a)=f(b)\), i.e. \(a^n=b^n\) with \(a,b\ge0\), the algebra fact from Section 9 gives \(a=b\).

Onto: let \(I=[0,\infty)\). Since \(f:I\to I\), certainly \(f(I)\subseteq I\); we need the reverse containment \(I\subseteq f(I)\). Take any \(k\in I\). Then \(f(k)=k^n\ge k\) (from the algebra fact, since \(k\ge1\) gives \(k^n\ge k\) directly, and \(0\le k\le1\) gives \(k^n\le k\le1\) — either way \(k\) is trapped between \(f(0)=0\) and \(f(\max(k,1))\)). More directly: \(0\in f(I)\) (as \(f(0)=0\)) and \(k^n\in f(I)\) (as \(f(k)=k^n\)), and since \(f(I)\) is an interval (Problem 0!), the entire segment \([0,k^n]\) — in particular \(k\) itself, once \(k^n\ge k\) — lies in \(f(I)\). So every \(k\in I\) is in \(f(I)\), giving \(I\subseteq f(I)\).

This is a nice full-circle moment: Problem 0's "image of an interval is an interval" isn't just a warm-up fact, it's doing real work in the onto argument here.

Exercise 1 — try it yourself

Let \(n\in\mathbb{N}\) be odd, and \(h:\mathbb{R}\to\mathbb{R}\), \(h(x)=x^n\). Show \(h\) is bijective.

You'll need the odd-degree version of the algebra fact from Section 9, extended to negative numbers — odd powers preserve sign, so \(x^n\) is still strictly increasing across all of \(\mathbb{R}\), not just \([0,\infty)\). For onto: given any \(y\in\mathbb{R}\), find two points where \(x^n-y\) changes sign (try very negative and very positive \(x\)) and apply Bolzano's theorem, the same way Problem 9 did.
Exercise 2 — try it yourself

If \(f:I\to\mathbb{R}\) is continuous on an interval \(I\) and \(f(x)\ne0\) for every \(x\in I\), show that either \(f(x)>0\) for all \(x\in I\), or \(f(x)<0\) for all \(x\in I\).

Argue by contradiction using Bolzano's theorem directly: if \(f\) took both a positive and a negative value somewhere on \(I\), what would that force to exist between them — and why does the hypothesis "\(f(x)\ne0\) for all \(x\in I\)" immediately rule that out?
The one idea to take away. Every solution above did the same three things: (1) build a new continuous function, almost always by subtracting the two things you want to show are equal; (2) check the sign of that new function at two convenient points; (3) invoke Bolzano's theorem. If you can spot "I want to show two quantities are equal, or that some equation has a solution" in a problem, this is very often the fastest route in.
