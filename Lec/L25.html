The Lagrange Mean Value Theorem and its applications

Rolle's Theorem needed the graph to return to the same height. Drop that requirement and ask a more honest question instead: is there always a point where the instantaneous rate of change matches the average rate of change over the whole interval? The answer is yes — and it's one of the hardest-working theorems in analysis. As before, every problem hides its solution behind a "Show solution" button.

01The statement

The Lagrange Mean Value Theorem

Statement. Let \(f:[a,b]\to\mathbb{R}\) be a function such that:

  1. \(f\) is continuous on the closed interval \([a,b]\),
  2. \(f\) is differentiable on the open interval \((a,b)\).

Then there exists at least one \(c\in(a,b)\) such that

\[ f'(c)=\frac{f(b)-f(a)}{b-a}. \]

02The proof

Rolle's Theorem applied to "f minus its secant"

Rolle's Theorem handles curves whose endpoints are level. A general curve is not level, but we can make it level by subtracting the straight line through its endpoints.

Setup. Let \(m=\dfrac{f(b)-f(a)}{b-a}\) be the slope of the secant, and define \[ \varphi(x)=f(x)-\bigl[f(a)+m(x-a)\bigr]. \] The bracket is the secant line, so \(\varphi(x)\) is the signed vertical gap between the curve and the secant.

Step 1: equal endpoint values. \(\varphi(a)=f(a)-f(a)-0=0\), and \[ \varphi(b)=f(b)-f(a)-m(b-a)=f(b)-f(a)-\bigl(f(b)-f(a)\bigr)=0. \] So \(\varphi(a)=\varphi(b)\).

Step 2: regularity. \(f\) is continuous on \([a,b]\) and differentiable on \((a,b)\), and so is the linear function \(f(a)+m(x-a)\). Hence so is their difference \(\varphi\).

Step 3: Rolle. \(\varphi\) satisfies all three hypotheses of Rolle's Theorem, so there is \(c\in(a,b)\) with \(\varphi'(c)=0\). Since \(\varphi'(x)=f'(x)-m\), \[ f'(c)=m=\frac{f(b)-f(a)}{b-a}.\qquad\blacksquare \]

Explore · Tilt the curve until it is level

The violet curve is \(\psi_s(x)=f(x)-s\,m\,(x-a)\); the dim dashed curve is \(f\) itself. At \(s=0\) the endpoints sit at different heights (coral dashed level shows \(f(a)\)). As you raise \(s\) the whole curve tilts, and at \(s=1\) the endpoints are exactly level: this is \(\varphi\) (up to the constant \(f(a)\)). Its flat tangent is the Rolle point, and a flat tangent of \(\psi_1\) means \(f'(c)=m\).

Geometric meaning. The point where \(\varphi\) is largest or smallest is the point of the curve farthest from the secant (measured vertically). There the tangent runs parallel to the secant, which is exactly why the slopes match.
Slogan. The Mean Value Theorem is Rolle's Theorem applied to "\(f\) minus its secant line". The trick of subtracting off the straight-line part to force equal endpoint values will reappear constantly.
03Explore

Which hypotheses really matter?

The theorem asks for continuity on the closed interval and differentiability on the open one. Test six examples.

Explore · Testing the hypotheses
Takeaway. Corners, cusps and jumps inside \((a,b)\) can destroy the conclusion. Trouble at an endpoint (like \(\sqrt x\) at \(0\)) does not, as long as \(f\) is continuous there. And the hypotheses are sufficient, not necessary: failing one means no guarantee, not that no \(c\) exists.
04Six uses of one central theorem

Applications of the Mean Value Theorem

  1. Establishing inequalities. If \(f\) is continuous on \([a,b]\) and \(|f'(x)|\le M\) for all \(x\in(a,b)\), then \(|f(b)-f(a)|\le M|b-a|\) — bounding the derivative bounds how much the function can move.
  2. Proving monotonicity. If \(f'(x)>0\) throughout \((a,b)\), then \(f\) is strictly increasing on \([a,b]\); if \(f'(x)<0\), strictly decreasing.
  3. Detecting constant functions. If \(f'(x)=0\) for every \(x\) in an interval, then \(f\) is constant there — a fact that looks obvious but genuinely needs proof, and the MVT supplies it.
  4. Mean rate of change interpretation. There is always some instant where the instantaneous rate of change equals the average rate of change over the whole interval.
  5. Error estimation. In Taylor's theorem and numerical methods, the MVT bounds the gap between a function and its linear approximation.
  6. Physics — matching average and instantaneous velocity. If \(s(t)\) is position, some instant \(c\) has \(v(c)=\dfrac{s(t_2)-s(t_1)}{t_2-t_1}\) — this is the precise statement behind "somewhere on the highway you were going exactly the speed limit average."

05Problems 1–2

Finding c by hand

Problem 1

Verify the MVT for \(f(x)=x^2+2x+1\) on \([1,3]\).

\(f\) is a polynomial, so continuous and differentiable everywhere — MVT applies on any interval, in particular \([1,3]\).

\[ f(3)=9+6+1=16, \qquad f(1)=1+2+1=4, \qquad \frac{f(3)-f(1)}{3-1}=\frac{12}{2}=6. \]

Find \(c\) with \(f'(c)=6\): \(f'(x)=2x+2\), so \(2c+2=6\implies c=2\). Indeed \(c=2\in(1,3)\). ✓

Problem 2

Apply the MVT to \(f(x)=\sqrt{x}\) on \([1,4]\).

\(f\) is continuous on \([1,4]\) and differentiable on \((1,4)\), so the MVT applies.

\[ f(4)=2,\quad f(1)=1,\quad \frac{f(4)-f(1)}{4-1}=\frac13. \]

\(f'(x)=\dfrac{1}{2\sqrt x}\); set \(f'(c)=\dfrac13\): \(\dfrac{1}{2\sqrt c}=\dfrac13\implies\sqrt c=\dfrac32\implies c=\dfrac94\). Indeed \(c=\dfrac94\in(1,4)\). ✓

06Problems 3–4

Monotonicity, and a classic inequality

Problem 3

Solve \(\ln(x)<\ln(5)\) for \(x\in(0,\infty)\).

\(\ln'(x)=\dfrac1x>0\) for every \(x>0\), so by MVT-application 2, \(\ln x\) is strictly increasing on \((0,\infty)\). A strictly increasing function preserves the direction of an inequality: \(\ln(x)<\ln(5)\iff x<5\). Combined with the domain requirement \(x>0\):

\[ \boxed{0<x<5} \]

This looks like a one-line algebra fact, but "you can just compare the insides of an increasing function" is secretly the Mean Value Theorem at work every time you use it.

Problem 4

Use the MVT to show \(|\sin w-\sin z|\le|w-z|\) for \(0\le z<w\le2\pi\).

Let \(f(x)=\sin x\) on \([z,w]\). \(f\) is continuous on \([z,w]\) and differentiable on \((z,w)\) (sine is smooth everywhere), with \(f'(x)=\cos x\) — so the MVT applies. There is some \(c\in(z,w)\) with

\[ f'(c)=\frac{f(w)-f(z)}{w-z} \implies \cos c=\frac{\sin w-\sin z}{w-z}. \]

Take absolute values: \(\dfrac{|\sin w-\sin z|}{|w-z|}=|\cos c|\le1\), since cosine is always between \(-1\) and \(1\). Multiplying through by \(|w-z|>0\):

\[ |\sin w-\sin z|\le|w-z|. \]

This is application 1 from Section 2 in action: bounding \(|f'|\le1\) directly bounded how much \(\sin\) could change.

07Problems 5–6

Zero derivative means constant — and what follows from it

Problem 5

Suppose \(f'(x)=0\) for every \(x\in[a,b]\). Show \(f\) is constant on \([a,b]\).

By contradiction: suppose \(f\) is not constant. Then there exist \(x_1\ne x_2\) in \([a,b]\) with \(f(x_1)\ne f(x_2)\). Since \(f\) is differentiable on \([a,b]\) (hence continuous too), the MVT applies on the interval between \(x_1\) and \(x_2\): there's some \(c\) between them with

\[ f'(c)=\frac{f(x_2)-f(x_1)}{x_2-x_1}. \]

But \(f'(c)=0\) by hypothesis, forcing \(f(x_2)=f(x_1)\) — contradicting \(f(x_1)\ne f(x_2)\). So the assumption was false: \(f\) is constant.

Problem 6 — two corollaries

(a) If \(f'(x)=g'(x)\) for all \(x\in[a,b]\), show \(f(x)=g(x)+c\) for some constant \(c\).
(b) If \(f'(x)=k\) (a constant) for all \(x\), show \(f(x)=kx+d\) for some constant \(d\).

(a) Let \(h(x)=f(x)-g(x)\). Then \(h'(x)=f'(x)-g'(x)=0\) for every \(x\), so by Problem 5, \(h\) is constant: \(h(x)=c\) for some \(c\), i.e. \(f(x)=g(x)+c\).

(b) Let \(g(x)=kx\), so \(g'(x)=k=f'(x)\) for every \(x\). By part (a), \(f(x)=g(x)+d=kx+d\) for some constant \(d\).

Part (b) is the fact that makes "\(\int k\,dx=kx+C\)" true — antiderivatives are only defined up to a constant precisely because of Problem 5.

08Problems 7–8

How far can f travel if its derivative is bounded?

Problem 7

Suppose \(f\) is continuous and differentiable on \([-7,0]\), \(f(-7)=-3\), and \(f'(x)\le2\) for all \(x\). What's the largest possible value of \(f(0)\)?

The MVT applies on \([-7,0]\): there's some \(c\in(-7,0)\) with

\[ f(0)-f(-7)=f'(c)\big(0-(-7)\big) \implies f(0)+3=7f'(c) \implies f(0)=7f'(c)-3. \]

Since \(f'(c)\le2\), the largest \(f(0)\) can possibly be occurs when \(f'(c)\) takes its maximum allowed value, \(2\):

\[ f(0)\le7(2)-3=11. \]

So the largest possible value of \(f(0)\) is \(\boxed{11}\).

Problem 8

Suppose \(f(0)=-3\) and \(f'(x)\le5\) for all \(x\). How large can \(f(2)\) be? Separately, prove \(\tan^{-1}x+\cot^{-1}x=\dfrac\pi2\) for all \(x\).

First part. \(f(2)=f(0)+2f'(c)=-3+2f'(c)\) for some \(c\in(0,2)\), by the same MVT argument as Problem 7. Since \(f'(c)\le5\), \(f(2)\le-3+2(5)=7\).

Second part. Let \(f(x)=\tan^{-1}x+\cot^{-1}x\). Then \(f'(x)=\dfrac{1}{1+x^2}-\dfrac{1}{1+x^2}=0\) for every \(x\). By Problem 5, \(f\) is constant: \(f(x)=c\) for all \(x\). Evaluate at any convenient point, say \(x=1\): \(c=\tan^{-1}1+\cot^{-1}1=\dfrac\pi4+\dfrac\pi4=\dfrac\pi2\). So \(\tan^{-1}x+\cot^{-1}x=\dfrac\pi2\) for every \(x\).

09Problems 9–10

Ruling out functions, and a symmetric case

Problem 9

Does there exist a function \(f\) with \(f(0)=-1\), \(f(2)=4\), and \(f'(x)<2\) for all \(x\)?

No. If \(f'(x)\) exists everywhere, \(f\) is differentiable (hence continuous), so the MVT applies on \([0,2]\): there's some \(c\in(0,2)\) with \(f'(c)=\dfrac{f(2)-f(0)}{2-0}=\dfrac{4-(-1)}{2}=\dfrac52\). But \(\dfrac52=2.5>2\), contradicting the requirement \(f'(x)<2\) for every \(x\), including this particular \(c\). So no such function exists.
Problem 10

Suppose \(f\) is odd (\(f(-x)=-f(x)\)) and differentiable everywhere. Show that for every \(b>0\), there is some \(c\in(-b,b)\) with \(f'(c)=\dfrac{f(b)}{b}\).

Apply the MVT to \(f\) on \([-b,b]\): there's some \(c\in(-b,b)\) with

\[ f'(c)=\frac{f(b)-f(-b)}{b-(-b)}=\frac{f(b)-(-f(b))}{2b}=\frac{2f(b)}{2b}=\frac{f(b)}{b}, \]

using oddness, \(f(-b)=-f(b)\), in the middle step.

A natural follow-up: could you instead find \(c\in(0,b)\)? Yes — since \(f\) is odd, \(f(0)=0\) automatically (set \(x=0\) in \(f(-x)=-f(x)\) to get \(f(0)=-f(0)\)), so applying the MVT to \(f\) on \([0,b]\) directly gives \(f'(c)=\dfrac{f(b)-f(0)}{b-0}=\dfrac{f(b)}{b}\) with \(c\in(0,b)\), a sharper conclusion than the symmetric interval above.

10Wrapping up

Self-assessment

Part A — recall

State the two hypotheses of the MVT and its conclusion. How does Rolle's Theorem sit inside it?

\(f\) continuous on \([a,b]\), differentiable on \((a,b)\); conclusion: \(\exists c\in(a,b)\) with \(f'(c)=\frac{f(b)-f(a)}{b-a}\). Rolle's Theorem is the special case \(f(a)=f(b)\), which makes the right-hand side \(0\).
Part B — apply

Verify the MVT for \(f(x)=x^3\) on \([0,2]\), finding \(c\) explicitly.

\(f\) is a polynomial (continuous, differentiable everywhere), so the MVT applies. \(\frac{f(2)-f(0)}{2-0}=\frac{8-0}{2}=4\). \(f'(x)=3x^2\); set \(3c^2=4\implies c=\sqrt{4/3}=\frac{2}{\sqrt3}\approx1.15\), which lies in \((0,2)\). ✓
Part B — apply

Use the MVT to show \(e^x\ge1+x\) for all \(x\ge0\). (Hint: apply the MVT to \(f(t)=e^t\) on \([0,x]\).)

For \(x=0\), equality holds trivially. For \(x>0\), the MVT on \([0,x]\) gives some \(c\in(0,x)\) with \(e^c=\frac{e^x-e^0}{x-0}=\frac{e^x-1}{x}\). Since \(c>0\), \(e^c>e^0=1\), so \(\frac{e^x-1}{x}>1\implies e^x-1>x\implies e^x>1+x\). Combined with the \(x=0\) case, \(e^x\ge1+x\) for all \(x\ge0\).
Part C — think

Problem 5 (zero derivative ⟹ constant) required the domain to be an interval. Find a function defined on a non-interval set where the derivative is zero everywhere it's defined, but the function isn't constant.

Let \(f(x)=1\) for \(x\in(0,1)\) and \(f(x)=2\) for \(x\in(2,3)\), defined on the disconnected set \((0,1)\cup(2,3)\). Then \(f'(x)=0\) everywhere it's defined, but \(f\) takes two different values overall. The proof of Problem 5 breaks down because the MVT needs a genuine interval \([x_1,x_2]\) between any two points \(x_1,x_2\) in the domain — and here, a point like \(x_1=0.5\) and \(x_2=2.5\) has no path through the domain connecting them.
Part C — think

Problem 9 concluded no function exists with \(f(0)=-1\), \(f(2)=4\), \(f'(x)<2\) everywhere. Which specific hypothesis would you need to weaken to make such a function possible, and why?

You'd need to drop differentiability (or continuity) somewhere on \([0,2]\) — the contradiction relied entirely on the MVT applying, which needs \(f\) differentiable on the open interval and continuous on the closed one. If \(f\) is allowed a jump discontinuity, it can leap from near \(-1\) straight up to near \(4\) without any single point ever needing a steep-enough slope, sidestepping the MVT's guarantee entirely.
The one idea to take away. Every non-trivial problem above reduced to the same move: build a single-variable function (often a difference, like \(f-g\) or \(g-h\)), confirm it's continuous and differentiable on the interval in question, then read off what the MVT (or, when the endpoint values match, Rolle's Theorem) forces to be true about its derivative. Recognizing "I want to compare two values of something" as the cue for this move is most of the skill.
