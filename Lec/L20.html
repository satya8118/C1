Lecture 19: Intermediate Value Theorem & Root Location

Global Properties on Closed Intervals & Real-World Applications

Step 1 — Bolzano's Location of Roots Theorem

In L18, we proved that if $f(c) > 0$, then $f(x)$ remains positive in a small interval $(c-\delta, c+\delta)$ (Sign-Preserving Property). We now use this local property together with the Least Upper Bound (LUB) Property of real numbers to prove our first global theorem.

Theorem 19.1 — Bolzano's Location of Roots Theorem
Let $f: [a, b] \to \mathbb{R}$ be continuous on the closed interval $[a, b]$. If $f(a) < 0$ and $f(b) > 0$, then there exists at least one point $c \in (a, b)$ such that: $$f(c) = 0$$
Proof using LUB Property & $\epsilon$-$\delta$ Continuity:
1. Consider the set $S = \{x \in [a, b] : f(t) < 0 \text{ for all } t \in [a, x]\}$.
2. $S$ is non-empty because $a \in S$ (since $f(a) < 0$). Also, $S$ is bounded above by $b$.
3. By the Completeness Property of $\mathbb{R}$, $S$ has a Least Upper Bound (LUB), say $c = \text{LUB}(S)$. Since $a \in S$ and $b$ is an upper bound, $a \le c \le b$.

We claim that $f(c) = 0$:
We eliminate the other two possibilities using sign preservation:
  • Suppose $f(c) < 0$: Then $c \neq b$ (since $f(b) > 0$). By the sign-preserving property with $\epsilon = \frac{|f(c)|}{2}$, there exists $\delta > 0$ such that $f(x) < 0$ for all $x \in (c - \delta, c + \delta)$. This means we can find $x_1 > c$ where $f$ stays negative, so $x_1 \in S$. But this contradicts $c$ being an upper bound of $S$!
  • Suppose $f(c) > 0$: Then $c \neq a$ (since $f(a) < 0$). By sign preservation, there exists $\delta > 0$ such that $f(x) > 0$ for all $x \in (c - \delta, c + \delta)$. Thus, no point in $(c - \delta, c + \delta)$ can belong to $S$. This means $c - \delta$ is an upper bound for $S$, which contradicts $c$ being the least upper bound!
Therefore, by elimination, $f(c) = 0$. Since $f(a) \neq 0$ and $f(b) \neq 0$, $c \in (a, b)$. $\blacksquare$

Step 2 — General Intermediate Value Theorem (IVT)

Theorem 19.2 — Intermediate Value Theorem (IVT)
Let $f: [a, b] \to \mathbb{R}$ be continuous. If $k$ is any real number strictly between $f(a)$ and $f(b)$ (i.e., $f(a) < k < f(b)$ or $f(b) < k < f(a)$), then there exists at least one $c \in (a, b)$ such that: $$f(c) = k$$
Proof:
Assume without loss of generality that $f(a) < k < f(b)$.
Define an auxiliary function $g: [a, b] \to \mathbb{R}$ by: $$g(x) = f(x) - k$$ 1. Since $f(x)$ is continuous on $[a,b]$ and constant functions are continuous, $g(x)$ is continuous on $[a,b]$ by the algebra of limits.
2. Evaluate $g$ at the endpoints: $$g(a) = f(a) - k < 0 \quad \text{and} \quad g(b) = f(b) - k > 0$$ 3. By Bolzano's Theorem (Theorem 19.1), there exists $c \in (a, b)$ such that $g(c) = 0$.
4. Substituting $g(c) = f(c) - k = 0$ gives $f(c) = k$. $\blacksquare$

Step 3 — Application: Fixed Point Theorem on $[0,1]$

Theorem 19.3 — Brouwer's Fixed Point Theorem in 1D
Let $f: [0, 1] \to [0, 1]$ be a continuous function. Then $f$ has at least one fixed point; that is, there exists $c \in [0, 1]$ such that: $$f(c) = c$$
Proof:
Define $h(x) = f(x) - x$ for $x \in [0, 1]$.
Since $f(x)$ and $x$ are continuous on $[0, 1]$, $h(x)$ is continuous on $[0, 1]$.
Evaluate $h(x)$ at $x = 0$ and $x = 1$: $$h(0) = f(0) - 0 = f(0) \ge 0 \quad (\text{since } f(x) \in [0,1] \text{ for all } x)$$ $$h(1) = f(1) - 1 \le 0 \quad (\text{since } f(1) \le 1)$$
  • If $h(0) = 0$, then $f(0) = 0$, so $c = 0$ is a fixed point.
  • If $h(1) = 0$, then $f(1) = 1$, so $c = 1$ is a fixed point.
  • If $h(0) > 0$ and $h(1) < 0$, then $h(x)$ changes sign. By Bolzano's Theorem, there exists $c \in (0, 1)$ such that $h(c) = 0 \implies f(c) - c = 0 \implies f(c) = c$.
In all cases, a fixed point $c \in [0, 1]$ exists. $\blacksquare$

Step 4 — Practice Problems

Problem 1: Polynomial Root Existence
Prove that the equation $x^5 - 3x - 1 = 0$ has at least one real root in the interval $[1, 2]$.
Solution: Define $f(x) = x^5 - 3x - 1$. As a polynomial, $f$ is continuous on $[1, 2]$.
Evaluate at endpoints: $$f(1) = (1)^5 - 3(1) - 1 = 1 - 3 - 1 = -3 < 0$$ $$f(2) = (2)^5 - 3(2) - 1 = 32 - 6 - 1 = 25 > 0$$ Since $f(1) < 0 < f(2)$, by Bolzano's Theorem, there exists $c \in (1, 2)$ such that $f(c) = 0$, i.e., $c^5 - 3c - 1 = 0$. $\blacksquare$
Problem 2: Odd Degree Polynomial Theorem
Prove that every real polynomial of odd degree has at least one real root.
Solution: Let $P(x) = a_n x^n + a_{n-1}x^{n-1} + \dots + a_1 x + a_0$ where $n$ is odd and $a_n \neq 0$. Assume $a_n > 0$.
Rewrite $P(x) = a_n x^n \left(1 + \frac{a_{n-1}}{a_n x} + \dots + \frac{a_0}{a_n x^n}\right)$.
Since $n$ is odd: $$\lim_{x \to \infty} P(x) = +\infty \implies \exists M_1 > 0 \text{ such that } P(M_1) > 0$$ $$\lim_{x \to -\infty} P(x) = -\infty \implies \exists M_2 < 0 \text{ such that } P(M_2) < 0$$ Since $P(x)$ is continuous on $[M_2, M_1]$ and $P(M_2) < 0 < P(M_1)$, by IVT there exists $c \in (M_2, M_1)$ such that $P(c) = 0$. $\blacksquare$
Problem 3: Antipodal Temperature Problem
Assuming the temperature on the Earth's equator is a continuous function of position, prove that there exist two diametrically opposite points on the equator with the exact same temperature.
Solution: Represent position on the equator by angle $\theta \in [0, \pi]$. Let $T(\theta)$ be the temperature at angle $\theta$.
The opposite point is at $\theta + \pi$. Define the temperature difference: $$f(\theta) = T(\theta + \pi) - T(\theta) \quad \text{for } \theta \in [0, \pi]$$ Since $T$ is continuous, $f$ is continuous on $[0, \pi]$.
Evaluate at $\theta = 0$ and $\theta = \pi$: $$f(0) = T(\pi) - T(0)$$ $$f(\pi) = T(2\pi) - T(\pi) = T(0) - T(\pi) = -f(0)$$ If $f(0) = 0$, then $T(\pi) = T(0)$ and we are done. If $f(0) \neq 0$, then $f(0)$ and $f(\pi)$ have opposite signs! By IVT, there exists $\theta_0 \in (0, \pi)$ such that $f(\theta_0) = 0 \implies T(\theta_0 + \pi) = T(\theta_0)$. $\blacksquare$
