Lecture 18: Local Properties & Functional Equations

Rigorous $\epsilon$-$\delta$ Foundations Before the Intermediate Value Theorem

Step 1 — Fundamental Local Properties of Continuous Functions

A property of a continuous function is called local if it holds within an open neighborhood $(a - \delta, a + \delta)$ of a given point $a$. Here we prove two fundamental local properties purely using the $\epsilon$-$\delta$ definition.

Property 1 — Local Boundedness
If $f: A \to \mathbb{R}$ is continuous at $a \in A$, then $f$ is locally bounded at $a$. That is, there exist constants $M > 0$ and $\delta > 0$ such that $|f(x)| \le M$ for all $x \in A \cap (a - \delta, a + \delta)$.
Proof ($\epsilon$-$\delta$ definition):
By definition of continuity at $a$, for any chosen $\epsilon > 0$, there exists a $\delta > 0$ such that: $$x \in A \text{ and } |x - a| < \delta \implies |f(x) - f(a)| < \epsilon$$ Choose $\epsilon = 1$. Then there exists $\delta > 0$ such that for all $x \in A \cap (a - \delta, a + \delta)$: $$|f(x) - f(a)| < 1$$ By the reverse triangle inequality: $$|f(x)| - |f(a)| \le |f(x) - f(a)| < 1 \implies |f(x)| < |f(a)| + 1$$ Setting $M = |f(a)| + 1 > 0$, we have $|f(x)| < M$ for all $x \in A \cap (a - \delta, a + \delta)$. Hence, $f$ is locally bounded at $a$. $\blacksquare$
Property 2 — Sign-Preserving Property (Local Strict Positivity / Negativity)
If $f: A \to \mathbb{R}$ is continuous at $a \in A$ and $f(a) \neq 0$, then there exists $\delta > 0$ such that $f(x)$ has the same sign as $f(a)$ for all $x \in A \cap (a - \delta, a + \delta)$. Specifically, $f(x) > \frac{f(a)}{2}$ if $f(a) > 0$, and $f(x) < \frac{f(a)}{2}$ if $f(a) < 0$.
Proof ($\epsilon$-$\delta$ definition):
Case 1: $f(a) > 0$.
Choose $\epsilon = \frac{f(a)}{2} > 0$. By continuity at $a$, there exists $\delta > 0$ such that: $$|x - a| < \delta \implies |f(x) - f(a)| < \frac{f(a)}{2}$$ Expanding the absolute value inequality: $$-\frac{f(a)}{2} < f(x) - f(a) < \frac{f(a)}{2} \implies f(a) - \frac{f(a)}{2} < f(x) < f(a) + \frac{f(a)}{2}$$ $$f(x) > \frac{f(a)}{2} > 0$$ Case 2: $f(a) < 0$.
Choose $\epsilon = \frac{|f(a)|}{2} = -\frac{f(a)}{2} > 0$. By continuity at $a$, there exists $\delta > 0$ such that: $$|x - a| < \delta \implies |f(x) - f(a)| < -\frac{f(a)}{2}$$ This gives: $$f(x) - f(a) < -\frac{f(a)}{2} \implies f(x) < f(a) - \frac{f(a)}{2} = \frac{f(a)}{2} < 0$$ In both cases, $f(x)$ maintains the sign of $f(a)$ on $A \cap (a - \delta, a + \delta)$. $\blacksquare$

Step 2 — Local Comparison Results via $\epsilon$-$\delta$ Definitions

Theorem 18.1 — Local Dominance Theorem
Let $f, g: A \to \mathbb{R}$ be continuous at $a \in A$. If $f(a) > g(a)$, then there exists $\delta > 0$ such that $f(x) > g(x)$ for all $x \in A \cap (a - \delta, a + \delta)$.
Proof ($\epsilon$-$\delta$ definition):
Define $h(x) = f(x) - g(x)$. Since $f$ and $g$ are continuous at $a$, $h$ is continuous at $a$ with $h(a) = f(a) - g(a) > 0$.
Let $\epsilon = \frac{h(a)}{2} = \frac{f(a) - g(a)}{2} > 0$.
By continuity of $f$ and $g$ at $a$, choose $\delta_1, \delta_2 > 0$ such that for $|x - a| < \delta_1$, $|f(x) - f(a)| < \frac{\epsilon}{2}$, and for $|x - a| < \delta_2$, $|g(x) - g(a)| < \frac{\epsilon}{2}$.
Set $\delta = \min(\delta_1, \delta_2)$. For $|x - a| < \delta$: $$|(f(x) - g(x)) - (f(a) - g(a))| \le |f(x) - f(a)| + |g(x) - g(a)| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon$$ Hence, $h(x) > h(a) - \epsilon = h(a) - \frac{h(a)}{2} = \frac{f(a) - g(a)}{2} > 0$, implying $f(x) > g(x)$. $\blacksquare$
Theorem 18.2 — Preservation of Non-Strict Inequalities
Let $f: A \to \mathbb{R}$ be continuous at $a$. If there exists $\delta_0 > 0$ such that $f(x) \ge 0$ for all $x \in A \cap (a - \delta_0, a + \delta_0) \setminus \{a\}$, then $f(a) \ge 0$.
Proof ($\epsilon$-$\delta$ definition by contradiction):
Assume $f(a) < 0$. By the sign-preserving property (Property 2), choosing $\epsilon = -\frac{f(a)}{2} > 0$, there exists $\delta_1 > 0$ such that for all $x \in A \cap (a - \delta_1, a + \delta_1)$: $$f(x) < \frac{f(a)}{2} < 0$$ Setting $\delta = \min(\delta_0, \delta_1)$, pick $x \in A \cap (a - \delta, a + \delta) \setminus \{a\}$. Then $f(x) \ge 0$ (from hypothesis) and $f(x) < 0$ (from continuity), a contradiction! Thus $f(a) \ge 0$. $\blacksquare$

Step 3 — Continuous Functional Equation Problem

Problem — Cauchy-like Ring Homomorphism Functional Equation
Find all continuous functions $f: \mathbb{R} \to \mathbb{R}$ satisfying both: $$\text{(1) } f(x+y) = f(x) + f(y) \quad \text{for all } x, y \in \mathbb{R}$$ $$\text{(2) } f(xy) = f(x)f(y) \quad \text{for all } x, y \in \mathbb{R}$$ Solve strictly using the $\epsilon$-$\delta$ definition of continuity.
Complete Rigorous Proof:
Part A: Additive Relations for Rational Numbers ($\mathbb{Q}$)
  1. Setting $x = y = 0$ in (1): $f(0 + 0) = f(0) + f(0) \implies f(0) = 0$.
  2. For any $x \in \mathbb{R}$, $f(0) = f(x + (-x)) = f(x) + f(-x) = 0 \implies f(-x) = -f(x)$.
  3. By induction on (1), for any $n \in \mathbb{N}$ and $x \in \mathbb{R}$: $f(nx) = nf(x)$.
  4. For $q = \frac{p}{q} \cdot q$ ($p \in \mathbb{Z}, q \in \mathbb{N}$): $f(p) = f\left(q \cdot \frac{p}{q}\right) = q f\left(\frac{p}{q}\right) \implies f\left(\frac{p}{q}\right) = \frac{p}{q} f(1)$.
  5. Hence, for all $r \in \mathbb{Q}$, $f(r) = c \cdot r$ where $c = f(1)$.
Part B: Determining $c = f(1)$ via Multiplicative Property
From (2), $f(1) = f(1 \cdot 1) = [f(1)]^2 \implies c = c^2 \implies c(c-1) = 0$.
Thus, either $c = 0$ or $c = 1$.

Part C: Extension from $\mathbb{Q}$ to $\mathbb{R}$ via $\epsilon$-$\delta$ Definition
Let $x_0 \in \mathbb{R}$ be an arbitrary real number. Since $f$ is continuous at $x_0$, for any $\epsilon > 0$, there exists $\delta > 0$ such that: $$|x - x_0| < \delta \implies |f(x) - f(x_0)| < \frac{\epsilon}{2}$$ By the density of rational numbers in $\mathbb{R}$, there exists $r \in \mathbb{Q}$ inside the interval $(x_0 - \delta, x_0 + \delta)$, meaning $|r - x_0| < \delta$.
Therefore, $|f(r) - f(x_0)| < \frac{\epsilon}{2}$. Since $r \in \mathbb{Q}$, $f(r) = c \cdot r$, so: $$|c \cdot r - f(x_0)| < \frac{\epsilon}{2}$$ Now, consider $|c \cdot x_0 - f(x_0)|$: $$|c \cdot x_0 - f(x_0)| \le |c \cdot x_0 - c \cdot r| + |c \cdot r - f(x_0)| = |c||x_0 - r| + |f(r) - f(x_0)|$$ Since $|x_0 - r| < \delta$, choose $\delta$ so small that $|c||x_0 - r| < \frac{\epsilon}{2}$. Then: $$|c \cdot x_0 - f(x_0)| < \frac{\epsilon}{2} + \frac{\epsilon}{2} = \epsilon$$ Since $|c \cdot x_0 - f(x_0)| < \epsilon$ for **every** $\epsilon > 0$, we must have: $$|c \cdot x_0 - f(x_0)| = 0 \implies f(x_0) = c \cdot x_0 \quad \text{for all } x_0 \in \mathbb{R}$$ Conclusion: Substituting $c = 0$ and $c = 1$ gives the only two continuous solutions: $$\bbox[5px,border:2px solid var(--lime)]{\mathbf{f(x) = 0 \quad \text{or} \quad f(x) = x \quad \text{for all } x \in \mathbb{R}}} \quad \blacksquare$$

Step 4 — Additional Results & Applications Prior to IVT

Below are crucial foundational results proven strictly with $\epsilon$-$\delta$ arguments to build complete tools before studying the Intermediate Value Theorem.

Problem 1: Density Property of Vanishing Continuous Functions
Let $f: \mathbb{R} \to \mathbb{R}$ be continuous. If $f(r) = 0$ for all $r \in \mathbb{Q}$, prove using $\epsilon$-$\delta$ that $f(x) = 0$ for all $x \in \mathbb{R}$.
Proof ($\epsilon$-$\delta$): Let $x \in \mathbb{R}$ and let $\epsilon > 0$. By continuity of $f$ at $x$, there exists $\delta > 0$ such that: $$|y - x| < \delta \implies |f(y) - f(x)| < \epsilon$$ By density of $\mathbb{Q}$, choose $r \in \mathbb{Q} \cap (x - \delta, x + \delta)$. Then $|r - x| < \delta$, so: $$|f(r) - f(x)| < \epsilon$$ Since $r \in \mathbb{Q}$, $f(r) = 0$. Thus $|0 - f(x)| < \epsilon \implies |f(x)| < \epsilon$.
Since $|f(x)| < \epsilon$ holds for all $\epsilon > 0$, we conclude $f(x) = 0$. $\blacksquare$
Problem 2: Uniqueness of Extension from Dense Subsets
If $f, g: \mathbb{R} \to \mathbb{R}$ are continuous functions such that $f(r) = g(r)$ for all $r \in \mathbb{Q}$, prove that $f(x) = g(x)$ for all $x \in \mathbb{R}$.
Proof ($\epsilon$-$\delta$): Define $h(x) = f(x) - g(x)$. By the difference rule for continuous functions, $h$ is continuous on $\mathbb{R}$.
For any $r \in \mathbb{Q}$, $h(r) = f(r) - g(r) = 0$.
Applying Problem 1 to $h(x)$, we obtain $h(x) = 0$ for all $x \in \mathbb{R}$, which implies $f(x) = g(x)$ for all $x \in \mathbb{R}$. $\blacksquare$
Problem 3: Local Glueing / Paste Lemma
Let $f: [a, b] \to \mathbb{R}$ and $g: [b, c] \to \mathbb{R}$ be continuous with $f(b) = g(b)$. Define $h: [a, c] \to \mathbb{R}$ by: $$h(x) = \begin{cases} f(x) & \text{if } x \in [a, b] \\ g(x) & \text{if } x \in (b, c] \end{cases}$$ Prove by $\epsilon$-$\delta$ definition that $h$ is continuous at $x = b$.
Proof ($\epsilon$-$\delta$): Let $\epsilon > 0$.
1. Since $f$ is continuous at $b$, $\exists \delta_1 > 0$ such that for $x \in [a, b]$, $|x - b| < \delta_1 \implies |f(x) - f(b)| < \epsilon$.
2. Since $g$ is continuous at $b$, $\exists \delta_2 > 0$ such that for $x \in [b, c]$, $|x - b| < \delta_2 \implies |g(x) - g(b)| < \epsilon$.
Set $\delta = \min(\delta_1, \delta_2)$. For any $x \in [a, c]$ with $|x - b| < \delta$:
  • If $x \in [a, b]$, $|h(x) - h(b)| = |f(x) - f(b)| < \epsilon$.
  • If $x \in (b, c]$, $|h(x) - h(b)| = |g(x) - g(b)| = |g(x) - f(b)| < \epsilon$.
In both cases, $|h(x) - h(b)| < \epsilon$. Hence $h$ is continuous at $b$. $\blacksquare$
Problem 4: Cauchy's Additive Functional Equation
Let $f: \mathbb{R} \to \mathbb{R}$ be continuous such that $f(x+y) = f(x) + f(y)$ for all $x, y \in \mathbb{R}$. Prove using $\epsilon$-$\delta$ that $f(x) = cx$ for all $x \in \mathbb{R}$, where $c = f(1)$.
Proof ($\epsilon$-$\delta$): By induction and algebraic property, $f(r) = cr$ for all $r \in \mathbb{Q}$, where $c = f(1)$.
Define $g(x) = cx$. Then $g$ is continuous on $\mathbb{R}$.
Since $f(r) = g(r)$ for all $r \in \mathbb{Q}$, and both $f$ and $g$ are continuous, by Problem 2, $f(x) = g(x) = cx$ for all $x \in \mathbb{R}$. $\blacksquare$
Problem 5: Open Complement of the Zero-Set
Let $f: \mathbb{R} \to \mathbb{R}$ be continuous and let $Z(f) = \{x \in \mathbb{R} : f(x) = 0\}$ be its set of zeros. Show using the $\epsilon$-$\delta$ definition that if $x_0 \notin Z(f)$, there exists an open interval $(x_0-\delta, x_0+\delta)$ entirely contained in $\mathbb{R} \setminus Z(f)$ (i.e., $f(x) \neq 0$ for all $x \in (x_0-\delta, x_0+\delta)$).
Proof ($\epsilon$-$\delta$): Suppose $x_0 \notin Z(f)$. Then $f(x_0) \neq 0$, which implies $|f(x_0)| > 0$.
Choose $\epsilon = \frac{|f(x_0)|}{2} > 0$.
By continuity of $f$ at $x_0$, there exists $\delta > 0$ such that for all $|x - x_0| < \delta$: $$|f(x) - f(x_0)| < \frac{|f(x_0)|}{2}$$ By the reverse triangle inequality, $|f(x_0)| - |f(x)| \le |f(x) - f(x_0)| < \frac{|f(x_0)|}{2}$, which yields: $$|f(x)| > \frac{|f(x_0)|}{2} > 0$$ Thus $f(x) \neq 0$ for all $x \in (x_0 - \delta, x_0 + \delta)$. This proves that around every point $x_0 \notin Z(f)$, there is an entire interval free of zeros, showing that the complement set $\mathbb{R} \setminus Z(f)$ is open. $\blacksquare$
