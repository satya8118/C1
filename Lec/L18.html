Lecture 18: Boundedness & Extreme Value Theorems

Global Boundedness, Least Upper Bounds, and Maximum/Minimum Values

Step 1 — Boundedness Theorem on Closed Intervals

In L18, we saw that continuity at a single point implies local boundedness. We now prove that on a closed bounded interval $[a, b]$, continuity guarantees global boundedness.

Theorem 20.1 — Boundedness Theorem
If $f: [a, b] \to \mathbb{R}$ is continuous on $[a, b]$, then $f$ is bounded on $[a, b]$. That is, there exists $M > 0$ such that: $$|f(x)| \le M \quad \text{for all } x \in [a, b]$$
Proof using LUB Property:
Define the set $S = \{x \in [a, b] : f \text{ is bounded on } [a, x]\}$.
1. $S$ is non-empty because $a \in S$ (since $f$ is bounded on $[a, a]$ with bound $|f(a)|$).
2. $S$ is bounded above by $b$. By the LUB property, let $c = \text{LUB}(S) \in [a, b]$.

We claim $c = b$ and $b \in S$:
By local boundedness (L18), since $f$ is continuous at $c$, there exists $\delta > 0$ and $K > 0$ such that $|f(x)| \le K$ for all $x \in (c - \delta, c + \delta) \cap [a, b]$.
- Since $c = \text{LUB}(S)$, pick $x_1 \in S$ with $c - \delta < x_1 \le c$. Thus $f$ is bounded on $[a, x_1]$ by some $M_1$.
- For any $x \in [a, c + \delta/2] \cap [a, b]$, $|f(x)| \le \max(M_1, K)$.
This shows $c + \delta/2 \in S$. If $c < b$, this contradicts $c$ being an upper bound of $S$. Therefore, $c = b$, and $f$ is bounded on $[a, b]$. $\blacksquare$

Step 2 — The Extreme Value Theorem (Weierstrass Theorem)

Theorem 20.2 — Extreme Value Theorem (EVT)
If $f: [a, b] \to \mathbb{R}$ is continuous, then $f$ attains its absolute maximum and absolute minimum values on $[a, b]$. That is, there exist points $x_m, x_M \in [a, b]$ such that: $$f(x_m) \le f(x) \le f(x_M) \quad \text{for all } x \in [a, b]$$
Proof using LUB and Contradiction:
By Theorem 20.1, the image set $f([a, b]) = \{f(x) : x \in [a, b]\}$ is bounded.
Let $M^* = \text{LUB}\{f(x) : x \in [a, b]\}$. We must show there exists $x_M \in [a, b]$ such that $f(x_M) = M^*$.

Suppose $f(x) < M^*$ for all $x \in [a, b]$. Define $g(x) = \frac{1}{M^* - f(x)}$.
1. Since $f(x) \neq M^*$, $g(x)$ is continuous on $[a, b]$ (by quotient rule of continuous functions).
2. By Theorem 20.1, $g(x)$ is bounded on $[a, b]$, so $\exists K > 0$ such that $\frac{1}{M^* - f(x)} \le K$ for all $x \in [a, b]$.
3. Rearranging gives $M^* - f(x) \ge \frac{1}{K} \implies f(x) \le M^* - \frac{1}{K}$ for all $x \in [a, b]$.
This means $M^* - \frac{1}{K}$ is an upper bound for $f([a, b])$, which contradicts $M^*$ being the least upper bound!
Thus, $f(x_M) = M^*$ for some $x_M \in [a, b]$.
(Applying the same logic to $-f(x)$ yields the existence of $x_m$ where $f(x_m) = \text{GLB}\{f(x)\}$.) $\blacksquare$

Step 3 — Why the Hypotheses Matter

Both hypotheses—continuity and a closed bounded interval $[a,b]$—are essential for the Extreme Value Theorem to hold.

Counterexample 1: Open Interval $(0, 1)$
Let $f(x) = \frac{1}{x}$ on $(0, 1)$. $f$ is continuous, but unbounded because $\lim_{x \to 0^+} f(x) = \infty$. It has no maximum.
Counterexample 2: Unbounded Interval $[0, \infty)$
Let $f(x) = x$ on $[0, \infty)$. $f$ is continuous, but attains no maximum value.
Counterexample 3: Discontinuous Function on $[0, 1]$
Define $f:[0,1] \to \mathbb{R}$ by: $$f(x) = \begin{cases} x & \text{if } 0 \le x < 1 \\ 0 & \text{if } x = 1 \end{cases}$$ Here $\text{LUB}\{f(x)\} = 1$, but $f(x)$ never equals $1$ anywhere in $[0, 1]$.

Step 4 — Practice Problems

Problem 1: Image of a Closed Interval
Let $f: [a, b] \to \mathbb{R}$ be continuous. Prove that the image set $f([a, b])$ is also a closed bounded interval $[m, M]$, where $m = \text{GLB}\{f(x)\}$ and $M = \text{LUB}\{f(x)\}$.
Solution: 1. By EVT (Theorem 20.2), there exist $x_m, x_M \in [a, b]$ such that $f(x_m) = m$ and $f(x_M) = M$.
2. By definition of GLB and LUB, $f(x) \in [m, M]$ for all $x \in [a, b]$, so $f([a, b]) \subseteq [m, M]$.
3. For any value $k \in (m, M)$, since $f$ is continuous on the subinterval between $x_m$ and $x_M$, the Intermediate Value Theorem (L19) guarantees there is some $c \in [a, b]$ such that $f(c) = k$.
4. Hence $[m, M] \subseteq f([a, b])$. Combining both inclusions gives $f([a, b]) = [m, M]$. $\blacksquare$
Problem 2: Minimum Distance Problem
Let $f: \mathbb{R} \to \mathbb{R}$ be a continuous function such that $\lim_{|x| \to \infty} f(x) = +\infty$. Prove that $f$ attains a global minimum on $\mathbb{R}$.
Solution: Fix $x_0 \in \mathbb{R}$ and set $K = f(x_0)$.
Since $\lim_{|x| \to \infty} f(x) = +\infty$, there exists $R > 0$ such that $|x| > R \implies f(x) > K$.
Consider the closed bounded interval $[-R, R]$. Since $f$ is continuous on $[-R, R]$, by EVT it attains its minimum at some point $x_m \in [-R, R]$, so $f(x_m) \le f(x)$ for all $x \in [-R, R]$.
Since $x_0 \in [-R, R]$ (or we can enlarge $R$ so $x_0 \in [-R, R]$), we have $f(x_m) \le f(x_0) = K$.
For any $x \notin [-R, R]$, $f(x) > K \ge f(x_m)$. Thus, $f(x_m) \le f(x)$ for all $x \in \mathbb{R}$. $\blacksquare$
