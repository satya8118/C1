Lecture 16: Continuity via Epsilon-Delta

Real Analysis — Rigorous Metric Proximity, Simple Functions, and Discontinuities

1. Motivation & The Strict $\epsilon$-$\delta$ Definition

In real analysis, we define continuity directly via static metric proximity. Continuity at a given point states that output deviations can be kept inside any arbitrary tolerance window ($< \epsilon$) exclusively by restricting the local input domain radius ($< \delta$).

Definition (Continuity at a Point): Let $A \subseteq \mathbb{R}$, $f: A \to \mathbb{R}$, and $c \in A$. The function $f$ is continuous at $c$ if for every real tolerance $\epsilon > 0$, there exists a corresponding control radius $\delta > 0$ such that: $$\forall x \in A, \quad |x - c| < \delta \implies |f(x) - f(c)| < \epsilon$$ If $f$ is continuous at every individual point $c \in A$, we say $f$ is continuous on $A$.

2. Foundational Linear Examples

We verify the core metric structure by analyzing linear and affine equations.

Example 1 (Constant Function): Let $f(x) = k$ for a fixed constant $k \in \mathbb{R}$. Prove $f$ is continuous at any $c \in \mathbb{R}$.
Proof: Let $\epsilon > 0$. Evaluating the absolute target distance: $$|f(x) - f(c)| = |k - k| = 0 < \epsilon$$ This holds true for all $x \in \mathbb{R}$. We may pick an arbitrary control assignment such as $\delta = 1$. $\blacksquare$
Example 2 (Identity & Affine Function): Let $f(x) = mx + b$ with $m \neq 0$. Prove $f$ is continuous everywhere on $\mathbb{R}$.
Proof: Let $c \in \mathbb{R}$ and $\epsilon > 0$. We write: $$|f(x) - f(c)| = |(mx + b) - (mc + b)| = |m(x - c)| = |m| |x - c|$$ We want $|m||x - c| < \epsilon$, which is equivalent to $|x - c| < \frac{\epsilon}{|m|}$. Choosing $\delta = \frac{\epsilon}{|m|}$ directly yields the result. $\blacksquare$

3. Non-Linear & Transcendental Continuous Functions

Example 3 (The Hyperbola on a Positive Domain): Prove $f(x) = \frac{1}{x}$ is continuous at any point $c \in (0, \infty)$.
Proof: Let $c > 0$ and $\epsilon > 0$. We write the distance as: $$|f(x) - f(c)| = \left|\frac{1}{x} - \frac{1}{c}\right| = \frac{|x - c|}{cx}$$ To bound $x$ away from zero, enforce a localized domain restriction $\delta \le \frac{c}{2}$. $$|x - c| < \frac{c}{2} \implies x > \frac{c}{2} \implies \frac{1}{x} < \frac{2}{c}$$ Substituting this bound yields $\frac{|x - c|}{cx} < \frac{2|x - c|}{c^2}$. Thus, we select: $$\delta = \min\left(\frac{c}{2}, \frac{c^2 \epsilon}{2}\right)$$ Whenever $|x - c| < \delta$, we have $|f(x) - f(c)| < \epsilon$. $\blacksquare$
Example 4 (Trigonometric Sine Wave): Prove $f(x) = \sin x$ is continuous on $\mathbb{R}$.
Proof: Let $c \in \mathbb{R}$ and $\epsilon > 0$. Using the trigonometric identity: $$|\sin x - \sin c| = \left|2 \sin\left(\frac{x - c}{2}\right) \cos\left(\frac{x + c}{2}\right)\right| \le 2 \left|\frac{x - c}{2}\right| \cdot 1 = |x - c|$$ Hence, choosing $\delta = \epsilon$ guarantees $|\sin x - \sin c| < \epsilon$. $\blacksquare$
Example 5 (Natural Exponential Function): Prove $f(x) = e^x$ is continuous at any $c \in \mathbb{R}$.
Proof: Let $\epsilon > 0$. Isolate the offset: $$|e^x - e^c| = e^c|e^{x-c} - 1|$$ For $|x - c| < 1$, we use the inequality $|e^u - 1| \le 2|u|$ for $|u| \le 1$. Thus: $$e^c|e^{x-c} - 1| \le 2e^c|x - c|$$ Selecting $\delta = \min\left(1, \frac{\epsilon}{2e^c}\right)$ completes the proof. $\blacksquare$

4. Discontinuous Mappings

Example A (Step Discontinuity): Consider $f(x) = \begin{cases} 1 & \text{if } x > 0 \\ 0 & \text{if } x \le 0 \end{cases}$.
Let $\epsilon = \frac{1}{2}$. For any $\delta > 0$, pick $x = \frac{\delta}{2}$. Then $|x - 0| < \delta$, but $|f(x) - f(0)| = |1 - 0| = 1 \ge \frac{1}{2}$. Thus, $f$ is discontinuous at $c = 0$.
Example B (Dirichlet Function): $f(x) = \begin{cases} 1 & \text{if } x \in \mathbb{Q} \\ 0 & \text{if } x \notin \mathbb{Q} \end{cases}$.
By the density of rationals and irrationals, every neighborhood $(c-\delta, c+\delta)$ contains points mapping to $1$ and points mapping to $0$. Choosing $\epsilon = \frac{1}{2}$ shows $f$ is discontinuous everywhere.

5. Practice Exercises on $\epsilon$-$\delta$ Continuity

Question 1: Using $\epsilon$-$\delta$, prove $f(x) = 3x + 7$ is continuous at $c = 2$.
We evaluate $|f(x) - f(2)| = |(3x + 7) - (13)| = |3x - 6| = 3|x - 2|$. To ensure $3|x - 2| < \epsilon$, we set $|x - 2| < \frac{\epsilon}{3}$. Thus, choose $\delta = \frac{\epsilon}{3}$.
Question 2: Prove $f(x) = \sqrt{x}$ is continuous at $c = 4$ using $\epsilon$-$\delta$.
$|\sqrt{x} - 2| = \frac{|x - 4|}{\sqrt{x} + 2}$. Assuming $\delta \le 3$, we have $x > 1 \implies \sqrt{x} + 2 > 3 \implies \frac{1}{\sqrt{x} + 2} < \frac{1}{3}$. Thus $|\sqrt{x} - 2| < \frac{|x - 4|}{3}$. Choose $\delta = \min(3, 3\epsilon)$.
Question 3: Prove $f(x) = x \sin(1/x)$ for $x \neq 0$ and $f(0) = 0$ is continuous at $c=0$.
$|f(x) - f(0)| = \left|x \sin\left(\frac{1}{x}\right) - 0\right| \le |x|$. Choosing $\delta = \epsilon$ ensures $|f(x) - 0| < \epsilon$ whenever $|x - 0| < \delta$.
