Real Analysis · Riemann Integration, Part II of III

The Cauchy Criterion, and curved graphs

Lecture I built lower and upper sums for a constant and a line. Now we define what "integrable" formally means, get a workable test for it (the Cauchy Criterion), and put that test through its paces on a parabola, an exponential, and — the real test — a function that isn't monotonic at all: \(\sin x\).

01Turning sums into integrals

Lower and upper integrals

Lecture I's bounding proposition showed the set of lower sums is bounded above (by \(M(b-a)\)) and the set of upper sums is bounded below (by \(m(b-a)\)). So both a supremum and an infimum exist:

Definition — Lower and Upper Riemann Integrals \[ \underline{\int_a^b} f\,dx = L(f) = \text{lub}\{L(f,P):P\in\Pi\}, \qquad \overline{\int_a^b} f\,dx = U(f) = \text{glb}\{U(f,P):P\in\Pi\} \] where \(\Pi\) is the set of all partitions of \([a,b]\).
Definition — Riemann Integrability A bounded \(f:[a,b]\to\mathbb R\) is Riemann integrable if \(L(f)=U(f)\). The common value is written \(\int_a^b f\,dx\), the Riemann integral.
A necessary consequence Since every lower sum is \(\le\) every upper sum (Lecture I's corollary), \(L(f)=\text{lub}_P L(f,P)\le\text{glb}_P U(f,P)=U(f)\) — always. Integrability is precisely the statement that this gap closes to zero.
02The single most useful theorem in this course

The Cauchy Criterion for Riemann Integrability

Theorem A bounded \(f:[a,b]\to\mathbb R\) is Riemann integrable if and only if for every \(\varepsilon>0\), there exists a partition \(P\) (depending on \(\varepsilon\)) with \(U(f,P)-L(f,P)<\varepsilon\).
Try the easy direction yourself

Assume the \(\varepsilon\)-condition holds. Show \(f\) is integrable.

Let \(\varepsilon>0\) and pick \(P\) satisfying the condition. Since \(U(f)\le U(f,P)\) and \(L(f,P)\le L(f)\): \(0\le U(f)-L(f)\le U(f,P)-L(f,P)<\varepsilon\). This holds for every \(\varepsilon>0\), so \(U(f)-L(f)=0\), i.e. \(f\) is integrable.
The harder direction

Assume \(f\) is integrable. Show the \(\varepsilon\)-condition holds. Hint: use the definitions of glb/lub to find \(Q\) with small \(U(f,Q)\) and \(R\) with large \(L(f,R)\), then take a common refinement.

Given \(\varepsilon>0\), pick \(Q,R\) with \(U(f,Q)L(f)-\frac\varepsilon2\). Let \(P=Q\cup R\), a common refinement. Refining decreases upper sums and increases lower sums, so \(U(f,P)\le U(f,Q)\) and \(L(f,P)\ge L(f,R)\). Subtracting: \[ U(f,P)-L(f,P)\le U(f,Q)-L(f,R) < \Big(U(f)+\tfrac\varepsilon2\Big)-\Big(L(f)-\tfrac\varepsilon2\Big) = U(f)-L(f)+\varepsilon. \] Since \(f\) is integrable, \(U(f)=L(f)\), so \(U(f,P)-L(f,P)<\varepsilon\).
Definition — Oscillation For \(A\subseteq[a,b]\) nonempty, the oscillation of \(f\) on \(A\) is \(\omega(f,A)=\text{lub}_A f - \text{glb}_A f\). For a partition's \(i\)-th subinterval, \(\omega(f,[x_{i-1},x_i])=M_i-m_i\), so \[ U(f,P)-L(f,P) = \sum_{i=1}^n \omega\big(f,[x_{i-1},x_i]\big)\,\Delta x_i. \]
Intuition A function is integrable exactly when subinterval widths can be made small enough to overpower any large local oscillations. Roughly: \(f\) is integrable if it oscillates by an arbitrarily small amount except on a finite collection of intervals whose total length is arbitrarily small.
03Beyond linear

f(x) = x² on [0, 2]

Still strictly increasing, so the same left/right endpoint rule applies — but now the algebra needs \(\sum k^2\) instead of \(\sum k\).

Regular partition: \(m_i=\left(\frac{2(i-1)}{n}\right)^2\), \(M_i=\left(\frac{2i}{n}\right)^2\).

Try it yourself

Using \(\sum_{k=1}^{N}k^2=\frac{N(N+1)(2N+1)}{6}\), compute \(L(f,P_n)\) and \(U(f,P_n)\), then take \(n\to\infty\).

\[ L(f,P_n)=\frac{8}{n^3}\sum_{k=0}^{n-1}k^2=\frac{8}{n^3}\cdot\frac{(n-1)n(2n-1)}{6}=\frac{4(n-1)(2n-1)}{3n^2} = \frac83-\frac4n+\frac{4}{3n^2} \] \[ U(f,P_n)=\frac{8}{n^3}\sum_{i=1}^{n}i^2=\frac{4(n+1)(2n+1)}{3n^2} = \frac83+\frac4n+\frac{4}{3n^2} \] Both \(\to\frac83\) as \(n\to\infty\).
Result \(\displaystyle\int_0^2 x^2\,dx=\frac83.\)

04Geometric series enter the picture

f(x) = eˣ on [0, 2]

Regular partition: \(m_i=e^{2(i-1)/n}\), \(M_i=e^{2i/n}\) — a geometric sequence in \(i\).

Try it yourself

Using the finite geometric series \(\sum_{k=0}^{n-1}r^k=\frac{1-r^n}{1-r}\) with \(r=e^{2/n}\), and the fact \(\lim_{h\to0}\frac{e^h-1}{h}=1\), find \(\lim_{n\to\infty}L(f,P_n)\).

\[ L(f,P_n)=\frac{2(e^2-1)}{n(e^{2/n}-1)}, \qquad U(f,P_n)=\frac{2e^{2/n}(e^2-1)}{n(e^{2/n}-1)}. \] Let \(h=2/n\to0\). Since \(\frac{e^h-1}{h}\to1\), the denominator \(n(e^{2/n}-1)=\frac{2(e^h-1)}{h}\to2\). So both sums converge to \(e^2-1\).
Result \(\displaystyle\int_0^2 e^x\,dx=e^2-1.\)

05A genuinely new challenge

f(x) = sin(x): when the extremum hides inside a subinterval

Caution \(\sin x\) increases on \([0,\frac\pi2]\) and decreases on \([\frac\pi2,2]\). The simple "left endpoint = min, right endpoint = max" rule that worked for \(x\), \(x^2\), \(e^x\) can fail completely.

Take \(n=6\) on \([0,2]\): \(\Delta x=\frac13\), nodes \(0,\frac13,\frac23,1,\frac43,\frac53,2\). Note \(\frac43\approx1.333<\frac\pi2\approx1.571<\frac53\approx1.667\) — the peak falls inside the fifth subinterval.

Think about it

Why does this "interior extremum" problem never arise for \(x\), \(x^2\), or \(e^x\) on \([0,2]\)?

All three are strictly monotonic (increasing) on the whole interval — so on any subinterval, the extreme values are forced to sit at the endpoints. \(\sin x\) is monotonic on each of \([0,\pi/2]\) and \([\pi/2,2]\) separately, but a partition node doesn't have to land exactly at \(\pi/2\), so a single subinterval can straddle the turning point and hide the true max in its interior.

Verify by hand

For \(P=\{0,1,2\}\): \(L(s,P)=U(s,P)=1(1)+3(1)=4\). For \(P'=\{0,0.5,1.5,2\}\), the subinterval \([0.5,1.5]\) straddles the jump — what are \(m,M\) there, and what do \(L,U\) come out to?

On \([0.5,1.5]\), \(s\) takes both values \(1\) and \(3\), so \(m=1,M=3\). Lower sum \(=0.5(1)+1(1)+0.5(3)=0.5+1+1.5=3\). Upper sum \(=0.5(1)+1(3)+0.5(3)=0.5+3+1.5=5\). Gap \(=2\) — simply including the jump point as a partition node makes the gap vanish entirely.
07Resolving Lecture I's subtlety

The mesh-based Riemann condition

Theorem \(f\) is Riemann integrable on \([a,b]\) iff for every \(\varepsilon>0\), there is a \(\delta>0\) such that any partition \(P\) with \(\|P\|<\delta\) satisfies \(U(f,P)-L(f,P)<\varepsilon\). Note the strength: any small-mesh partition works, not just a specially chosen refinement.
Why regular partitions are sufficient Let \(f\) be integrable on \([0,2]\). Given \(\varepsilon>0\), find \(\delta>0\) as in the theorem. The regular partition \(P_n\) has mesh \(\|P_n\|=\frac2n\to0\), so for \(n\) large enough, \(\frac2n<\delta\) — and then \(U(f,P_n)-L(f,P_n)<\varepsilon\) automatically, even though \(P_n\) may not be a strict refinement of whatever arbitrary partition you started with. This is exactly Lecture I's rescue: mesh size, not node-inclusion, is what actually matters.
Refinement vs. mesh-shrinking on [0, 2]

Yellow: coarse partition \(P\) containing the irrational node \(\sqrt2\). Pink: regular partition \(Q\) with mesh \(0.5\) — its nodes never land exactly on \(\sqrt2\), so \(Q\) is not a refinement of \(P\), yet \(\|Q\|<\|P\|\) is all that's needed for the integrability test.

08Before Lecture III

Self-assessment

Question 1

State the Cauchy Criterion for Riemann integrability in one sentence.

\(f\) is integrable on \([a,b]\) iff for every \(\varepsilon>0\) there's some partition \(P\) with \(U(f,P)-L(f,P)<\varepsilon\).
Question 2

For \(f(x)=x^3\) on \([0,2]\) (strictly increasing, like \(x\), \(x^2\), \(e^x\)), would you expect an interior-extremum problem like \(\sin x\)'s? Why or why not?

No — \(x^3\) is strictly increasing on all of \([0,2]\) (no turning point), so exactly like \(x\), \(x^2\), \(e^x\), every subinterval has its min at the left endpoint and max at the right. The interior-extremum issue only arises when the function changes direction inside some subinterval, which requires a genuine local max or min in the interior of \([a,b]\).
Question 3

Redo the step-function computation from Section 6, but for \(s(x)=2\) on \([0,1)\), \(s(x)=5\) on \([1,3]\), using the "good" partition \(P=\{0,1,3\}\) that includes the jump.

\(L(s,P)=U(s,P)=2(1)+5(2)=2+10=12\). Including the jump node always collapses the gap to zero for a step function, regardless of how many jumps or what the values are.
Question 4 — think

The oscillation formula says \(U(f,P)-L(f,P)=\sum_i\omega(f,[x_{i-1},x_i])\Delta x_i\). Use this to explain, in words, why the \(e^x\) demo in Section 4 needed a much larger \(n\) than the \(x^2\) demo in Section 3 to reach a comparably small gap.

Exponential growth means \(f\) changes far more steeply near \(x=2\) than \(x^2\) does — so the oscillation \(\omega\) on the last few subintervals is much larger for \(e^x\) at any fixed \(n\). Since the gap is a weighted sum of these oscillations, matching \(x^2\)'s gap at a given \(n\) requires many more, thinner subintervals for \(e^x\) to tame that same steep region.
