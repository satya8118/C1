RIEMANN INTEGRATION · AN EXPLORABLE ARTICLE

How do we measure the area under a curve, exactly?

We'll build the Riemann integral from the ground up using one running example — squeezing the area under f(x) = x² between rectangles that are too small and rectangles that are too big, until the gap between them vanishes.

f(x) = x²  |  a = 0  |  b = 6  |  ∫₀⁶ x² dx = 72

What is a partition?

definition

A partition \(P\) of \([a,b]\) is a finite set of points

\[ P = \{a = x_0 < x_1 < x_2 < \cdots < x_n = b\} \]

that chops \([a,b]\) into \(n\) smaller subintervals \([x_{i-1}, x_i]\), each of length \(\Delta x_i = x_i - x_{i-1}\). When every subinterval has the same length \(\Delta x = \frac{b-a}{n}\), we call \(P\) a regular (uniform) partition — that's what we'll use throughout, with \(a=0,\ b=6\).

Why do we insist a partition is finite and increasing?

We need finitely many points so each "rectangle" that we'll build over \([x_{i-1},x_i]\) has a well-defined base length \(\Delta x_i\), and we need them strictly increasing so no subinterval collapses to a point. This is exactly what lets us form finite sums — nothing more exotic is needed yet.

Sampling f on a subinterval: the extreme values

setup

On each subinterval \([x_{i-1}, x_i]\), since \(f(x)=x^2\) is continuous, it attains a minimum and a maximum. Define

\[ m_i = \inf_{x \in [x_{i-1},x_i]} f(x), \qquad M_i = \sup_{x \in [x_{i-1},x_i]} f(x). \]

Because \(f(x) = x^2\) is strictly increasing on \([0,6]\), the minimum on every subinterval occurs at its left endpoint and the maximum at its right endpoint: \[ m_i = f(x_{i-1}), \qquad M_i = f(x_i). \] This is a special feature of monotone functions — for a function that goes up and down inside a subinterval, \(m_i\) and \(M_i\) need not sit at the endpoints at all.

The Lower and Upper Sum Explorer

interactive

For a partition \(P\), the lower sum and upper sum of \(f\) are

\[ L(f,P) = \sum_{i=1}^n m_i\,\Delta x_i, \qquad\qquad U(f,P) = \sum_{i=1}^n M_i\,\Delta x_i. \]

Geometrically, \(L(f,P)\) is the total area of rectangles sitting under the curve (an underestimate), and \(U(f,P)\) is the total area of rectangles sitting over the curve (an overestimate). Since \(f\) is increasing here, \(L(f,P)\) is exactly the left-endpoint Riemann sum and \(U(f,P)\) is exactly the right-endpoint Riemann sum \(R(f,P)\) — drag the slider and watch both build, subinterval by subinterval.

Where does the closed-form formula for L and U come from?

For a regular partition of \([0,6]\) into \(n\) pieces, \(x_i = \frac{6i}{n}\) and \(\Delta x = \frac{6}{n}\). Since \(m_i = x_{i-1}^2\) and \(M_i = x_i^2\):

\[ L(f,P) = \sum_{i=1}^n \left(\frac{6(i-1)}{n}\right)^{\!2}\frac{6}{n} = \frac{216}{n^3}\sum_{i=1}^n (i-1)^2 = \frac{216}{n^3}\cdot\frac{(n-1)n(2n-1)}{6} = \frac{36(n-1)(2n-1)}{n^2}. \]

\[ U(f,P) = \frac{216}{n^3}\sum_{i=1}^n i^2 = \frac{216}{n^3}\cdot\frac{n(n+1)(2n+1)}{6} = \frac{36(n+1)(2n+1)}{n^2}. \]

Check at \(n=4\): \(L = \frac{36\cdot3\cdot7}{16} = \frac{756}{16}=47.25\) ✓, and \(U = \frac{36\cdot5\cdot9}{16}=\frac{1620}{16}=101.25\) ✓ — matching the table above.

From sums to the integral

definitions

Every lower sum underestimates and every upper sum overestimates the true area, no matter the partition, so it always holds that

\[ L(f,P) \le U(f,Q) \quad \text{for \emph{any} two partitions } P, Q \text{ of } [a,b]. \]

This lets us define two numbers that squeeze from either side:

\[ \underline{\int_a^b} f = \sup_P L(f,P) \qquad \text{(lower integral)}, \qquad \overline{\int_a^b} f = \inf_P U(f,P) \qquad \text{(upper integral)}. \]

Definition (Riemann integrability). \(f\) is Riemann integrable on \([a,b]\) if the lower and upper integrals agree: \[ \underline{\int_a^b} f = \overline{\int_a^b} f, \] and this common value is denoted \(\int_a^b f(x)\,dx\) — the Riemann integral.
The Riemann criterion: a practical test for integrability

Theorem. \(f\) is Riemann integrable on \([a,b]\) if and only if for every \(\varepsilon > 0\), there exists a partition \(P\) such that

\[ U(f,P) - L(f,P) < \varepsilon. \]

Our convergence table is this criterion in action: since \(U-L = \frac{216}{n}\), given any \(\varepsilon>0\) we can choose \(n > \frac{216}{\varepsilon}\) and the criterion is satisfied. This confirms \(f(x)=x^2\) is Riemann integrable on \([0,6]\), and since \(L(f,P)\le 72\le U(f,P)\) for every \(n\) while \(U-L\to 0\), the common squeezed value must be exactly \(72\).

Why is every continuous function on [a,b] automatically integrable?

A continuous function on a closed bounded interval is uniformly continuous (Heine–Cantor theorem): for every \(\varepsilon>0\) there is \(\delta>0\) so that \(|x-y|<\delta \Rightarrow |f(x)-f(y)|<\varepsilon\). Take a partition with every \(\Delta x_i < \delta\); then on each subinterval \(M_i - m_i < \varepsilon\), so

\[ U(f,P)-L(f,P) = \sum_i (M_i-m_i)\Delta x_i < \varepsilon \sum_i \Delta x_i = \varepsilon(b-a). \]

Since \(\varepsilon(b-a)\) can be made as small as we like, the Riemann criterion holds. This is exactly why \(f(x)=x^2\), being continuous everywhere, is integrable on any \([a,b]\).

Archimedes got here first — 2,000 years earlier

history

Long before Riemann formalised \(L(f,P)\) and \(U(f,P)\), Archimedes (c. 250 BC) found the exact area under a parabola using inscribed and circumscribed rectangles — precisely our lower and upper sums for \(f(x)=x^2\). What follows rebuilds his argument for a general segment \([0,b]\), following the classical treatment of the sum-of-squares approach found in Apostol's Calculus. Setting \(b=6\) at the end will hand us back the number 72 we already found in the Lab and Convergence tabs.

Archimedes' set-up. Split \([0,b]\) into \(n\) equal strips of width \(b/n\). Using the left endpoints gives the inscribed rectangles, and the right endpoints give the circumscribed rectangles — exactly \(L(f,P)\) and \(U(f,P)\) in our notation. Archimedes called their areas \(s_n\) and \(S_n\): \[ s_n = \frac{b^3}{n^3}\Big[1^2+2^2+\cdots+(n-1)^2\Big], \qquad S_n = \frac{b^3}{n^3}\Big[1^2+2^2+\cdots+n^2\Big]. \] Everything now hinges on getting a handle on the sum of squares \(1^2+2^2+\cdots+n^2\).

Taming the sum of squares by telescoping

interactive derivation

The trick starts from the algebraic identity \((k+1)^3 - k^3 = 3k^2+3k+1\). Write this out for \(k=1,2,\ldots,n-1\) and add all the equations — the cubes on the right almost entirely cancel, leaving only the very first and very last. The closed-form result, once the dust settles

Solving the telescoped equation for the sum of squares (and using \(1+2+\cdots+(n-1)=\tfrac12 n(n-1)\)) gives

\[ 1^2+2^2+\cdots+(n-1)^2 = \frac{n^3}{3} - \frac{n^2}{2} + \frac{n}{6}, \qquad\text{so likewise}\qquad 1^2+2^2+\cdots+n^2 = \frac{n^3}{3}+\frac{n^2}{2}+\frac{n}{6}. \]

Both are a little less, respectively a little more, than \(n^3/3\) — which is exactly the squeeze we need next.

The squeeze: s_n < b³/3 < S_n

inequality

Because \(1^2+\cdots+(n-1)^2 < \dfrac{n^3}{3} < 1^2+\cdots+n^2\) for every \(n\ge 2\), multiplying through by \(b^3/n^3\) turns this directly into a statement about areas:

\[ s_n < \frac{b^3}{3} < S_n \qquad \text{for every } n. \]

With \(b=6\), this is nothing new — it's the same squeeze \(L(f,P) < 72 < U(f,P)\) you already saw in the Lab and Convergence tabs, just derived by hand instead of by computer.

Why b³/3 is the only possible area

the exhaustion argument

Archimedes still had to rule out every other candidate number. Padding the squeeze slightly (adding/subtracting \(n^2\) before multiplying by \(b^3/n^3\)) sharpens it to

\[ \frac{b^3}{3} - \frac{b^3}{n} < s_n \le A \le S_n < \frac{b^3}{3} + \frac{b^3}{n} \qquad \text{for every } n\ge 1, \]

for any number \(A\) that is supposed to represent the true area (it always sits between the inscribed and circumscribed totals). Now suppose \(A > b^3/3\). The right-hand inequality forces

\[ A - \frac{b^3}{3} < \frac{b^3}{n} \quad\Longleftrightarrow\quad n < \frac{b^3}{A - b^3/3} \qquad \text{for every } n. \]

This is false the moment \(n\) is chosen larger than \(\dfrac{b^3}{A-b^3/3}\) — and such an \(n\) always exists, since there's no largest integer. So \(A>b^3/3\) is impossible. A mirror-image argument rules out \(A
